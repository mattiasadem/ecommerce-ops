# Unified Government ISMS — FedRAMP Moderate + GovRAMP Moderate + CMMC Level 2/3 + NIST SP 800-171 Rev 3 + NIST SP 800-53 Rev 5 + NIST CSF 2.0

> Move #176 is the **canonical unified Government ISMS** every $25M+ GMV ecommerce operator pursuing US-federal + US-state + US-defense-industrial-base + US-public-sector + healthcare-public-sector + education-public-sector contracts must ship AFTER Move #175 (the canonical international ISMS covering ISO/IEC 27001:2022 + ISO/IEC 27701:2019 + ISO/IEC 27018:2019 + ISO/IEC 42001:2023 + SOC 2 Type II): one unified government-grade ISMS that ships **FedRAMP Moderate (Class C in FedRAMP 2026 nomenclature, ~323 NIST SP 800-53 Rev 5 controls)** + **GovRAMP Moderate (state-government equivalent to FedRAMP Moderate)** + **CMMC Level 2 (C3PAO-assessed, aligned with NIST SP 800-171 Rev 3, 110 security practices, SPRS-score-of-110)** + **CMMC Level 3 (DIBCAC-assessed, ~134 NIST SP 800-172 enhanced-security-requirements, all-DIB-APL-programs-required)** + **NIST SP 800-171 Rev 3 (the canonical DIB-CUI protection standard, replaced Rev 2 in May 2024)** + **NIST SP 800-53 Rev 5.2.0 (the canonical US-federal control catalogue, 1000+ controls across 20 control-families)** + **NIST CSF 2.0 (the canonical cybersecurity-framework, Govern/Identify/Protect/Detect/Respond/Recover with the new Govern-function + Supply-Chain-Risk-Management)** + **NIST SP 800-37 Rev 2 RMF (the canonical 7-step Risk-Management-Framework: Categorize → Select → Implement → Assess → Authorize → Monitor → Maintain)** + **NIST SP 800-218 SSDF v1.1 (Secure Software Development Framework) v1.1** + **CISA Secure-by-Design + Secure-by-Default pledge 2024** + **EO 14028 Zero-Trust Architecture-mandate** + **OMB M-24-15 FedRAMP-Modernization + FedRAMP-20x transition (deadline July 4, 2026 for Consolidated Rules)**. ## When to use this skill

You have **one or more** of these signals:

- **≥$25M GMV AND pursuing US-federal contracts (GSA-Schedule + NASA-SEWP + DOD-DITCO + DHS-CS2 + VA-T4NG + GSA-VETS-2 + DOI-BPA + NIH-ECS-III + DOJ-ITSS + Treasury-ITES-3S).** Federal procurement teams increasingly require FedRAMP Moderate (Class C in FedRAMP-2026 nomenclature) Authorization-to-Operate (ATO) as table-stakes for any cloud-service-OFFERING that processes federal-information. Missing FedRAMP Moderate blocks 9-15 months of federal-sales-pipeline while waiting for the 3PAO assessment + agency-sponsorship-or-pmo-review cycle. The canonical "we lost the NASA-SEWP-V contract because NASA's CIO required FedRAMP Moderate ATO" anti-pattern.
- **≥$25M GMV AND pursuing US-state contracts (CA-DGS + TX-DIR + NY-OGS + FL-DMS + PA-ITQ + IL-CMS + WA-DES + MA-ITC + OH-DAS + GA-ITS).** State-government procurement teams increasingly require GovRAMP Moderate (formerly StateRAMP) verification as table-stakes for state-cloud-service-OFFERINGS. CA-StateRAMP + TX-DIR-Cloud + NY-State-Cloud + 28-state-Naspo-ValuePoint all require GovRAMP-or-equivalent verification. Missing GovRAMP blocks 6-12 months of state-sales-pipeline. The canonical "we lost the CA-DGS-IT-Services contract because Cal-CIO required GovRAMP Moderate verification" anti-pattern.
- **Pursuing US Defense Industrial Base (DIB) prime-or-sub-contractor relationships.** The DoD phased CMMC 2.0 implementation through 2024-2027: CMMC Level 1 (self-attested, 17 controls, 17 CFR-protected-information) for any DIB-contractor-handling-FCI; CMMC Level 2 (C3PAO-assessed, 110 controls aligned with NIST SP 800-171 Rev 3, SPRS-score-of-110) for any DIB-contractor-handling-CUI; CMMC Level 3 (DIBCAC-assessed, ~134 enhanced-security-requirements-aligned-with-NIST-SP-800-172) for DIB-programs-handling-critical-CUI (DIB-APL-programs). Missing CMMC Level 2 = contract-disqualification in DoD-solicitations-issued-after-Q4-2025. The canonical "we lost the Lockheed-Martin-F-35-sub-contract because LM-procurement-required-CMMC-Level-2-C3PAO-certification" anti-pattern.
- **Processing Controlled Unclassified Information (CUI) on behalf of any US-federal agency.** NIST SP 800-171 Rev 3 (the canonical CUI-protection standard, replaced Rev 2 May 2024) + DFARS 252.204-7012 (Safeguarding Covered Defense Information + Cyber-Incident-Reporting) + DFARS 252.204-7019 (NIST SP 800-171 DoD-Assessment-Requirements-notice) + DFARS 252.204-7020 (NIST SP 800-171 DoD-Assessments clause) + DFARS 252.204-7021 (CMMC-clause) all apply. SPRS-score-of-110 (perfect 110-out-of-110 on the 110 NIST SP 800-171 Rev 3 security-requirements) is the canonical DIB-procurement-floor for any CUI-handling DIB-contractor. The canonical "we have an SPRS-score-of-72 and we're locked out of every DoD-solicitation-issued-after-Q4-2025" anti-pattern.
- **Subject to Executive Order 14028 (Improving the Nation's Cybersecurity, May 2021)** + **OMB M-22-15 (Federal Zero-Trust-Strategy)** + **OMB M-24-15 (FedRAMP-Modernization-and-Authorization-Act-Implementation).** All federal agencies must migrate to Zero-Trust Architecture by FY27; all cloud-service-offerings handling federal-information must adopt Zero-Trust-principles; all FedRAMP-authorizations must migrate to FedRAMP-20x by 2028. Missing ZTA = contract-disqualification in federal-zero-trust-pilot-programs. The canonical "we lost the CISA-Continuous-Diagnostics-Mitigation-pilot because our IdP wasn't FedRAMP-Moderate" anti-pattern.
- **Cyber-insurance broker requires FedRAMP Moderate + CMMC Level 2 + NIST CSF 2.0 for renewal OR premium reduction.** Cyber-insurance premiums dropped 18-35% in 2024-2025 for FedRAMP-Moderate-authorized operators vs SOC-2-only operators. Brokers now require: FedRAMP Moderate + CMMC Level 2 + NIST CSF 2.0 OR equivalent-framework (ISO 27001 + ISO 27701 + ISO 27018 + SOC 2 Type II + ISO 42001).
- **CISO asks "where's our FedRAMP package + CMMC SSP + SPRS-score-of-110 + NIST 800-171 POAM?"** The canonical "we have a SOC 2 report + 47 PDFs in a Dropbox folder named 'FedRAMP' + an SPRS-score-of-72 with a 28-POAM-gap" anti-pattern. FedRAMP package must be: FedRAMP-Moderate-baseline-of-323-NIST-800-53-Rev-5-controls fully-implemented + SSP-documented + 3PAO-assessed + agency-ATO-issued + continuous-monitoring-active + POAM-tracked. CMMC Level 2 requires SPRS-score-of-110 + CMMC-C3PAO-assessment-passed + DIBCAC-acknowledged.
- **Pursuing a healthcare-public-sector expansion (CMS + ONC + VA + IHS + HHS + CDC + NIH + FDA-IT)** + **education-public-sector expansion (ED-FSA + NSF + DoEd-Grants + state-public-university-procurement)** + **financial-services-public-sector expansion (Treasury + CFPB + SEC + FDIC + OCC + Federal Reserve Banks + Farm Credit + Export-Import Bank + NCUA).** All these public-sector-verticals require FedRAMP Moderate + GovRAMP Moderate + NIST CSF 2.0 + FIPS-140-3-validated-cryptographic-modules as the canonical public-sector-cloud-service-offering-floor. Move #175 is the international ISMS; Move #176 is the **US-public-sector ISMS**.
- **An EU/APAC customer is a US-federal-government prime-contractor** (e.g. Siemens-Energy-US-Federal-Division + Thales-Defense-US + BAE-Systems-Inc + Leonardo-DRS + Rheinmetall-Defence-US). The EU/APAC prime requires FedRAMP Moderate + CMMC Level 2 from US-sub-contractors even though the parent company is ISO-27001-certified. Missing FedRAMP/CMMC = loss-of-US-federal-sub-contracting-eligibility.

## Common pitfalls (18 from real builds)

1. **Inheriting-from-a-FedRAMP-Low-CSP-when-the-system-is-FedRAMP-Moderate.** The first mistake operators make is deploying on a FedRAMP-Low (Class B in 2026 nomenclature) cloud-infrastructure-provider when the system is FedRAMP-Moderate (Class C). FedRAMP-Low-inheritance-only-covers-~156-controls; the operator must independently-implement the additional ~167-controls-needed-for-FedRAMP-Moderate-baseline-of-323-controls. **Fix:** Verify the FedRAMP-authorization-level of the chosen cloud-infrastructure-provider on the FedRAMP-Marketplace BEFORE-architecting-the-system. AWS-GovCloud-FedRAMP-High + Azure-Government-FedRAMP-High + GCP-Assured-Workloads-FedRAMP-Moderate-or-High + Oracle-Cloud-Government-FedRAMP-High + IBM-Cloud-for-Government-FedRAMP-High all inherit 35-45% of FedRAMP-Moderate-controls. AWS-Commercial-FedRAMP-Moderate + Azure-Commercial-FedRAMP-Moderate + GCP-Commercial-FedRAMP-Moderate + AWS-Standard + GCP-Standard + Azure-Standard do NOT-inherit FedRAMP-Moderate-controls. Use ONLY-FedRAMP-Moderate-or-High-cloud-infrastructure-providers for FedRAMP-Moderate-or-Higher-systems.
2. **CMMC-Level-2-Assessment-Scope-too-broad.** The second-most-common-mistake is including-too-many-systems in the CMMC-Assessment-Scope (every-developer-laptop + every-office-Wi-Fi-router + every-corporate-mobile-device + every-warehouse-handheld-scanner). SPRS-score-of-110-must-apply to the in-scope-boundary ONLY. **Fix:** Use the CMMC-Scope-Cutter + C3PAO-clarification-process to minimize scope to ONLY-systems-that-process-store-or-transmit-CUI + ONLY-systems-that-provide-security-protection-for-CUI-systems. Apply-Specialized-Asset-classes for Government-Furnished-Equipment + IoT + OT + Restricted-Information-Systems + Test-Equipment + Special-Equipment. Target: <50% of total-IT-environment in-scope. Capture the CMMC-Scope-Diagram-with-clear-boundary.
3. **SPRS-score-submitted-before-all-110-practices-are-implemented.** The third-most-common-mistake is submitting-SPRS-score-of-110-to-the-Supplier-Performance-Risk-System before all-110-practices-are-actually-implemented + verified-by-an-independent-C3PAO. SPRS-score-of-110-must-be-substantiated-by-evidence. If-the-C3PAO-finds-non-implemented-practices-during-the-CMMC-L2-assessment, the operator is subject to (a) CMMC-L2-certification-denial + (b) DFARS-252-204-7021-CMMC-clause-violation + (c) potential-False-Claims-Act-liability-($5k-$11k-per-false-claim + treble-damages). **Fix:** Submit-SPRS-score ONLY after all-110-practices-are-fully-implemented + verified + tested + captured-in-the-SSP + sample-tested-by-an-independent-readiness-3PAO. Use the SPRS-Score-Self-Assessment-Tool first.
4. **Not-having-an-agency-sponsor-or-PMO-path-resolved-before-starting-the-3PAO-engagement.** The fourth-most-common-mistake is starting-the-3PAO-engagement without first identifying-the-sponsoring-agency (for Agency-ATO-path) OR the PMO-review-path (for PMO-ATO-path). The Agency-AO-or-PMO-must-issue-the-ATO-letter; the 3PAO-cannot-issue-the-ATO-letter. **Fix:** Identify-the-sponsoring-agency FIRST (typically the federal-customer-who-is-the-first-federal-customer OR the agency-CIO-who-is-sponsoring-the-FedRAMP-package). If-no-agency-sponsor-available, use the PMO-Review-path which is open-to-all-providers-without-agency-sponsorship. Engage-the-3PAO AFTER-the-sponsoring-agency-or-PMO-path-is-resolved. Capture the Agency-Sponsorship-Letter-or-PMO-Review-Path-Confirmation-before-the-3PAO-readiness-assessment.
