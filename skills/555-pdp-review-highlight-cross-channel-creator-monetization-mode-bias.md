## Common pitfalls (15 from real builds)

1. **Treating CMM-tier as a one-hot label instead of a probabilistic distribution.** The bandit-arm picker's per-creator CMM-tier classification returns a probability distribution over the 4 tiers (CMM1 0.42 + CMM2 0.18 + CMM3 0.20 + CMM4 0.20) — using `argmax` instead of sampling from the distribution loses 8-12% conversion-lift per CaptivateA Creator Monetization Mode 2026 + CreatorIQ 2025. **Fix:** use Thompson sampling with the per-CMM-tier probability distribution as the prior, OR use a weighted reservoir sampler.

2. **Mixing CMM-tier with disclosure-mode-tier (DM-tier).** CMM-tier describes HOW the creator is paid (affiliate-link / promo-code / brand-deal-flat-fee / revenue-share); DM-tier describes the FTC + EU UCPD compliance disclosure style (#ad / #sponsored / credentials / reactivator). A CMM1 affiliate-link creator can use DM1 #ad-disclosure OR DM3 credentials-disclosure — they are orthogonal axes. **Fix:** keep CMM-tier × DM-tier as separate dimensions in the per-arm readback v15 schema, do not collapse them.

3. **Ignoring FTC + EU UCPD compliance on per-CMM-tier CTA copy.** CMM1 affiliate-link requires `#ad` + `#affiliate` + tracking-link-disclosure per FTC 16 CFR Part 255 + EU UCPD 2024 + UK CMA 2024. Writing a CTA copy without the compliance disclosure can result in FTC fines ($50,120 per violation per Postscript Compliance 2024) + EU UCPD enforcement + state-AG action + Lost trust from cohort. **Fix:** wire the `cmm-ftc-compliance.ts` checker into the bandit-arm picker and block any CTA copy that fails the per-CMM-tier compliance check.

4. **Confusing CMM-tier with creator-tier.** CMM-tier describes the monetization mode (affiliate-link / promo-code / brand-deal-flat-fee / revenue-share); creator-tier describes the follower-count-band (T1 nano 1k-10k + T2 mid 10k-50k + T3 mid 50k-500k + T4 macro 500k-1M + T5 niche 1M-5M + T6 celebrity 5M+ + T7 specialist + T8 micro-niche). A T1 nano creator can be CMM1 OR CMM2 OR CMM3 OR CMM4. **Fix:** keep CMM-tier × creator-tier as separate dimensions in the per-arm readback v15 schema.

5. **Hard-coding the per-CMM-tier review pool instead of biasing the bandit.** A common mistake is to hard-code the per-CMM-tier review pool (e.g. "CMM1 = LTK-pool only") which loses 15-25% conversion-lift because the operator's specific cohort may have higher affinity for a different vendor pool within CMM1 (e.g. Skimlinks-pool for Gen-Z tech cohort). **Fix:** use the `cmm-pool-picker.ts` which returns a probability distribution over the 27-vendor pool per CMM-tier × cohort × channel × creator-tier and sample from it.

6. **Treating CMM3 brand-deal-flat-fee as low-conversion because it has 1.15x ATC-rate.** CMM3 has the lowest ATC-rate of the 4 tiers, but CMM3 creators typically have 3-8x higher AOV per CaptivateA Creator Monetization Mode ROI 2026 + Aspire 2026 + Influencer Marketing Hub 2026 — the LTV contribution can be 1.4-1.8x CMM1's LTV contribution. **Fix:** always evaluate CMM-tier on cohort-LTV contribution, not raw ATC-rate.

7. **Missing per-CMM-tier × per-cohort-LTV cohort-affinity calibration.** CMM1 affiliate-link has 1.32x Gen-Z cohort-affinity but only 1.18x Boomer cohort-affinity; CMM3 brand-deal-flat-fee has 1.32x Boomer cohort-affinity but only 1.10x Gen-Z cohort-affinity. A bandit-arm picker without per-CMM-tier × per-cohort-LTV cohort-affinity calibration picks the wrong CMM-tier for the cohort. **Fix:** wire the cohort-affinity calibration into the bandit-arm picker.

8. **Forgetting to handle CMM-tier transitions (CMM1 → CMM2 → CMM4 over time).** Creators frequently transition between CMM-tier modes over time (e.g. a creator who starts as CMM1 affiliate-link can become CMM3 brand-deal-flat-fee after building audience). A bandit-arm picker that pins CMM-tier at signup time loses 10-18% conversion-lift per CaptivateA Creator Monetization Mode 2026 + CreatorIQ 2025. **Fix:** re-classify CMM-tier every 30 days using the LLM-judge ensemble.

9. **Not weighting CMM-tier × per-channel correctly.** CMM1 × email has 12.30% ATC-rate but CMM1 × SMS has 14.50% ATC-rate; CMM2 × email has 11.80% but CMM2 × push has 9.40%. A flat per-CMM-tier ATC-rate baseline loses 8-15% conversion-lift per channel. **Fix:** use the per-CMM-tier × per-channel ATC-rate matrix in the bandit-arm picker.

11. **Missing per-CMM-tier × per-daypart daypart-affinity calibration.** CMM1 × morning-commute = 1.22x daypart-affinity (commute-shoppers prefer link-only-CTA) vs CMM2 × lunch-break = 1.18x (lunch shoppers respond to code-first-CTA) vs CMM3 × evening-relax = 1.15x vs CMM4 × weekend-browse = 1.25x. A bandit-arm picker without per-daypart calibration loses 5-10% conversion-lift. **Fix:** wire the daypart-affinity calibration into the bandit-arm picker.

12. **Treating per-CMM-tier × per-creator-tier cross-axis as one-way (CMM-tier → creator-tier only).** The cross-axis is bi-directional: CMM1 × T8 micro-niche = link-only-with-LTK-micro-pool (high-fit), but T8 micro-niche × CMM2 = code-first-with-Refersion-micro-pool (low-fit). A bandit-arm picker that only considers CMM-tier → creator-tier direction loses 6-12% conversion-lift per CaptivateA Creator Monetization Mode 2026 + CreatorIQ 2025. **Fix:** implement the cross-axis as a bi-directional lookup table.

13. **Not handling the CMM-tier × per-cohort-LTV LTV-overlay correctly.** CMM1 × LTV-band-high = +$487 incremental LTV vs CMM2 × LTV-band-high = +$412 vs CMM3 × LTV-band-high = +$358 vs CMM4 × LTV-band-high = +$445 per CaptivateA Creator Monetization Mode ROI 2026 + Triple Whale Cohort 2026. A bandit-arm picker that doesn't apply the LTV-overlay picks the wrong CMM-tier for high-LTV cohorts. **Fix:** wire the LTV-overlay into the bandit-arm picker with the per-CMM-tier × per-LTV-band deltas.

14. **Forgetting to validate the per-CMM-tier × per-other-tier cross-axis correctness on synthetic fixtures.** A common bug is to ship the cross-axis validator without verifying it on synthetic test fixtures (e.g. CMM1 × CCF8 micro-niche should return link-only-with-LTK-Reels-pool, not branded-with-Aspire-pool). **Fix:** write the 56-test suite covering 14 cross-axis validators × 4 CMM-tier.

15. **Missing the per-CMM-tier attribution-decoder-quality-gate.** A CMM-tier classification with confidence <88% should NOT be used to bias the bandit arm picker — low-confidence classifications can be 30-50% wrong per CaptivateA Creator Monetization Mode Confidence Rubric 2026 + CreatorIQ 2025. **Fix:** wire the per-CMM-tier confidence-rubric gate (CMM1 ≥92% / CMM2 ≥90% / CMM3 ≥88% / CMM4 ≥91%) into the bandit-arm picker.
