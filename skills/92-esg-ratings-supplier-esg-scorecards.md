## The build (time estimate)

## Common pitfalls (18 from real builds)

1. **Cluster A — ship-without-materiality-assessment-and-call-it-engine.** Build the ESG-ratings-engine without the canonical **double-materiality assessment** (financial-materiality + impact-materiality per GRI-3 / ESRS-1 / SASB-materiality-map / ISSB-industry-based-standards). Result: Move #92 ships, dashboards render numbers, but the operator cannot tell if the GRI-topic that matters (e.g. Scope-3-Emissions for a $50M apparel DTC) is the SAME topic that the S&P-Global-CSA / Sustainalytics / MSCI analyst flagged. **Fix:** Pre-build (Week 0, 16 hr) **double-materiality-assessment + stakeholder-consultation + 10-15 priority-topics-mapping** gates the entire 16-week build. Use **GRI-3 material-topic-prioritization template** + **ESRS-1 + ESRS-2 double-materiality template** + **SASB-materiality-map lookup** + **ISSB-industry-based-standards lookup** for the operator's industry (Apparel-Accessories-2026 / Multiline-Specialty-Retailers-2026 / E-Commerce-2026 / Food-Retailers-2026). **Critical pitfall #2 sub-fix:** the materiality-assessment must be **financial-materiality (impact on enterprise-value) + impact-materiality (impact on people/planet)** — not just one of the two — and the **double-materiality-assessment must be re-done annually + on-event-triggered-basis** (every supply-chain-disruption, every major customer complaint, every regulatory change, every CDP-leaderboard-cycle).

2. **Cluster A — ship-without-ratings-platform-membership-and-call-it-disclosure.** Build the ESG-disclosure-engine without **active membership on MSCI-ESG-Ratings + Sustainalytics-ESG-Risk-Rating + S&P-Global-CSA + ISS-ESG + Bloomberg-ESG-Data + Refinitiv-ESG + FTSE-Russell-ESG + Ecovadis + Sedex-SMETA + amfori-BSCI + CDP + B-Corp + Higg-FEM + Textile-Exchange-MCI + Better-Cotton + Bluesign + ZDHC + OEKO-TEX + GOTS + GRS + RCS + Fairtrade + LWG**. Result: Move #92 ships, dashboards render, but the operator's **MSCI-ESG-Rating is BB** (because MSCI is using public data + 10-K/10-Q + press-releases + NGO-reports and not the operator's internal-data) AND the operator cannot dispute the rating because they have **no analyst relationship** with MSCI. **Fix:** Pre-build (Week 0, 8 hr) **ratings-platform-onboarding-baseline** + **analyst-relationship-establishment** + **analyst-rebuttal-process**. Pay **$25k-$120k/yr per platform** for the data-feed + analyst-access. Hire or contract **dedicated analyst capacity (1-2 FTE at $5M-$50M GMV, 4-8 FTE at $50M-$500M GMV)** for **questionnaire-completion + evidence-upload + analyst-rebuttal-cycle**. **Critical pitfall #2 sub-fix:** the **annual-rebuttal-cycle is mandatory** — every year when the MSCI-ESG-Rating / Sustainalytics-ESG-Risk-Rating / S&P-Global-CSA-Score / ISS-ESG-Prime-Status / Bloomberg-ESG-Data-Score / Refinitiv-ESG-Score / FTSE-Russell-ESG-Rating / Ecovadis-Medal / CDP-Climate-Score / B-Corp-Score comes out, the operator must run an **analyst-rebuttal** (2-5 page rebuttal + corrected data + supporting evidence) if the score is below the operator's target.

3. **Cluster A — ship-without-supplier-portal-and-call-it-supplier-ESG-scorecard.** Build the supplier-ESG-scorecard without **active supplier-portal-onboarding for every tier-1 supplier** (typically 100-500 suppliers for a $5M-$50M GMV DTC). Result: Move #92 ships, dashboards render, but **only 30-40% of tier-1 suppliers have completed the questionnaire** (the rest are skipped because the operator doesn't have an analyst + the supplier doesn't have a portal-account + the supplier doesn't speak English and the questionnaire is only in English). **Fix:** Pre-build (Week 0, 24 hr) **per-supplier portal-account + per-supplier questionnaire-completion + per-supplier evidence-upload + per-supplier audit-tracking**. Use **Ichia / SupplyShift / Avetta / Achilles / IntegrityNext / Coupa-Supplier-Management / SAP-Ariba-Supplier-Management** for **per-supplier onboarding + per-supplier questionnaire-completion + per-supplier evidence-upload + per-supplier audit-tracking**. **Critical pitfall #2 sub-fix:** the **supplier-onboarding-rate must be ≥95% of tier-1 suppliers** — anything below that, the operator's ESG-due-diligence-report is incomplete and the buyer (Walmart, Patagonia, H&M, etc.) can reject the report. **Critical pitfall #3 sub-fix:** the questionnaire must be **multi-language** (English + Chinese + Vietnamese + Indonesian + Hindi + Bengali + Tamil + Turkish + Portuguese + Spanish + Bengali at minimum for global supply chains).

4. **Cluster B — ship-without-third-party-assurance-and-call-it-disclosure.** Build the ESG-disclosure-engine without **third-party-assurance-statement** (limited assurance for FY 2024-2026, reasonable assurance for FY 2027+). Result: Move #92 ships, dashboards render, but the **Sustainability Report is unaudited** AND the **CSRD-filing is rejected** AND the **California-SB-253 + SB-261 disclosure is rejected** AND the **German-LkSG due-diligence-report is questioned** AND the **EU-CSDDD due-diligence-report is questioned**. **Fix:** Pre-build (Week 0, 16 hr) **third-party-assurance-provider-contracting** + **assurance-readiness-assessment**. Contract **Big-4 (Deloitte / PwC / EY / KPMG) + boutique-firms (ERM-CVS / Apex-Companies / RINA / Bureau-Veritas / SGS / TÜV-SÜD / TÜV-Rheinland / DNV / BSI / Control-Union)** for **limited assurance FY 2024-2026** + **reasonable assurance FY 2027+**.
