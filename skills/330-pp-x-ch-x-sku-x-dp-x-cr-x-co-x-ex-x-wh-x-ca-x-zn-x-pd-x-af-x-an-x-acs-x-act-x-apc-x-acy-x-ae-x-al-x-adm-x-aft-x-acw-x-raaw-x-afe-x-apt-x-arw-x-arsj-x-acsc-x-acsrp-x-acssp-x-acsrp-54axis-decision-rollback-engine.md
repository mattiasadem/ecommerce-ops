> Move #287.20 is the canonical **54-axis decision-rollback engine** that extends Move #287.19 (skill/329, per-affiliate-recovery-translation-state-suspension-procedure-jurisdictional-rule-restatement 53-axis) by adding the **Per-affiliate-recovery-translation-state-reinstatement-procedure-jurisdictional-rule-restatement** dimension — the canonical 54th axis per Move #329's "How to extend this skill" roadmap. State-reinstatement-procedure is structurally distinct from revocation (revocation = permanent/temporary license removal), from suspension (suspension = license-temporarily-withheld-with-restoration-procedure but no formal reinstatement-application), from collateral (collateral = dollar-amount-required-to-secure-license), from bond (bond = financial security instrument posted at license-issuance), from surety (surety = guarantor backing the bond), and from license (license = the right to operate).
