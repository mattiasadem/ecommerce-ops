## Common pitfalls (15 from real builds)

1. **Per-arm LTV attribution silently drifts when Triple Whale / Polar / Northbeam cohort-LTV-per-channel-per-dimension event stream is incomplete.** The most common pitfall in the per-arm readback v2 build: the operator wires the bandit's reward function to the per-arm LTV attribution, but the per-arm LTV attribution depends on the Triple Whale / Polar / Northbeam cohort-LTV-per-channel-per-dimension event stream being complete. If the event stream has gaps (e.g. cohort-C9 mobile-first + Tier-2 micro + TikTok DPA + DE-locale + D1 mobile + R2 mid-risk + V1 best-seller + S3 subscription-attach-with-flexible-skip → Triple Whale cohort-LTV-per-channel-per-dimension event stream only covers cohort C9 + email + D1 mobile + DE-locale, not the full 7-dimension hierarchy), the per-arm LTV attribution silently returns 0 for those arms, the bandit stops picking those arms, and the operator loses the incremental LTV without realizing why. Fix: build a per-dimension event-stream-coverage audit per cohort per channel per dimension per decay-window. The audit must catch "cohort-LTV-per-channel-per-dimension event stream has 0 events for arm X on cohort Y on channel Z on dimension W in decay-window D" and either backfill from mParticle / Segment CDP / Salesforce CDP / RudderStack / Hightouch / Census fallback event stream or fall back to the 7-dimension proxy-metric signal. Validate with a 5,000-arm canary deployment per cohort per channel per dimension per decay-window before rolling out to production.

2. **Per-arm LLM cost silently explodes when the LLM-judge-ensemble overhead is mis-priced.** The second most common pitfall: the operator wires the LLM-as-judge ensemble (Anthropic Claude 3.5 Sonnet + OpenAI GPT-4o + DeepMind Gemini 2.0 + custom-roberta-tone-resonance-classifier + custom-snippet-tone-validator) into the per-arm readback v2 without pricing the 13-dimension LLM-judge-ensemble cost. Each LLM-judge call is $0.003-$0.015 per dimension per arm, and the 13-dimension ensemble cost is $0.04-$0.20 per arm per decay-window. If the operator has 5,000-15,000+ arms per cohort per channel per decay-window, the LLM-judge-ensemble cost can reach $200-$3,000 per cohort per channel per decay-window, which is 10-100x the LLM-snippet cost. Fix: amortize the LLM-judge-ensemble cost across 1,000-10,000 arm impressions per cohort per channel per dimension. Build a per-arm LLM-judge-ensemble-cost-budget per cohort per channel per dimension per decay-window.
