## Common pitfalls (16 from real builds)

Mitigation: PRIMARY trigger = `Move #1.13.per_cohort_rollback_state_consistency_replay_emit.cohort_id == event.cohort_id AND platform_id == event.platform_id AND tier == event.tier AND replay_emit_id == event.replay_emit_id`; idempotency-key = `cohort_id + platform_id + tier + replay_emit_id + drift_window_seconds`.
