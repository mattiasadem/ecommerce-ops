## Common pitfalls (18 from real builds)

**P1. Treating social-search-traffic-source-cohort as a single "social-media" bucket instead of decomposing into the canonical 7-social-search-traffic-sources.** Real builds lump TikTok-search + Instagram-search + YouTube-search + Pinterest-search + Reddit-search + Snap-search + LinkedIn-search into a single "social-media" cohort and lose the per-source-leak-rate signal. The discriminator is completion-rate-band divergence: TikTok-search 55-70% vs Pinterest-search 70-82% is a 15-percentage-point spread that's invisible in the lumped view. Fix: enforce per-source-instrumentation at the social-bot-classifier layer; reject any cohort-aggregation that hides the 7-source granularity.

**P2. Using UTM-source as the sole social-search-traffic-source-detection signal.** Real builds rely on `utm_source=tiktok-search` alone, missing organic social-search-traffic-source-encounters where UTM is absent (Pinterest organic, YouTube organic, Reddit organic). Fix: deploy social-bot-user-agent-classifier as middleware on checkout-pixel; combine UTM + referrer-parser + UA-parser; reject single-signal detection.

**P3. Confusing social-search with social-ads.** Social-search = customer discovers via TikTok-search / Instagram-search / YouTube-search / Pinterest-search / Reddit-search / Snap-search / LinkedIn-search (organic or paid search-surface); social-ads = customer sees paid-creative via Meta-Ads / TikTok-Ads / Pinterest-Ads / Snap-Ads / LinkedIn-Ads in-feed. Move #3.9 covers social-search ONLY. Real builds conflate them and end up with `social-search-completion-rate` that mixes TikTok-search (organic discovery) with TikTok-Ads (paid creative) — different funnel behaviors. Fix: gate Move #3.9 instrumentation on social-search detection (UA-classifier + referrer + UTM combination); reject social-ads-only sources from the cohort.

**P4. social-search-citation-coverage-gap — operator assumes social-search traffic is high-quality but discovers citation-coverage is missing for Reddit-search / Snap-search / LinkedIn-search.** Real builds don't enable social-search-citation-tracking-engine (F1 + F2 + F3) and discover per-source citation-coverage-failure only after Triple-Whale-attribution-loop surfaces 35-50% Reddit-search leak-rate.
