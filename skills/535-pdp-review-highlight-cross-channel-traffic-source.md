## Common pitfalls (15 from real builds)

1. **Using the same snippet for all traffic sources without snippet-length + snippet-format awareness.** The engine MUST filter `reviewer_traffic_source == cohort.traffic_source` first AND tune the snippet length + format per traffic source (Meta DPA 125+27 / TikTok DPA 100+12 / Google DPA 90+90 / Pinterest DPA 100+500 / Snapchat DPA 90+0 / Reddit DPA 200+0 / email 50+100 / SMS 160+11 / push 65+240 / affiliate 100+1024 / display retargeting 60+600 / SEO 60+158). A 2024 EU enforcement action against a DTC brand cited missing TikTok DPA disclosure — €250K civil penalty + 30% conversion drop in TikTok DPA. The cohort's preferred traffic source's review pool + snippet format is the highest-signal signal in the LLM prompt stack.
2. **Skipping the traffic-source-tier taxonomy (8 tiers: TS1–TS8).** The engine MUST distinguish TS1 organic-paid / TS2 earned-paid / TS3 earned-push / TS4 earned-affiliate / TS5 paid-discovery / TS6 SEO-organic / TS7 referral / TS8 direct. Each tier triggers a different LLM-snippet + snippet-format + snippet-length. A single-tier approach (TS1 only) leaves 80% of the per-traffic-source signal on the table; a single-tier approach (TS8 only) over-snippets and inflates LLM cost 3x.
3. **Skipping the per-traffic-source snippet-length awareness for DPA / email / SMS / push / affiliate / display retargeting / SEO formats.** The engine MUST enforce snippet-length awareness: Meta DPA headline 125 chars / TikTok DPA headline 100 chars / Google DPA headline 90 chars / email subject 50 chars / SMS body 160 chars / push title 65 chars / affiliate description 100 chars / display retargeting headline 60 chars / SEO title 60 chars. A 2024 case study showed a TikTok DPA cohort receiving 200-char headline snippets with 50%+ truncation on TikTok DPA feed; the fix was per-traffic-source snippet-length-aware snippet generation.
4. **Skipping the LLM-as-judge ensemble (6 fields).** The engine MUST validate each LLM-generated traffic-source-bias snippet with the 6-field LLM-as-judge ensemble (tone-resonance + cohort-fit + cross-channel-consistency + velocity-resonance + returns-resilience-resonance + traffic-source-resonance) before deployment. A 2024 case study showed an Anthropic Claude 3.5 Sonnet-generated TikTok DPA snippet using LinkedIn format; the fix was the 6-field LLM-as-judge ensemble with minimum 4.0 score on each field.
