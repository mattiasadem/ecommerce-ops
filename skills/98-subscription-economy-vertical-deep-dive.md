## Common pitfalls (18 from real builds)

1. **Pitfall #1 — Using ONE billing-mechanics for ALL subscription-verticals (consumable + membership + rental + digital + B2B + regulated).** This is the canonical subscription-economy-vertical-engine anti-pattern. The cancellation-flow for a consumable subscribe-and-save brand (price / value / convenience / product-fit / shipping / seasonal / competitor / life-event reason-tree + 50%-off winback + pause-skip-swap-downgrade) is COMPLETELY different from the cancellation-flow for a B2B-SaaS brand (budget-cut / stakeholder-change / value-mismatch / feature-mismatch / competitor / contract-renewal reason-tree + 90-day-extension + multi-seat-downgrade + annual-renewal-discount + custom-invoice-billing-mechanics). **Fix:** Deploy Move #5.6 per-vertical cancellation-flow-orchestrator with 6 distinct per-vertical reason-trees + per-vertical save-actions. Operators shipping a single horizontal cancellation-flow across all 6 verticals are misdiagnosing per-vertical churn drivers and losing 30-50% of potential save-rate per vertical.

2. **Pitfall #2 — No per-vertical dunning-engine (single horizontal 11-stage smart-retry across all verticals).** The dunning cadence for a consumable brand (day-1 / day-3 / day-5 / day-7 / day-10 / day-14 / day-21 / day-28 / day-35 / day-45 / day-60 with 50%-off winback at day-7) is COMPLETELY different from the dunning cadence for a B2B brand (day-3 / day-7 / day-14 / day-21 / day-30 with custom-invoice-reissue + AR-team-outreach + procurement-team-outreach at day-14) which is COMPLETELY different from the dunning cadence for a regulated brand (day-1 / day-3 / day-7 / day-14 / day-21 / day-30 / day-45 with regulatory-compliance-pause + age-reverification at day-7). **Fix:** Deploy Move #5.6 per-vertical dunning-engine with 6 distinct per-vertical cadences + per-vertical winback-offers.
