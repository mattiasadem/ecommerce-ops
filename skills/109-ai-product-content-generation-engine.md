## Common pitfalls (18 from real builds)

1. **Brand-voice-anchor not configured.** The most common Path B failure — the operator installs Jasper Business $499/mo + AirOps $399/mo and runs the per-SKU AI description templates WITHOUT configuring the brand-voice-anchor, the AI defaults to "we are passionate about delivering the highest quality products to our customers" boilerplate, the brand-voice-match-score falls to 5-6/10, and the content-team rejects every AI-block as "sounds like a robot." **Fix:** configure the 5-voice profile (F2/H3/BN2/P2/O3 friendly / F4/H1/BN3/P4/O2 luxury / F3/H2/BN2/P3/O3 sustainable / F1/H4/BN1/P1/O2 gen-z / F4/H1/BN3/P3/O3 B2B) with 50-100 brand-voice-anchor-examples per voice-profile BEFORE running the per-SKU AI description templates; the brand-voice-match-score must reach ≥8/10 on the canonical Move #20.7 brand-voice benchmark before any per-SKU AI content-block ships to publish.
2. **PIM-attribute-source not wired.** The second most common Path B failure — the operator runs the per-SKU AI description templates but the templates pull from manual-spreadsheet-input OR Google-Forms-input OR Notion-doc-input instead of the Move #26 PIM attribute-source (Akeneo / Salsify / Plytix), the AI content-block uses stale attributes (e.g. "available in 5 colors" when the SKU actually has 12 colors), and the marketplace-listing-rejection-rate spikes to 15-30%. **Fix:** wire every per-SKU AI description template to the canonical Move #26 PIM attribute-source (per-SKU features + per-SKU benefits + per-SKU specifications + per-SKU materials + per-SKU dimensions + per-SKU weight + per-SKU color-options + per-SKU size-options + per-SKU use-cases + per-SKU differentiators); the canonical Move #26 PIM-attribute-injection-correct is a hard prerequisite to Gate A verification.
3. **Cohort-overlay variants not generated.** The third most common Path B failure — the operator runs per-SKU AI description + per-SKU AI bullet-pack + per-SKU AI title + per-SKU AI marketplace copy but does NOT generate per-cohort-overlay variants (per-cohort-LTV-tier / per-cohort-RFM-tier / per-cohort-VIP-tier / per-cohort-subscription-tier / per-cohort-channel-tier / per-cohort-device-tier / per-cohort-traffic-source-tier / per-cohort-buyer-stage), so the email-block-3-variants-per-cohort default does not ship, and Move #61 personalization-engine cannot overlay the per-SKU-content-block on the per-customer-cohort. **Fix:** configure the per-SKU AI cohort-message-copy templates with 12-15 cohort-overlay variants per canonical Move #61 personalization-substrate; the per-SKU-cohort-content-variant-count must reach ≥8 variants per canonical Path B benchmark before any Klaviyo / Postscript / Iterable / Braze email-campaign ships.
4. **Marketplace-listing-rejection-rate not monitored.** The fourth most common Path B failure — the operator runs per-SKU AI marketplace-copy with the canonical Amazon title + bullet-points + long-description templates but does NOT monitor the marketplace-listing-rejection-rate in the Amazon Seller Central + Walmart Seller Center + Target Plus + TikTok Shop partner-API, so Amazon rejects 15-30% of bullet-pack-submissions due to prohibited-words (e.g. "best", "#1", "guaranteed") and the SKU goes into suppressed-listing-status for 7-14 days. **Fix:** wire the canonical Move #85 trade-compliance-operations + Move #69 product-compliance + Move #46 promotional-calendar-discount-strategy guardrails into the per-SKU AI marketplace-copy templates; the marketplace-listing-rejection-rate must stay <2% per canonical Path B benchmark.
