## Common pitfalls

1. **No per-vertical-network-onboarding-pack.** Operators launch Sephora Media Network or Ulta Beauty Media or Kroger Precision Marketing or Home Depot Mediator or Best Buy Ads without a per-vertical-network-onboarding-pack. Each vertical-network has unique onboarding requirements (Sephora-Media-Network-Beauty-Insider-API-key + Ulta-Beauty-Collective-cohort-tag-overlay + CVS-Media-Exchange-CPG-vertical-knowledge-overlay + Kroger-Precision-Marketing-grocery-vertical-knowledge-overlay + Home-Depot-Mediator-home-improvement-vertical-knowledge-overlay + Best-Buy-For-Business-B2B-overlay + PetSmart-Media-Network-VIP-overlay). **Fix:** Build per-vertical-network-onboarding-pack-template BEFORE launch (Sephora + Ulta + CVS + Walgreens + Kroger + Instacart + Costco + Albertsons + Home Depot + Lowe's + Ace + Best Buy + Target + Walmart + PetSmart + Petco + Chewy) with API-key-onboarding-coverage + cohort-overlay-onboarding-coverage + vertical-knowledge-onboarding-coverage.

2. **No per-vertical-cohort-LTV-overlay (90/180/365-day).** Operators use one-size-fits-all-cohort-LTV for all vertical-networks. The reality: beauty Sephora-Media-Network-Beauty-Insider-cohort-LTV-90-day differs from grocery Kroger-84-51-cohort-LTV-90-day. **Fix:** per-vertical-cohort-LTV-overlay with vertical-90/180/365-day-cohort-LTV and vertical-networks-cohort-LTV-overlay.

3. **Wrong per-vertical-keyword-research.** Reusing Amazon-keywords for Sephora-Media-Network or Ulta-Beauty-Media or CVS-Media-Exchange or Home-Depot-Mediator. Each vertical-network has unique keyword universe (Sephora: beauty-ingredient + beauty-shade-range + beauty-clean-beauty / Ulta: beauty-mass + beauty-occasion / CVS: CPG-vertical-knowledge + Rx-coverage / Home Depot: home-improvement-DIY + home-improvement-pro-contractor). **Fix:** per-vertical-keyword-research with vertical-brand-defensive-keyword-set + vertical-competitor-product-targeting-keyword-set + vertical-in-market-shoppers-keyword-set + vertical-lifestyle-contextual-keyword-set + vertical-keyword-set-volume-benchmark.

4. **No per-vertical-DSP-launch.** Operators use Amazon-DSP + Walmart-Connect-DSP without per-vertical-DSP-launch. The reality: beauty-Sephora-vertical-DSP-CPM differs from grocery-Kroger-vertical-DSP-CPM. **Fix:** per-vertical-DSP-launch with per-vertical-DSP-budget-allocation-rule (portfolio-share-percent × per-vertical-DSP-CPM × per-vertical-cohort-LTV-per-dollar × per-vertical-monthly-budget-tolerance-band).

5. **No per-vertical-DSP-Halo-defense-creative-asset-build.** Operators launch per-vertical-DSP without per-vertical-DSP-Halo-defense-creative-asset-build. The DSP layer needs 5–10 creative-asset-patterns per vertical-network (beauty-shade-range-inclusive-creative + beauty-clean-beauty-creative + grocery-meal-planning-creative + grocery-budget-meal-creative + home-improvement-DIY-creative + home-improvement-pro-contractor-creative + consumer-electronics-tech-spec-creative + pet-first-time-pet-owner-creative + apparel-occasion-driven-creative + footwear-athletic-creative + jewelry-engagement-creative). **Fix:** Build 5–10 per-vertical-creative-patterns BEFORE DSP-launch.

6. **No per-vertical-attribution-merge-recipe.** Operators run Amazon-Attribution + Walmart-Connect-attribution without per-vertical-attribution-merge. Each vertical-network has unique attribution-API (Sephora-Beauty-Insider + Ulta-Collective + CVS-Caremark + Kroger-84-51 + Home-Depot-Pro + Lowe's-For-Pros + Best-Buy-For-Business + PetSmart-VIP). **Fix:** per-vertical-attribution-merge-recipe with per-vertical-attribution-API + per-vertical-Amazon-Marketing-Cloud-equivalent-cohort-queries + per-vertical-cohort-LTV-overlay.

7. **No per-vertical-creative-asset-specs.** Operators use Amazon-Sponsored-Products-banner-specs (1200x300) for Sephora-Media-Network-banner (300x250) or Ulta-Beauty-Media-banner (300x250) or CVS-Media-Exchange-banner (300x250). Each vertical-network has different creative-specs + different aspect-ratios + different text-limits. **Fix:** per-vertical-creative-asset-specs-template (Sephora + Ulta + CVS + Walgreens + Kroger + Instacart + Costco + Albertsons + Home Depot + Lowe's + Ace + Best Buy + Target + Walmart + PetSmart + Petco + Chewy + Nordstrom + TJX + Nike + Foot Locker + Jared + Tiffany + Brilliant Earth + Pandora + Etsy + Poshmark) with aspect-ratio + text-limit + animation-supported flags.

8. **No per-vertical-Halo-defense-creative-pattern-categories.** Operators launch per-vertical-DSP without per-vertical-Halo-defense-creative-pattern-categories. The DSP layer needs vertical-specific Halo-defense-creative-pattern-categories (beauty-shade-range-inclusive + beauty-clean-beauty + grocery-meal-planning + grocery-budget-meal + home-improvement-DIY + home-improvement-pro-contractor + consumer-electronics-tech-spec + pet-first-time-pet-owner + apparel-occasion-driven + footwear-athletic + jewelry-engagement). **Fix:** Build per-vertical-Halo-defense-creative-pattern-categories BEFORE vertical-DSP-launch.

9. **No per-vertical-portfolio-budget-allocation-rule.** Operators launch multiple vertical-networks without per-vertical-portfolio-budget-allocation-rule. The reality: beauty-vertical-network budget is different from grocery-vertical-network budget. **Fix:** per-vertical-portfolio-budget-allocation-rule (per-vertical-GMV-target-share + per-vertical-cohort-LTV-per-dollar-target + per-vertical-DSP-CPM-target + per-vertical-monthly-budget-tolerance-band).

10. **No per-vertical-CPC-vs-DSP-CPM-trading-rule.** Operators run vertical-CPC-and-vertical-DSP-CPM blind. The reality: vertical-CPC may be cheaper than vertical-DSP-CPM, requiring budget-shift. **Fix:** per-vertical-CPC-vs-DSP-CPM-trading-rule (per-vertical-CPC-is-cheaper-than-DSP-CPM-then-shift-budget-from-DSP-to-CPC + per-vertical-DSP-CPM-is-cheaper-than-CPC-then-shift-budget-from-CPC-to-DSP + per-vertical-CPC-and-DSP-CPM-are-equal-then-hold-budget-and-test-new-vertical-network).

11. **No per-vertical-bid-automation.** Operators manually manage vertical-bids without per-vertical-bid-automation (Amazon-Ads-Console-AI-bid + Walmart-Connect-AI-bid + Pacvue-managed-service-bid + Tinuiti-managed-service-bid + Helium-10-managed-service-bid + Perpetua-managed-service-bid). **Fix:** per-vertical-bid-automation with per-vertical-AI-bid-rule.

12. **No per-vertical-real-time-dashboard.** Operators check per-vertical-ACoS weekly but not daily. The canonical failure: a vertical-network-exploit (competitor-bomb + keyword-bid-spike) inflates per-vertical-ACoS 5× in 24 hours; weekly check catches it 6 days late. **Fix:** per-vertical-real-time-dashboard (Triple-Whale-vertical-cohort-LTV-dashboard + Polar-vertical + Northbeam-vertical + per-vertical-Amazon-Marketing-Cloud-vertical-cohort-overlay-dashboard) with per-vertical-cohort-LTV-drop-threshold + per-vertical-DSP-CPM-spike-threshold + per-vertical-budget-pacing-alert + per-vertical-Halo-defense-rate-drop-threshold.

18. **No per-vertical-cohort-LTV-dashboard.** Operators check per-vertical-cohort-LTV monthly but not weekly. The canonical failure: a vertical-cohort-LTV-drop is invisible at monthly cadence. **Fix:** per-vertical-cohort-LTV-dashboard (Triple-Whale-vertical-cohort-LTV-dashboard + Polar-vertical + Northbeam-vertical + per-vertical-Amazon-Marketing-Cloud-vertical-cohort-overlay-dashboard + Looker-Vertical-Dashboard + Mode-Analytics-Vertical-Dashboard + Metabase-Vertical-Dashboard) with per-vertical-cohort-LTV-drop-threshold + per-vertical-cohort-LTV-spike-detection + per-vertical-cohort-LTV-trend-overlay.
