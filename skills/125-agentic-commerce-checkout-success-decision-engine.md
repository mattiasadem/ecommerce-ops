## Common pitfalls (18 from real builds)

Each pitfall below is a real failure mode that has shown up in 2026 agentic-commerce-checkout-success-decision-engine builds across Stripe + OpenAI + Microsoft + Google + Perplexity + Amazon + Walmart + Adyen + PayPal + Mastercard + Visa + Amex + Cloudflare + AWS WAF + Akamai + Imperva + DataDome + PerimeterX + Kasada + Anthropic-MCP customers. Each pitfall has a concrete corrective `Fix:` line that an operator can apply in <60 minutes without re-architecting.

1. **Treating agentic-cart-init-drop as a "checkout-conversion" problem instead of a per-step × per-failure-mode × per-cohort × per-LTV-overlay decision-engine problem.** The canonical mistake is to send the per-cart-init × per-channel × per-cohort failed-cart-attempts to a single human-CS-queue instead of routing each failed-cart-attempt to the canonical per-step × per-failure-mode retry-policy-decision-tree. The cost is 30-50% of recoverable agentic-cart-init-revenue (typically $200k-$1.2M/yr at $5M GMV) is lost because Step 1 WAF-block retry-rate is 5%, Step 2 endpoint-404 retry-rate is 30%, Step 4 payment-handler-unregistered retry-rate is 60%, but the human-CS-queue doesn't know which retry-policy to apply. **Fix:** wire a canonical per-step × per-failure-mode retry-policy-decision-tree into the per-cart-init failed-attempts-router so each failed-cart-attempt is auto-routed to the canonical retry-policy (retry-now / retry-after-15-min / retry-after-1-hour / refund-credit-card / escalate-to-human-CS / rollback-to-fallback-payment-handler / auto-revive-on-fix-completion).
2. **Implementing Step 1 WAF-allowlist as a one-time setup instead of a per-cart-init × per-channel × per-time-window × per-decision-actor continuous-validation-decision-engine.** The canonical mistake is to set the canonical Cloudflare Bot Allowlist for ChatGPT-User / GPTBot / OAI-SearchBot / Perplexity-User / Microsoft-Copilot-Bot / Google-Extended / Amazon-Alexa-Bot / Walmart-Sparky-Bot once during Move #124 Step 1 onboarding and never re-validate. The cost is 20-40% of cart-inits fail at Step 1 within 30-90 days because the canonical user-agent-strings change (e.g. OpenAI ships GPTBot/1.2 with new user-agent-string, the legacy allowlist doesn't match). **Fix:** wire a canonical per-cart-init × per-channel × per-time-window × per-decision-actor Step-1-WAF-allowlist-validator that runs every 15-min and auto-revalidates each canonical user-agent-string against the canonical Cloudflare Bot Allowlist / AWS WAF / Akamai / Imperva / DataDome / PerimeterX / Kasada WAF-rules.
