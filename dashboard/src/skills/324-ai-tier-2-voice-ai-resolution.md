# AI tier-2 voice-AI agentic-resolution

> Move #20.5 is the canonical **inbound voice-call tier-2 agentic-resolution engine** that sits BESIDE Move #20.2 (skill/321 ai-tier-2-customer-service-deflection, ticket-text/email-channel) and Move #20.4 (skill/323 ai-tier-3-voice-ai-proactive-customer-success, outbound voice-AI-proactive-call). Move #20.5 handles the **voice-channel inbound tier-2 tickets** — the 25-35% of inbound DTC customer requests that arrive via phone call (vs Move #20.2's email/text/SMS channel): voice-call-driven returns/exchanges (10-15% of all calls), voice-call-driven warranty/defect claims (4-7%), voice-call-driven sizing/fit disputes (3-6%), voice-call-driven billing disputes + subscription-cancellation (3-5%), voice-call-driven shipping-damage + lost-package claims (2-4%), and the "voice-AI-agentic-resolution" cases where the customer expects the voice-AI to **actually resolve the issue end-to-end during the call** (issue refund, generate return label, escalate to human if policy-blocked) rather than transfer them to email/text. Built on **5 layers**: (Layer 1) **inbound-voice-call-routing + intent-classifier** — when the customer calls the operator's voice-number (Twilio-Flex / Aircall / RingCentral / Dialpad-AI / Genesys / NICE-inContact / Five9 / Amazon-Connect), the call is routed to the voice-AI-tier-2-orchestrator (Regal/PolyAI/Balto/Vapi/Retell-AI/Bland-AI rendered via OpenAI-Realtime-API / Anthropic-Claude-Voice / Google-Gemini-Live-API / ElevenLabs-Conversational-AI); the voice-AI classifies the inbound-call into 12 tier-2-intents (return/exchange/warranty/sizing-fit/billing-dispute/subscription-cancel/shipping-damage/lost-package/wrong-item/defective-item/chargeback/address-change) via GPT-4o / Claude-Voice / Gemini-Live with low-temperature (0.1) + structured-output + per-intent-confidence-threshold (≥0.85 to auto-route, 0.5-0.85 to AI-assist-human, <0.5 to human-only); (Layer 2) **per-intent-voice-deflection-engine** — each of the 12 intents has its own dedicated voice-channel-deflection workflow: voice-driven-returns → Loop/ReturnGO API self-serve-portal-confirmation-during-call + return-label-generated-during-call; voice-driven-exchanges → Loop Exchange Incentive + per-customer-size-preference-from-True-Fit + variant-lookup-during-call; voice-driven-warranty → image-vision-defect-classifier (customer-uploads-photo-via-SMS-during-call) + auto-approve-RMA-under-$50-or-escalate-during-call; voice-driven-billing-dispute → Stripe-refund-API-confirmation-during-call + dispute-evidence-packet-pre-staged; voice-driven-shipping-damage → Loop-photo-evidence-collection-during-call + carrier-claim-API-call + auto-route-refund/exchange/reorder-by-value-during-call; voice-driven-subscription-cancel → Recharge-pause-API-call + save-offer-rendered-via-voice + customer-confirms-pause-during-call; (Layer 3) **voice-AI-agentic-resolution-layer** — the voice-AI doesn't just answer during the call, it takes the action IN-REAL-TIME: calls Loop API to generate the return label (customer receives via email-during-call + voice-AI-confirms), calls Stripe API to issue the refund (refund-receipt-read-back-to-customer-during-call), calls Recharge API to pause the subscription (pause-confirmation-read-back-to-customer-during-call), closes Gorgias ticket-with-resolution-summary during the call (so the customer never has to follow up via email), triggers Triple Whale tier-2-touch-attribution (so the touch is attributed to cohort-LTV in real-time); (Layer 4) **voice-AI-policy-engine + escalation-ladder** — 7-tier escalation-ladder (T0 voicemail-no-call / T1 voice-AI-call-with-AI-rendered-script / T2 voice-AI-call-with-real-time-coaching-via-Balto / T3 voice-AI-call-with-senior-human-coaching-via-Balto-QA-listening / T4 voice-AI-call-with-manager-on-call-listening / T5 voice-AI-call-with-senior-human-takeover-mid-call / T6 voice-AI-call-with-manager-takeover-mid-call / T7 senior-human-direct-call-with-no-voice-AI-layer); per-tier-2-cost-aware-deflection-overlay (voice-AI-call-cost $0.47-$1.40/call vs Move #20.2-tier-2-cost-per-resolution $3-$7/ticket — voice-AI is cheaper for high-LTV-customers, more expensive for low-LTV); per-cohort-LTV-aware-save-offer-policy (high-LTV ≥$1,200 = 8%-of-LTV-cap, mid-LTV $400-$1,200 = 6%-of-LTV-cap, low-LTV <$400 = 4%-of-LTV-cap); per-state-call-recording-consent-and-compliance (CA requires-all-party-consent, FL requires-one-party-consent); fallback-to-Move-#20.2-when-voice-AI-ineffective (call-resolution-rate <25% OR voicemail-rate-spike >40%); (Layer 5) **voice-AI-tier-2-attribution-loop + per-customer-LTV-aware-action-execution-loop** — Triple Whale voice-AI-call-attribution (every voice-AI-call is attributed to per-customer-touch-attribution-feed) + per-customer-voice-AI-call-cost-attribution-via-Move-#40-financial-operations-unit-economics + voice-AI-call-vs-Move-#20.2-tier-2-email-default-resolution-rate-comparison (voice-AI 35-55% in-call-resolution vs Move #20.2 email 55-70% email-resolution-rate — voice-AI is lower per-call but faster and preferred by high-LTV-customers) + voice-AI-call-cohort-segmentation-by-tier-2-intent + voice-AI-call-real-time-dashboard-monitoring + voice-AI-call-monthly-board-pack-and-rollback-decision.
