## Common pitfalls (15 from real builds)

**P1 — 8-store-state-collapsed-into-single-open-store-state.** Most operators ship one "store-state-flag" boolean and call it done. Discriminator: ask "what's the per-store-state conversion-rate?" — if the answer is a single number across all store-states, the 8-store-state taxonomy is collapsed.
