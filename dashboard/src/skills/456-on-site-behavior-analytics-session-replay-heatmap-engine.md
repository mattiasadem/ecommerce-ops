## When to use this skill

Use this skill when the operator has shipped the canonical CRO substrate (Move #1 cart-abandon + Move #3 checkout-audit + Move #4 welcome-series + Move #6 Triple-Whale-attribution + Move #9 mobile-PDP-redesign) AND is doing ≥$100k GMV AND ≥25k sessions/wk AND has **>15% checkout-completion-rate gap to top-quartile** (the canonical "we run Triple Whale + GA4 but we cannot explain WHY users abandon at the shipping-step" anti-pattern per Hotjar 2024 + Microsoft Clarity 2024 + FullStory 2024 + LogRocket 2024 + PostHog 2024 + Mixpanel 2024 + Amplitude 2024 + Heap 2024 + Triple Whale 2024 + Klaviyo 2024 benchmarks showing behavior-analytics-equipped operators close 30-60% of conversion leaks that no analytics-based routes can find) OR has **>40% cart-abandon rate unexplained** (the canonical "Triple Whale says we have 60% cart-abandon rate but we cannot see what they do in the cart-step" anti-pattern) OR has **>30% PDP-bounce rate with no mobile UI heatmap** (the canonical "we know our mobile CVR is 1.8% but we don't know where users are rage-clicking on the mobile PDP" anti-pattern) OR has **>5% checkout-funnel-drop-off at the shipping-step with no replay-evidence** (the canonical "we lost 40% of checkout-funnel users at the shipping-step and we don't know if it's the country-dropdown-broken OR the address-validation-UX-broken OR the form-field-count-too-high" anti-pattern) OR has **>20% form-abandon rate on email-capture with no form-analytics** (the canonical "we have 80% email-capture-form-abandon rate and we don't know which field they're failing on" anti-pattern per Mouseflow 2024 + Inspectlet 2024 + Hotjar form-analytics 2024 benchmarks showing behavior-analytics operators ship 1-click email-capture at >50% capture-rate vs the canonical 5-15% capture-rate of the no-analytics operators).

You have:

- **A Shopify (or Ikas / BigCommerce / WooCommerce / Headless) store** with admin API access + Theme API + Customer API + Cart API + Checkout API + Webhooks API + ≥25k sessions/wk (the canonical threshold for behavior-analytics ROI to break-even on Hotjar Plus $39-$89/mo OR Microsoft Clarity free OR FullStory Business $369/mo).
- **Triple Whale (Move #6) OR Polar Analytics installed and producing daily per-cohort-LTV overlay** — Move #10.5 reads Move #6's per-cohort-LTV + per-traffic-source + per-device-cohort + per-customer-LTV to overlay behavior-analytics-funnel against Move #6's revenue-overlay. Without Move #6 upstream, Move #10.5 produces "I see the funnel-funnel but we don't know which cohort drives revenue" output and the operator is back to guessing-where-the-leaks-are.
- **Klaviyo Email installed with at least 1 active flow** — Move #10.5 reads Klaviyo's per-customer-cohort + per-engagement-score to identify the canonical 4-VIP-cohort (top 10% LTV + 5+ purchases + email-open-rate >40% + Klaviyo-engagement-score >80) and overlay behavior-analytics-funnel per VIP-cohort vs non-VIP-cohort. Without Klaviyo upstream, Move #10.5 produces "I see the funnel-funnel but we don't know who's a VIP" output.
- **A staging theme + 4-week launch window** — Move #10.5 ships the canonical 12-page heatmap-setup + 6-page replay-record + 4-funnel-overlay during a 4-week build with the operator on-call during the 4-hour install-window per Heatmap-tool + the 24-hour replay-record-window per Session-replay-tool. Without a staging theme, Move #10.5 ships to production directly and risks breaking the live-store with the Heatmap-script-injection.
- **2-4 hr/wk operator time during the 4-week setup window + 1 hr/wk ongoing** — the canonical Move #10.5 setup is 2-4 hr/wk for 4 weeks (~30 hours of threshold-time at $100/hr loading) + 1 hr/wk ongoing for the canonical weekly behavior-analytics review (review 10 replay-recordings per week + 1 heatmap-segment per week + 1 funnel-overlay per week + 1 survey-result review per week).
- **Engineer availability for JS-injection + script-tag + webhook-subscriber setup** OR a Shopify-app-supported Marketing partner (Hotjar + Microsoft Clarity + FullStory + LogRocket + PostHog all have 1-click Shopify-app installs + Google Tag Manager container + Shopify-Pixels theme integration); without engineer or 1-click app, Move #10.5 requires 4-8 hr of engineer time during the 4-week setup window.

You do NOT have:

- **A session-replay tool installed and producing replay-segmented recordings** (the canonical "Triple Whale + GA4 say we have 60% cart-abandon rate but we cannot see what they do in the cart-step" anti-pattern).
- **A heatmap tool installed and producing heatmap-segmented scrollmaps + click-maps** (the canonical "we know our mobile CVR is 1.8% but we don't know where users are rage-clicking on the mobile PDP" anti-pattern).
- **A funnel-analysis tool installed and producing per-cohort-funnel + per-traffic-source-funnel + per-device-funnel** (the canonical "we cannot build a per-cohort overage funnel because Mixpanel + Amplitude are not installed" anti-pattern).
- **A form-analytics tool installed and producing per-field-form-abandon + per-field-form-friction** (the canonical "we have 80% email-capture-form-abandon rate and we don't know which field they're failing on" anti-pattern).
- **An on-site survey + feedback-widget installed** (the canonical "Triple Whale says our NPS is 4.2 but we don't know WHY they would recommend OR wouldn't recommend" anti-pattern).
- **A weekly behavior-analytics review cadence** (the canonical "we install Hotjar + FullStory but we never review the recordings so the $2000-tool costs don't generate ROI" anti-pattern).
