# Per-cohort PDP review-highlight cross-channel LLM-generated snippet

> Move #47.5.1.1.1.2 — a per-cohort × per-channel LLM-generated review snippet (OpenAI / Anthropic / Cohere / Llama 3.1 / Mistral Large / DeepSeek / AI21) that the multi-arm bandit (from Move #47.5.1.1.1.1 / skill/530) automatically picks as the winning arm, generating 50–160 char per-channel snippets from each cohort's top-3 reviews, and lifting per-cohort per-channel snippet CTR another 15–35% on top of the bandit picker while reducing A/B test cycle time from 7 days to 3 days.

## When to use this skill

Use this skill when ANY of the following is true:

- the operator has shipped Move #47.5.1.1.1.1 / skill/530 (per-cohort cross-channel multi-arm bandit picker) AND wants to expand the per-cohort per-channel arm space with LLM-generated challengers (1–2 challenger arms per cohort per channel per week);
- the operator has shipped Move #47.5.1.1.1 / skill/529 (per-cohort cross-channel export) AND the static picker (top-3 reviews by `cohort_LTV_weight × cohort_fit × verified_buyer × recency`) is leaving 15–35% per-cohort per-channel snippet CTR on the table because the cohort's preferred tone, length, and resonance is not always captured by deterministic top-3 selection;
- the operator wants per-cohort per-channel snippets in 16+ locales (de-DE, en-US, en-GB, fr-FR, es-ES, it-IT, nl-NL, pl-PL, pt-BR, ja-JP, ko-KR, zh-CN, zh-TW, ar-AE, tr-TR, sv-SE) without manually authoring 16×14×7 = 1,568 snippet variants — the LLM does it from each cohort's top-3 reviews;
- the operator wants per-cohort per-channel snippet variants tuned for email-subject-line vs email-body vs SMS (160 char) vs push-notification (60 char) vs DPA-headline (40 char) vs DPA-body (90 char) vs affiliate-creative (125 char) vs display-headline (30 char) — each channel has different length, tone, and CTA conventions, and a single static snippet cannot satisfy all of them;
- the operator has a thin review pool per cohort per PDP (< 50 reviews per cohort per PDP) and needs to augment the snippet pool with LLM-paraphrased variants while preserving the original review's verified-buyer attribution and cohort-fit score;
- the operator is running a 7-day A/B test per cohort per channel and the cohort's snippet preference drifts mid-test (LLM re-generates the challenger with new tone / length / CTA every 7 days to keep the arm space fresh);
- the operator wants to optimize MULTIPLE KPIs simultaneously (snippet CTR + ATC CVR + AOV + 90-day LTV + returns rate + spam-filter precision + cross-channel consistency + LLM-judge-tone-resonance + LLM-judge-cohort-fit) without metric seesaw;
- the operator needs cross-channel snippet consistency with per-cohort per-channel LLM-generated variants × multi-objective bandit × hierarchical bandit rollup × cold-start + privacy + attribution guard;
- the operator needs LLM-friendly vendor / experimentation integration with Eppo / Kameleoon / Optimizely / Monetate / VWO / Statsig / AB Tasty / Adobe Target / LaunchDarkly / GrowthBook / Split.io + LLM provider (OpenAI / Anthropic / Cohere / Mistral / DeepSeek / AI21 / Llama) + warehouse-native bandit computation (Snowflake, BigQuery, Databricks, Redshift).

Do NOT use this skill when:

- the operator has not yet shipped Move #47.5.1.1.1.1 (per-cohort cross-channel multi-arm bandit picker) — the LLM-generated snippet needs the bandit as its `arm space` picker;
- the operator has not yet shipped Move #47.5.1.1 (per-cohort PDP review-highlight) — the LLM needs the static picker + cohort-LTV-weighted + cohort-fit top-3 as its input seed;
- the operator has not yet shipped Move #47.5.1.1.1 (per-cohort cross-channel export) — the LLM needs the per-channel snippet picker to expand;
- the operator has < 50 reviews per cohort per PDP — the LLM seed is too thin to generate high-quality snippets;
- the operator is in a regulated vertical (FTC + state-AG enforcement on LLM-generated review snippets without verified-buyer attribution) — verified-buyer + cohort-fit guardrail is mandatory; LLM is a challenger only, never replaces verified-buyer top-3;
- the operator is in a market with strict GDPR / CCPA / LGPD / PIPEDA / CNIL / ICO + state-AG LLM disclosure rules (Italy 2025 AGCOM, France 2024 CNIL AI guidance) — LLM disclosure banner is mandatory per channel;
- the operator is optimizing a single-channel snippet (no cross-channel dimension) — use Move #47.5.1.1 / skill/528 alone or Move #47.5.1.1.1 / skill/529 with a smaller cohort × channel matrix.

## Common pitfalls (15 from real builds)

1. **Pitfall — The LLM-generated snippet drops the verified-buyer attribution and the cohort's trust-score collapses.** Per FTC 2024 + state-AG 2024 enforcement on LLM-generated review snippets without verified-buyer attribution: a LLM-generated snippet that says "Customers love this product" without the verified-buyer name + photo + helpful_count attribution is a deceptive practice. **Fix:** enforce verified_buyer_attribution in the LLM output schema (L7 of the 7-layer prompt stack); reject any LLM-generated snippet without the original reviewer's name + verified_buyer flag + photo_count + helpful_count; add a per-cohort per-channel trust-score floor (≥0.85) as a guardrail; the LLM is a challenger only, never replaces verified-buyer top-3.

2. **Pitfall — The LLM-generated snippet has the wrong tone for the cohort (e.g. casual tone for a luxury cohort, formal tone for a Gen-Z cohort, salesy tone for a discount-driven cohort).** Per McKinsey 2024 + BCG 2024 + Accenture 2024: cohort-aware tone is the single highest-impact snippet lever, and LLM-generated snippets without cohort-aware prompting default to a generic tone. **Fix:** add L6 (cohort-aware prompt extension) to the 7-layer prompt stack with explicit cohort-tone preferences ("this snippet will be shown to {cohort} who are {cohort-LTV-tier}, prefer {tone_1} tone over {tone_2}, suppress {suppression_pattern}"); LLM-judge-tone-resonance per snippet (Anthropic Claude 3.5 Sonnet or GPT-4o) with per-cohort per-channel LLM-judge-tone-resonance floor (≥0.7); per-cohort per-channel LLM-judge-cohort-fit floor (≥0.7).

3. **Pitfall — The LLM-generated snippet exceeds the per-channel length spec (e.g. 200 char snippet for a 60 char push notification, 500 char snippet for a 160 char SMS).** Per Klaviyo 2026 + Postscript 2026 + OneSignal 2026 + Meta 2026 + TikTok 2026 + Google Ads 2026: each channel has hard length limits, and a snippet that exceeds the limit is truncated or rejected. **Fix:** enforce length_compliance in the LLM output schema (L4 + L7 of the 7-layer prompt stack); reject any LLM-generated snippet that exceeds the per-channel length spec (email-subject-line ≤60 char, email-body 50–160 char, SMS 160 char, push-notification 60 char, DPA-headline 40 char, DPA-body 90 char, affiliate-creative 125 char, display-headline 30 char); add a per-cohort per-channel length-compliance guardrail (≥99%).

4. **Pitfall — The LLM-generated snippet breaks cross-channel snippet consistency (snippet A on email + snippet B on SMS + snippet C on DPA).** Per Move #47.5.1.1.1 / skill/529 + Move #47.5.1.1.1.1 / skill/530: cross-channel consistency is a top-3 guardrail, and LLM-generated snippets without cross-channel rollup can break it. **Fix:** add LLM-judge-cross-channel-consistency per snippet (Anthropic Claude 3.5 Sonnet or GPT-4o) with per-cohort per-channel LLM-judge-cross-channel-consistency floor (≥0.7); hierarchical bandit rollup (per-cohort bandit → per-channel bandit → cross-channel rollup per Storytel 2025) with LLM strategy-as-arm (cohort-AI / cohort-AI-Claude / cohort-AI-Mistral / cohort-AI-Cohere / cohort-cross-channel-rollup) ensures the cross-channel winner propagates.

5. **Pitfall — The LLM-generated snippet triggers GDPR / CCPA / LGPD / PIPEDA / CNIL / ICO + state-AG + EU AI Act disclosure violations (no LLM disclosure banner, missing consent gating, unverified automated decision-making).** Per Italy 2025 AGCOM + France 2024 CNIL AI guidance + EU AI Act 2024/2026 + GDPR Art. 22 + CCPA + LGPD + PIPEDA: LLM-generated review snippets are subject to AI disclosure rules, and a snippet without the LLM disclosure banner is a violation. **Fix:** add LLM disclosure banner per channel ("This snippet was generated by AI" or "Personalized for you by AI") per Italy 2025 AGCOM + France 2024 CNIL AI guidance + EU AI Act 2024/2026; GDPR Art. 22 right-to-explanation for automated decision-making (per-cohort per-channel AI opt-out link); CCPA / LGPD / PIPEDA right-to-opt-out of automated decision-making; consent-token propagation per channel × per cohort.

6. **Pitfall — The LLM-generated snippet has a hallucinated product claim not in the original review (e.g. the LLM adds "This product lasted me 5 years" when the review never said that).** Per Anthropic 2026 + OpenAI 2026 + DeepMind 2024: LLMs hallucinate, and a LLM-generated snippet with a fabricated product claim is a deceptive practice (FTC 2024 + state-AG 2024). **Fix:** enforce source-fidelity in the LLM output schema (every claim in the snippet must reference a specific claim in the original review); reject any LLM-generated snippet with hallucinated claims via Move #109 generative-AI engine + RAG-grounded generation; LLM-as-judge source-fidelity scoring (Anthropic Claude 3.5 Sonnet or GPT-4o) with per-cohort per-channel source-fidelity floor (≥0.95).

7. **Pitfall — The LLM-generated snippet is in the wrong locale (English snippet shown to a de-DE cohort, or machine-translated snippet with low translation quality).** Per DeepL 2026 + Google Translate 2026 + Anthropic 2026 + OpenAI 2026: machine translation quality varies by locale, and a poorly-translated snippet damages the cohort's trust-score. **Fix:** enforce locale_compliance in the LLM output schema; use locale-specific LLM provider (Anthropic Claude 3.5 Sonnet for ja-JP + ko-KR + zh-CN + zh-TW, Cohere Command R+ for ar-AE + tr-TR + sv-SE, Mistral Large 2 for nl-NL + pt-BR + it-IT, OpenAI GPT-4o for en-US + de-DE + fr-FR + es-ES); DeepL / Google Translate / Claude / GPT-4o translation quality scoring for thin-pool locales with per-locale translation quality floor (≥0.85 LLM-judge); reject any LLM-generated snippet below the per-locale translation quality floor.

8. **Pitfall — The LLM-generated snippet degrades 90-day LTV by optimizing for short-term CTR.** The canonical "metric seesaw" anti-pattern (snippet CTR up but 90-day LTV down) is documented in Anthropic 2026 + OpenAI 2026 + Kameleoon 2026. **Fix:** encode all KPIs in the BanditLP reward (snippet CTR + ATC CVR + AOV + 90-day LTV + returns rate + spam-filter precision + cross-channel consistency + deliverability + frequency-cap + consent + LLM-judge-tone-resonance + LLM-judge-cohort-fit + LLM-judge-cross-channel-consistency + LLM cost); per-cohort per-channel guardrails (margin floor, AOV floor, returns-rate ceiling); 30-day window for returns rate + 90-day window for cohort-LTV; always-valid p-values via sequential testing (mSPRT / Always Valid Inference / anytime-valid confidence sequences per Howard et al. 2021).

9. **Pitfall — The LLM cost per 1k impressions balloons and the operator exceeds the LLM budget.** Per OpenAI 2026 + Anthropic 2026 + Cohere 2026 + Mistral Large 2026: LLM cost is per-token, and a per-cohort per-channel LLM arm space with 294–490 LLM-generated arms × 14 cohorts × 7 channels = 28,826–49,000 LLM calls per 7-day refresh can quickly exceed budget. **Fix:** per-cohort per-channel LLM cost tiering ($0.40–$4.00 tiered by cohort-LTV-tier: anonymous cold-start = free LLM tier + Llama 3.1 8B self-hosted / new visitor = GPT-4o-mini / VIP = Claude 3.5 Sonnet); LLM cost per 1k impressions as a guardrail; budget alerts at 80% of monthly budget; cache LLM-generated snippets in the per-cohort per-channel snippet cache (1,568 cached variants per cohort × channel × locale × tone); DeepSeek V3 for cost-sensitive cache-hit ($0.14/1M cache-hit).

10. **Pitfall — The LLM-generated snippet is rejected by spam filter (high spam-filter precision score but actual spam-filter rejection rate spikes).** Per Litmus 2026 + Return Path 2026 + Validity 2026 + Twilio 2026: spam-filter precision proxy and actual spam-filter rejection rate diverge, and a LLM-generated snippet that passes the proxy but fails the actual filter damages inbox-placement. **Fix:** monitor actual spam-filter rejection rate per cohort per channel (Litmus / Return Path / Validity / Twilio inbox-placement ≥0.85); set per-cohort per-channel spam-filter-precision floor (≥0.95 for new-visitor cohort, ≥0.99 for VIP cohort) on actual rejection rate; back-off LLM generation frequency if rejection rate exceeds the floor; A/B test LLM-generated snippets with a 10% holdout per cohort per channel to measure actual spam-filter rejection rate.

11. **Pitfall — The LLM provider changes its API (deprecates a model, changes pricing, has an outage) and the per-cohort per-channel LLM arm space collapses.** Per OpenAI 2026 + Anthropic 2026 + Cohere 2026 + Mistral Large 2026 + DeepSeek 2026: LLM provider API stability varies, and a single-provider dependency is a single point of failure. **Fix:** multi-provider fallback chain (OpenAI → Anthropic → Cohere → Mistral → DeepSeek → AI21 → Llama self-hosted) per Move #109 generative-AI engine; per-cohort per-channel LLM provider selection with provider-health monitoring (OpenAI status page + Anthropic status page + Cohere status page + Mistral status page + DeepSeek status page); cache LLM-generated snippets for 7 days to absorb provider outages; budget guardrail ensures the fallback chain doesn't exceed budget.

12. **Pitfall — The LLM-generated snippet has the wrong CTA (e.g. "Buy Now" for a browse-abandoner cohort, "Learn More" for a high-AOV cohort, "Subscribe" for a one-time-purchase cohort).** Per Klaviyo 2026 + Postscript 2026 + Meta 2026 + TikTok 2026 + Google Ads 2026: CTA is the second-highest-impact snippet lever after tone, and a misaligned CTA damages the cohort's CVR. **Fix:** add CTA-specific cohort prompt extension ("prefer {cta_1} CTA over {cta_2} for {cohort}"); LLM-judge-CTA-fit per snippet (Anthropic Claude 3.5 Sonnet or GPT-4o) with per-cohort per-channel LLM-judge-CTA-fit floor (≥0.7); per-cohort CTA matrix (VIP = "Shop the Collection" / high-AOV = "Explore the Lineup" / browse-abandoner = "Pick Up Where You Left Off" / discount-driven = "Unlock Your Discount" / lapsed = "We've Saved Your Favorites").

13. **Pitfall — The LLM-generated snippet is in English for a non-English locale (locale-leak anti-pattern).** Per Klaviyo 2026 + Postscript 2026 + Iterable 2026 + Customer.io 2026 + Meta 2026 + TikTok 2026 + Google Ads 2026: locale-leak damages the cohort's trust-score and triggers GDPR Art. 5 + CCPA + LGPD + PIPEDA data-quality violations. **Fix:** enforce locale_compliance in the LLM output schema (L5 of the 7-layer prompt stack); reject any LLM-generated snippet that doesn't match the cohort's locale; per-locale LLM provider selection (Anthropic Claude 3.5 Sonnet for ja-JP + ko-KR + zh-CN + zh-TW, Cohere Command R+ for ar-AE + tr-TR + sv-SE, Mistral Large 2 for nl-NL + pt-BR + it-IT, OpenAI GPT-4o for en-US + de-DE + fr-FR + es-ES); DeepL / Google Translate / Claude / GPT-4o translation quality scoring with per-locale translation quality floor (≥0.85 LLM-judge).

14. **Pitfall — The LLM-generated snippet is locked onto a static winner and the cohort's preference drifts (LLM-staleness anti-pattern).** Per Anthropic 2026 + OpenAI 2026 + Kameleoon 2026: a LLM-generated snippet that wins at week 1 may lose at week 4 as the cohort's preference drifts toward a new tone / CTA / length. **Fix:** LLM challenger arm refresh at 7-day windows (1–2 new LLM-generated challengers per cohort per channel per week); re-warm new challengers with uniform 5–10% exploration for first 1,000 impressions; per-cohort per-channel LLM-judge-tone-resonance drift monitor (alert if the winning snippet's LLM-judge-tone-resonance drops below the per-cohort per-channel floor); weekly per-cohort per-channel LLM arm space refresh with new prompt seeds.
