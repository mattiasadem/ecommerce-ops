## When to use this skill

**Use this skill when the operator has shipped Move #11 (subscription-replenishment) ≥180 days AND Move #14.2 (post-charge dunning) ≥90 days AND Move #14.2.1 (AI failure prediction) ≥60 days AND Move #14.2.2 (cross-border dunning) ≥30 days AND Move #14.2.3 (voluntary-churn prevention + cancellation save-flow) shipped ≥60 days AND Move #14.2.4 (winback-discount-ladder) shipped ≥30 days AND is running a subscription-BOX brand (BarkBox / FabFitFun / Birchbox / Stitch Fix / Cratejoy / Bespoke Post / Quarterly.co / Decocrated / Kid Curate / Frank & Evelyn style with multi-product unboxing) AND is observing that voluntary churn (customer clicks cancel + completes cancellation) accounts for ≥60% of monthly subscriber churn AND the operator wants to lift winback-after-cancellation-rate from the baseline 5–12% (post-discount-only Move #14.2.4) to the best-in-class 25–38% (post-Move #14.2.4 + curated-discovery) AND wants to convert would-be permanent cancellations into resubscribed subscribers via per-customer-curated-product-suggestion.** Curated-discovery-engine is structurally distinct from Move #14.2's post-charge dunning (which fires AFTER the charge fails), from Move #14.2.1's AI failure prediction (which fires BEFORE the charge attempts), from Move #14.2.3's voluntary-churn-prevention + cancellation save-flow (which fires at the cancel-click moment), from Move #14.2.4's winback-discount-ladder (which fires on cancelled subscribers with discount-ladder-only). Move #14.2.5 fires in the 1–90 days AFTER the cancellation completes via winback-after-cancellation-curated-discovery-flow + per-customer-curated-product-suggestion-engine + lifestyle-DNA-onboarding-quiz + surprise-and-delight unboxing tier + per-customer-product-discovery-attribution + Triple Whale cohort-LTV feedback-loop + post-unboxing-feedback-collector. Move #14.2.5 is the **curated-discovery-engine layer** — the operator should only initiate it when ALL of the following are true:

You have:
- **Shopify (or Ikas / BigCommerce / WooCommerce / headless) DTC subscription-BOX store** with admin API access AND a subscription-box app with multi-product-curation + lifestyle-quiz-onboarding + cancellation-flow + discount-code + winback-flow support (BarkBox / FabFitFun / Birchbox / Stitch Fix / Cratejoy / Bespoke Post / Quarterly.co / Decocrated / Kid Curate / Frank & Evelyn / Loop Subscriptions / Subbly / Recharge / Stay AI / Skio / Bold Subscriptions / Chargebee / Recurly / Stripe Billing).
- **≥300 active subscribers AND ≥$30k MRR / ≥$360k ARR** with at least 60+ days of recurring-billing history AND a subscription-BOX product catalog of ≥12 SKUs (baseline-curated + premium-tier + wildcard-tier + founder-tier mix) — below these thresholds, the curated-discovery-engine subscriber base is too thin to amortize the platform-fee overhead; deferred manual curation + ad-hoc discount-codes suffice without a custom build.
- **Move #11 (subscription-replenishment) shipped ≥180 days** AND a baseline MRR-dashboard exists (Recharge Analytics / ProfitWell / Baremetrics / Stripe Sigma / Triple Whale) AND a baseline subscription-box-cycle-dashboard exists (Cratejoy / Bespoke Post analytics / Loop Subscriptions) — without a baseline, the operator cannot measure curated-discovery-rate OR attribute resubscribed MRR to specific curated-product-suggestions.
- **Move #14.2 (post-charge dunning) shipped ≥90 days** AND ≥3 baseline Klaviyo segments defined (active_subscriber / past_due_subscriber / cancelled_subscriber / at_risk_subscriber / paused_subscriber / skip_next_cycle_subscriber / winback_target_subscriber / high_ltv_cancelled_subscriber / lifestyle_dna_cluster_<6>).
- **Move #14.2.1 (AI failure prediction) shipped ≥60 days** AND the failure-risk-scoring-engine is fed voluntary-cancel-flow-survey data — without this, Move #14.2.5 cannot target the `high_intent_voluntary_churn` segment (cancelled subscribers with above-median pre-cancel engagement + LTV) BEFORE the curated-product-suggestion fires.
- **Move #14.2.2 (cross-border dunning) shipped ≥30 days** (only required for brands with ≥10% non-US subscribers) AND ≥6 baseline Klaviyo segments including per-currency and per-language segments AND per-locale-curated-discovery-tone-of-voice — the cross-border curated-discovery-rules depend on Move #14.2.2's per-locale copy substrate.
- **Move #14.2.3 (voluntary-churn prevention + cancellation save-flow) shipped ≥60 days** AND ≥6 baseline cancel-flow-survey reasons captured (too_expensive / not_using_enough / product_not_working / switching_to_competitor / moving / temporary_break / duplicate_order / gift_expiration / prefer_one_time_purchase / other) AND ≥60 days of cancel-flow-survey data — the curated-discovery-engine depends on Move #14.2.3's cancel-flow-survey as the data substrate.
- **Move #14.2.4 (winback-discount-ladder) shipped ≥30 days** AND ≥60 days of Move #14.2.4 winback-discount-ladder history exists — without Move #14.2.4 history, the curated-discovery-engine cannot layer per-customer-curated-product-suggestion ON TOP OF Move #14.2.4's per-cancel-reason-discount-engine + 3-step-discount-ladder.
- **Triple Whale cohort-LTV signal exists** OR equivalent (Recharge Analytics LTV / ProfitWell LTV / Baremetrics LTV) — the cancelled-subscriber-curated-product-suggestion for high-LTV cancelled subscribers depends on Triple Whale cohort-LTV to identify above-median LTV cancelled subscribers.
- **Documented lifestyle-DNA-onboarding-quiz decision** — quiz-length (10-question vs 5-question vs 15-question), cluster-mapping (6-cluster vs 4-cluster vs 8-cluster), surprise-tier-mix (60/20/10/10 vs 50/25/15/10 vs 40/30/20/10), feedback-collector-layer (5-emoji / 5-radio / 5-NPS) — without this, the operator is reacting to cancellations one at a time without a curated-discovery-engine.
