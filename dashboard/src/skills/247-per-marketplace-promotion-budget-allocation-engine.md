## Common pitfalls (17 from real builds)

1. **No per-marketplace weekly-promo-budget-split.** Operating promo-by-spreadsheet means each marketplace gets a different budget-spend-rule, different per-promo-mechanic ROI is invisible, and the operator cannot re-allocate from low-ROI mechanics to high-ROI mechanics. **Fix:** Pillar 1 build in Phase 2 — wire the per-marketplace weekly-promo-budget-allocator in Pacvue / Perpetua / Helium 10 / Tinuiti / AMC and the per-promo-mechanic-budget-re-allocator. **Impact:** 25-45pp gap in per-promo-mechanic ROI surface + 15-30% wasted promo-budget-spend.

2. **No per-promo-mechanic ROI cohort.** Running Amazon Deals + Lightning Deals + Coupons + Subscribe-and-Save-discount + Walmart Rollbacks + Target Circle Offers + Instacart Promo + Best Buy Deal-of-the-Day + TikTok Shop Flash-Sale all at the same default-discount-depth with no per-promo-mechanic ROI measurement means the operator cannot identify which mechanics are 6:1–24:1 ROI (Subscribe-and-Save-discount + Brand-Tailored-Promotions + Instacart Brand Boost + Kroger Boost) vs 2:1–8:1 ROI (Lightning Deals + Clearance + Best Buy Deal-of-the-Day + TikTok Shop Flash-Sale). **Fix:** Pillar 2 build in Phase 2 — wire the per-promo-mechanic-ROI-cohort in Pacvue / Perpetua / AMC / Triple Whale / Walmart Connect / Instacart Ads. **Impact:** 18-32% wasted promo-budget-spend + 5-12pp gap in net-ROI.

3. **No promotion-stacking-engine.** Operating with each marketplace's default-stacking-rules means the brand cannot enforce that Amazon Coupons DO NOT stack with Amazon Prime-Exclusive-Discounts but DO stack with Subscribe-and-Save-discount, OR that Target Circle Offers DO stack with Target Plus-Member-Offers but DO NOT stack with Target Deal-of-the-Day. **Fix:** Pillar 3 build in Phase 3 — wire the promotion-stacking-engine that enforces documented stacking-rules per marketplace + the promotion-margin-cap that auto-pauses any promo-mechanic when promo-margin falls below the documented floor. **Impact:** 8-18% margin-erosion from accidental over-stacking + 12-22% missed incremental-GMV from under-stacking.

4. **No per-vertical promotion-elasticity-model.** Treating all verticals the same means a beauty brand runs 25%-off Lightning Deals on luxury perfume (where elasticity is 0.6-1.2× and the customer is full-price-driven) the same as 25%-off Lightning Deals on grocery snacks (where elasticity is 1.8-3.4× and the customer is promo-driven). **Fix:** Pillar 4 build in Phase 3 — wire the per-vertical-promotion-elasticity-model that quantifies vertical-specific elasticity (luxury 0.6-1.2×, grocery 1.8-3.4×, apparel 1.6-2.8×, etc.) and the per-SKU-promotion-eligibility-rotator that re-evaluates each SKU's promo-eligibility weekly. **Impact:** 12-22% missed incremental-GMV + 8-15% wasted promo-budget-spend.
