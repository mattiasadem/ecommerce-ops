## Common pitfalls (15 from real builds)

1. **Move #47.4.1-without-Klaviyo-Segment** — the operator builds Move #47.4.1 email-merchandising-rule A/B testing but does NOT wire Klaviyo Segment + Klaviyo On-Site Behavior + Klaviyo Cohort Sync + Klaviyo CDP — without these, the email-merchandising-rule A/B tests run on the FULL email-list rather than per-cohort, and the A/B test results are dominated by the LTV-mid cohort's email-engagement patterns rather than the LTV-high / VIP / loyalty-tier cohorts. Fix: deploy Klaviyo Segment + Klaviyo On-Site Behavior + Klaviyo Cohort Sync + Klaviyo CDP BEFORE running any email-merchandising-rule A/B test.

2. **Move #47.4.1-without-Triple-Whale-Cohort** — the operator builds Move #47.4.1 email-merchandising-rule A/B testing but does NOT wire Triple Whale Cohort + Triple Whale Attribution + Triple Whale Experimentation — without these, the email-merchandising-rule-CVR-vs-LTV-overlay is invisible and the operator can't tell whether their email-merchandising-rule A/B test lifts CVR but LIFTS low-LTV-cohort-CVR (i.e., is a CAC-payback-increasing variant) or lifts high-LTV-cohort-CVR (i.e., is a CAC-payback-decreasing variant). Fix: deploy Triple Whale Cohort + Triple Whale Attribution + Triple Whale Experimentation as the cohort-LTV-overlay substrate.
