## Common pitfalls

1. **No per-SKU competitor-set-definition.** Operators launch Prisync or Competera or Price2Spy or Wiser or Minderest without per-SKU competitor-set-definition. Each SKU has unique competitor-set (per-SKU direct-competitor-set + per-SKU indirect-competitor-set + per-SKU aspirational-competitor-set + per-SKU-budget-competitor-set + per-SKU-MAP-authorized-reseller-set + per-SKU-marketplace-Amazon-competitor-set + per-SKU-marketplace-Walmart-competitor-set + per-SKU-marketplace-Target-competitor-set + per-SKU-marketplace-Shopify-DTC-competitor-set + per-SKU-marketplace-eBay-competitor-set + per-SKU-marketplace-Etsy-competitor-set + per-SKU-marketplace-TikTok-Shop-competitor-set + per-SKU-marketplace-Wayfair-competitor-set + per-SKU-marketplace-Home-Depot-competitor-set + per-SKU-marketplace-Lowe's-competitor-set + per-SKU-marketplace-Best-Buy-competitor-set + per-SKU-marketplace-Costco-competitor-set + per-SKU-marketplace-Sephora-competitor-set + per-SKU-marketplace-Ulta-competitor-set + per-SKU-marketplace-Kroger-competitor-set + per-SKU-marketplace-Instacart-competitor-set). **Fix:** Build per-SKU-competitor-set-definition BEFORE Prisync/Competera/Price2Spy/Wiser/Minderest launch.

2. **No per-SKU-MAP-policy-publication.** Operators launch per-SKU-MAP-violation-detection without per-SKU-MAP-policy-publication. The MAP-policy-document must be distributed to all resellers + marketplaces + DTC-channel + legal-team + sales-team BEFORE violation-detection has legal-grounds. **Fix:** per-SKU-MAP-policy-publication-distribution-to-resellers + per-SKU-MAP-policy-publication-distribution-to-marketplaces + per-SKU-MAP-policy-publication-distribution-to-DTC-channel + per-SKU-MAP-policy-violation-consequences-clause + per-SKU-MAP-policy-update-cadence-annual BEFORE violation-detection-launch.
