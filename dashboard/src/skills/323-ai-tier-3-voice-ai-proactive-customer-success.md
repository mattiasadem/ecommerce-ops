# AI tier-3 voice-AI proactive customer success

> Move #20.4 is the canonical **voice-channel-proactive layer** that sits ON TOP of Move #20.3 (skill/322 ai-tier-3-proactive-customer-success, tier-3 multi-channel proactive-cadence defaulting to email-SMS-push) and routes the **high-LTV / voice-preferring / declining-engagement cohort** through a dedicated **voice-AI proactive-call** instead of email/SMS/push. Move #20.4 detects 4 signals that Move #20.3 cannot see: (Signal 1) **per-customer-voice-channel-preference** — inferred from past inbound-call-history (call-history on file with Gorgias/Kustomer/Zendesk, Twilio-Flex call-detail-records, Aircall/RingCentral/Dialpad call-logs), past voicemail-leave-rate, past inbound-call-resolution-rate (if customer calls instead of emails/SMSes, they prefer voice); (Signal 2) **per-customer-engagement-decline-by-channel** — customer historically engaged with email (open-rate ≥40%, click-rate ≥5%) but email-engagement has declined ≥60% over 14 days AND SMS-engagement has declined ≥50% AND push-engagement has declined ≥70% (the email/SMS/push channels are saturated; voice is the only remaining high-attention channel); (Signal 3) **per-customer-LTV-tier** — high-LTV (24-month-predicted-LTV ≥$1,200) + declining + voice-preferring = voice-AI-proactive-call is the canonical tier-3 channel; (Signal 4) **per-customer-time-zone + calling-window-compliance** — voice-AI-call must respect per-customer local-time-zone + per-customer TCPA-prior-express-consent (US/CA) + per-customer calling-window-hours (08:00-20:00 local per FCC-TCPA-rules) + per-customer DNC-list-status (US DNC-list scrub via DNC.com scrubber API + per-state DNC-list). When all 4 signals align, Move #20.4 fires a **Balto/Regal/PolyAI voice-AI proactive-call** rendered via OpenAI-Realtime-API / Anthropic-Claude-3.5-Sonnet-Voice / Google-Gemini-Live-API / ElevenLabs-Conversational-AI / Vapi/Retell-AI/Bland-AI / Twilio-Flex-Voice. The 5 layers: (Layer 1) **voice-channel-preference-detector** — 4-signal-detector-set (voice-channel-preference + channel-engagement-decline + LTV-tier + time-zone-calling-window) with a canonical voice-channel-floor (all 4 signals positive = voice-channel-trigger); (Layer 2) **voice-AI-proactive-call-orchestrator** — routes through Balto (real-time-coaching) / Regal (outbound-voice-AI) / PolyAI (conversational-voice-AI) / Vapi/Retell-AI/Bland-AI (LLM-voice-agents) / Twilio-Flex + custom-LLM-Voice-Stack, calibrated by per-customer voice-AI-call-frequency (max 1 proactive-voice-call per 30 days per customer, max 3 per lifetime per customer per TCPA-consent + brand-tone) + per-customer voice-AI-call-cost-ceiling ($0.40-$1.20/call vs SMS $0.04-$0.08, voice = 10x SMS cost but 5-8x higher save-rate) + per-cohort-LTV-tier escalation (high-LTV → voice-AI-call default, mid-LTV → voice-AI-call-if-email-engagement-decline, low-LTV → email/SMS/push only); (Layer 3) **voice-AI-rendered-per-customer-intervention** — GPT-4o / Claude 3.5 Sonnet / Gemini-2.0-Flash-Live renders the proactive voice-AI-message in the customer's brand-voice (F/H/BN/P/O profile per `assets/02-brand-voice.md`) + customer's per-cohort-tone (VIP-tier-formal vs gen-z-casual) + customer's prior-engagement-style + customer's last-touch-product + customer's prior-resolution-summary (voice-AI references the prior ticket if any: "Hi Sarah, this is Maya from Kreis Studio following up on the German-learning-carousel question you filed last week...") + customer's prior-call-record (Gorgias-call-detail-record) to skip-already-asked-questions; (Layer 4) **voice-AI-policy-engine + escalation-ladder** — every voice-AI-proactive-call is gated by a per-customer per-channel policy-engine (TCPA-prior-express-consent required for US/CA, DNC-list scrubbed per FCC-rules, calling-window 08:00-20:00 local, max 1-call-per-30-days-per-customer, max 3-calls-per-lifetime-per-customer, voicemail-detection with Polite-Decline-If-Voicemail + callback-number-leave per FCC-rules, language-detection with multilingual-voice-AI-pivot to customer-preferred-language per Move #26 native-language-voice-profiles) + a 7-tier escalation-ladder (T0 monitor-only-no-voice, T1 voice-AI-call-with-AI-rendered-script, T2 voice-AI-call-with-real-time-coaching via Balto, T3 voice-AI-call-with-senior-human-coaching via Balto-quality-assurance, T4 voice-AI-call-with-manager-on-call-listening, T5 voice-AI-call-with-senior-human-takeover-mid-call, T6 voice-AI-call-with-manager-takeover-mid-call, T7 senior-human-direct-call with no voice-AI layer); (Layer 5) **voice-AI-attribution-loop + per-cohort-LTV-aware-save-offer-via-voice** — every voice-AI-proactive-call is attributed to a per-cohort-LTV-model (voice-AI-call-cost = $0.40-$1.20 + LLM-cost $0.05-$0.15 + telephony-cost $0.02-$0.05 = $0.47-$1.40/call total) + a per-cohort-LTV-aware-save-offer-via-voice (a $50 free-shipping-credit to a VIP-tier-customer with 24-month-LTV-of-$1,800 = 2.8% × LTV = ROI-positive; the same $50 credit via voice-AI-call to a 30-day-old-customer with $45-LTV = 111% × LTV = unprofitable; the voice-AI-call-cost is added to the calculation). Layer 5 routes the save-offer through the per-cohort-LTV-aware-policy-engine so the operator captures the canonical **5-8x higher save-rate on voice-AI-proactive-calls vs SMS-push-email-default** (per Regal 2024 + PolyAI 2024 + Balto 2024 voice-AI-outbound benchmarks: voice-AI-call save-rate = 18-32% vs SMS-push-email-default save-rate = 3-6% on the same cohort-decline-cohort) + **+15-25% incremental save-rate-uplift vs Move #20.3 default-email-SMS-push-cadence** + **voice-AI-call-resolves-30-50% of the cohort-decline-cohort BEFORE they file a tier-2-ticket** = $85k-$340k/yr Year-1 incremental net at $1M GMV (vs Move #20.3's $68k-$290k/yr) = 9:1-28:1 Year-1 ROI Path B default 18:1 at $1M-$10M US DTC base. Gated on Move #20.3 (skill/322 ai-tier-3-proactive-customer-success) shipped ≥90 days AND ≥6 months of Gorgias/Kustomer/Zendesk call-detail-records + ≥3 months of Triple Whale cohort-LTV-history AND TCPA-prior-express-consent-collection-mechanism shipped (per customer-voice-opt-in checkbox at signup + per-customer-call-recording-consent + per-customer-DNC-list-scrub) AND Balto/Regal/PolyAI subscription active + Twilio-Flex or Vonage-Voice or MessageBird-Voice telephony-subscription active + OpenAI-Realtime-API or Anthropic-Voice or ElevenLabs-Conversational-AI or Google-Gemini-Live-API voice-LLM-subscription active + 4 hr/week operator time during the 8-12 week build. Companion `dashboard/src/lib/ai-tier-3-voice-ai-proactive.ts` (Archetype-D agentic-orchestration + 4-signal-voice-channel-preference-detector + voice-AI-call-orchestrator + voice-AI-policy-engine + escalation-ladder + voice-AI-attribution-loop + per-cohort-LTV-aware-save-offer-via-voice). Distinct from Move #20.3 (skill/322 ai-tier-3-proactive-customer-success) which is the **tier-3 multi-channel proactive-cadence defaulting to email-SMS-push**; Move #20.4 is the **voice-AI-channel-specific tier-3 layer** that fires when email/SMS/push are saturated AND the customer is high-LTV AND voice-preferring AND TCPA-consented. Distinct from Move #20.2 (skill/321 ai-tier-2-customer-service-deflection) which is the **tier-2-agentic-resolution layer** for inbound tickets AFTER they're filed; Move #20.4 detects voice-preferring-at-risk-customers BEFORE they file. ## When to use this skill

## Common pitfalls (15 from real builds)

The following 15 pitfalls are the most common failure modes observed across Move #20.4 voice-AI-tier-3-proactive-CS builds. Each pitfall has a discriminator case (when does it fire?), the impact (what breaks?), and the canonical fix.

1. **Skip-Move-#20.3-prerequisite (most common pitfall).** Operator ships Move #20.4 voice-AI-call WITHOUT first shipping Move #20.3 (skill/322 ai-tier-3-proactive-customer-success). Without Move #20.3's 14-signal-cohort-decline-detector, Layer 1 voice-channel-preference-detector has no upstream cohort-decline-feed and fires voice-AI-calls for every customer (over-firing = TCPA-violation-spike + brand-damage). Discriminator: `bash scripts/skill-branch.sh status` shows Move #20.3 not-shipped OR Move #20.3 <90 days live OR Move #20.3 save-rate <12%. Fix: defer Move #20.4 until Move #20.3 ships ≥90 days AND ≥12% save-rate AND ≥15% channel-saturation-cohort.

2. **Below-voice-channel-preference-floor (Layer 1.1-1.12).** Operator builds Layer 1 voice-channel-preference-detector but the per-customer-voice-preference-score-floor is set too low (e.g., ≥0.4 instead of ≥0.7). The voice-AI-call fires for non-voice-preferring-customers (over-firing = customer-complaint-spike + low-resolution-rate). Discriminator: voice-AI-call-resolution-rate <15% after week-4 pilot = voice-channel-preference-floor-too-low. Fix: raise voice-preference-score-floor to ≥0.7 + add per-customer-prior-call-record-read (call-history >3-calls-in-past-12-months = voice-preferring-flag).

3. **Missing-TCPA-prior-express-consent-verification (Layer 4.1).** Operator ships voice-AI-call WITHOUT verifying per-customer-voice-opt-in-flag OR WITHOUT per-customer-DNC-list-scrub. Voice-AI-call fires for non-opt-in-customers → FCC-TCPA-violation ($500-$1,500/violation civil penalty + class-action-risk). Discriminator: voice-AI-call-fires-for-customer-without-voice-opt-in-flag OR voice-AI-call-fires-for-DNC-list-customer. Fix: hard-block voice-AI-call-orchestrator-until-customer-voice-opt-in-flag-set-at-signup + integrate DNC.com-scrub-API-into-call-orchestrator + per-state-DNC-list-scrub.

4. **Calling-before-08:00-or-after-20:00-local (Layer 4.3).** Operator builds voice-AI-call-orchestrator WITHOUT per-customer-time-zone-detection OR WITHOUT calling-window-hours-compliance. Voice-AI-call fires at 06:00 per-customer-local → FCC-TCPA-violation ($500-$1,500/violation). Discriminator: voice-AI-call-fires-outside-08:00-20:00-per-customer-local-time-zone. Fix: read customer-shipping-address-time-zone OR customer-IP-time-zone + pre-call-scheduler-queue-holds-call-until-08:00-20:00-window-opens.

5. **Over-calling-frequency (Layer 4.4).** Operator builds voice-AI-call-orchestrator WITHOUT max-call-frequency-cap OR with cap too high (e.g., 5 calls/30 days instead of 1/30 days). Over-calling = brand-damage + customer-complaint-spike + TCPA-complaint-rate-spike. Discriminator: per-customer-voice-AI-call-frequency >1/30 days OR >3/lifetime. Fix: enforce-max-1-call-per-30-days + max-3-calls-per-lifetime-via-policy-engine + per-customer-call-frequency-tracking.

6. **Marketing-message-on-voicemail (Layer 4.5).** Operator's voice-AI-call leaves full-marketing-message-on-voicemail (instead of polite-decline + callback-number). FCC-TCPA-violation + customer-complaint-spike + voicemail-detection-rate-spike (>40% of calls go to voicemail). Discriminator: voice-AI-call-voicemail-detection >40% OR customer-complaint-"received-marketing-voicemail"-rate-spike. Fix: build voicemail-detection-with-polite-decline-and-callback-number-leave (per FCC-TCPA-rules: "Hi, this is Maya from Kreis Studio. Please call us back at...") + NEVER-leave-marketing-message-on-voicemail.

7. **English-only-voice-AI-call-on-non-English-customer (Layer 1.8 + Layer 4.6).** Operator builds voice-AI-call with English-only-script. Non-English-customer (Spanish, French, German, etc.) receives English-voice-AI-call = off-brand + customer-complaint + low-resolution-rate. Discriminator: non-English-customer-voice-AI-call-resolution-rate <8% OR customer-complaint-"received-English-call-despite-speaking-Spanish"-rate-spike. Fix: integrate per-customer-language-detection-for-voice-AI-pivot + ElevenLabs-multilingual-voice-engine OR Google-Gemini-Live-API-multilingual OR PolyAI-multilingual.

8. **Generic-template-script-without-per-customer-context (Layer 3.1-3.4).** Operator builds voice-AI-call-script with static-template ("Hi, this is a call from Kreis Studio...") WITHOUT per-customer-context (brand-voice-anchor, last-touch-product, prior-call-record, prior-resolution-summary). Voice-AI-call feels-generic + customer-feels-robotic + low-engagement-rate. Discriminator: voice-AI-call-engagement-rate <50% OR customer-complaint-"felt-robotic"-rate-spike. Fix: build per-customer-context-injection (brand-voice-anchor + last-touch-product + prior-call-record + prior-resolution-summary + cohort-tone).

9. **No-human-takeover-trigger-detection (Layer 4.10).** Operator builds voice-AI-call WITHOUT customer-takeover-trigger-detection. Voice-AI-call continues-even-when-customer-says-"let-me-talk-to-a-human" OR customer-stress-detected. Customer-frustration-spike + churn-acceleration. Discriminator: voice-AI-call-customer-takeover-rate <10% OR customer-complaint-"couldn't-reach-a-human"-rate-spike. Fix: build customer-takeover-trigger-detection (OpenAI-Realtime-API-stress-detection + voice-stress-detection + sentiment-detection) + auto-promote-to-T5/T6/T7-escalation-on-trigger.

10. **No-pilot-cohort-gating (Layer 2.12).** Operator launches voice-AI-call-orchestrator on FULL-COHORT on day-1 WITHOUT pilot-cohort (50 customers max). Brand-damage-risk if voice-AI-call renders off-brand OR fires for non-TCPA-consented-customer. Discriminator: voice-AI-call-fires-for-1000+-customers-on-day-1-OR-pilot-cohort-not-defined. Fix: enforce-pilot-cohort-gating (max-50-customers + max-1-call-per-pilot-customer + max-3-calls-per-week-across-pilot-cohort) + pilot-floor (≥18% save-rate + ≥15% resolution-rate + ≤40% voicemail-rate + ≥4.0/5.0 customer-satisfaction-score + ≥95% TCPA-compliance-rate) required before scaling.

Voice-AI-call-cost-spike on low-LTV-customers = unprofitable. Discriminator: voice-AI-call-cost >$1.50/call OR per-customer-voice-AI-cost >8%-of-24-month-predicted-LTV. Fix: build voice-AI-call-cost-ceiling-per-customer + cost-attribution-via-Move-#40 + auto-fallback-to-Move-#20.3-when-cost-exceeded.

12. **Save-offer-not-LTV-aware (Layer 5.3).** Operator builds voice-AI-call-save-offer with single-percentage (e.g., 20%-off-for-all). Over-discount-on-high-LTV-customers (giving $200-off to $1,800-LTV-customer = unprofitable) OR under-discount-on-low-LTV-customers (giving $200-off to $400-LTV-customer = insufficient-incentive).
