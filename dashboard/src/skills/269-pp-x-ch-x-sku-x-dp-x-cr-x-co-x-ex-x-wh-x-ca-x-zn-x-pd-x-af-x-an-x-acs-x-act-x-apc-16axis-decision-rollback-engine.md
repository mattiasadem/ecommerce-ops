1. **Per-axis decision-rollback without Per-16-axis-combination attribution** — rolling back a single tier-mis-routing incident in isolation without checking whether the same root-cause affected Per-cohort × Per-affiliate-network × Per-commission-structure × Per-cadence siblings. Fix: every Per-axis-rollback incident MUST carry the canonical 16-axis attribution-decoder (Move #180 SHAP + Move #119 Per-cohort × Per-affiliate attribution-decision) before rollback fires.
2. **Single-axis rollback-engine only (tier OR commission OR network OR cadence)** — building a tier-mis-routing-rollback-engine WITHOUT the parallel commission-structure-mis-routing + network-mis-routing + cadence-mis-routing rollback-engines. Fix: build all 4 rollback-engines + the unified Per-16-axis-combination-decoder FIRST, then wire individual rollback-engines.
3. **Manual rollback only (no automated rollback-engine)** — relying on the on-call operator to manually identify + classify + rollback Per-axis-mis-routing incidents. Fix: build the canonical Per-16-axis-combination-decision-rollback-engine with the canonical 1-3 day detection + 1-3 day rollback Path B / <24h detection + <24h rollback Path C automated loop.
4. **Detection without attribution-decoder** — detecting Per-axis-mis-routing incidents WITHOUT the SHAP-value attribution-decision-audit-explainer-engine to identify which of the 16 axes caused the mis-routing. Fix: every detection MUST carry the canonical Move #180 SHAP-value attribution-decoder.

## Common pitfalls (26 from real builds)

1. **Move #268-naive-extension pitfall** — adding the Per-axis decision-rollback-engine to Move #268's 16-axis LTV-overlay without extending Move #268's 9-cost-strip-overlay with the Per-axis-rollback-net-cost dimension (rollback-decision-cost + rollback-execution-cost + rollback-cost-strip-cost + rollback-prevention-decision-cost + rollback-decoder-cost + cross-axis-compound-incident-detection-cost + per-axis-frequency-cap-violation-cost + cross-border-rollback-cost + per-tier-sub-tier-rollback-distinction-cost). Fix: extend Move #268's 9-cost-strip with the 9-rollback-cost dimensions BEFORE adding the Per-axis-decision-rollback-engine.
2. **Single-axis-rollback-engine-only pitfall** — building a tier-mis-routing-rollback-engine WITHOUT the parallel commission-structure-mis-routing + network-mis-routing + cadence-mis-routing rollback-engines. Fix: build all 16 axis-rollback-engines + the unified Per-16-axis-combination-decoder FIRST, then wire individual axis-rollback-engines.
3. **Manual-rollback-only pitfall** — relying on the on-call operator to manually identify + classify + rollback Per-axis-mis-routing incidents. Fix: build the canonical Per-16-axis-combination-decision-rollback-engine with the canonical 1-3 day detection + 1-3 day rollback Path B / <24h detection + <24h rollback Path C automated loop wired to PagerDuty 2024 / Opsgenie 2024 / FireHydrant 2024 / incident.io 2024 / Rootly 2024.
