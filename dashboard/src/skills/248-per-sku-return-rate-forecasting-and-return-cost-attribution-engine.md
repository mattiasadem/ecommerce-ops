## Common pitfalls (18 from real builds)

1. **Conflating per-SKU-return-rate with per-SKU-refund-rate.** A SKU's per-SKU-refund-rate can be inflated by partial-refunds (e.g. 20% partial-refund on a damaged-product = a $200-product-refunded-at-$40 = 1 refund counted, but $40 of refund not $200 of refund counted). Use per-SKU-return-rate (count-of-returns / count-of-orders) as the canonical KPI, NOT per-SKU-refund-rate (count-of-refunds / count-of-orders). The canonical recipe is: `per-SKU-return-rate = COUNT(returns WHERE SKU = X AND date >= 30-days-ago) / COUNT(orders WHERE SKU = X AND date >= 30-days-ago)`, and `per-SKU-refund-rate = COUNT(refunds WHERE SKU = X AND date >= 30-days-ago) / COUNT(orders WHERE SKU = X AND date >= 30-days-ago)`, but the return-rate and refund-rate are often NOT the same — return-rate is per-SKU, refund-rate can be per-order-multi-SKU. **Fix:** use per-SKU-return-rate as the canonical KPI and report it in the per-SKU-return-rate-dashboard; report per-SKU-refund-rate as a secondary KPI with explicit warning that partial-refunds inflate it.

2. **Not adjusting per-SKU-return-rate for SKU-launch-date + SKU-cohort-mix.** A SKU launched 7-days-ago has a sample-size of N orders which is too small to compute a meaningful per-SKU-return-rate (a single return on 5 orders = 20% return-rate, statistically meaningless). Use per-SKU-return-rate only when sample-size ≥ 30 orders AND ≥ 30 days post-launch; for SKUs with <30 orders OR <30 days post-launch, use per-vertical-return-rate-baseline as the placeholder per Triple Whale 2024 + Polar Analytics 2024 + Northbeam 2024 + Daasity 2024 + Ecommerce Per SKU Launch Return Rate 2024 + Ecommerce Per SKU Evergreen Return Rate 2024 benchmarks. **Fix:** add a `sample-size-floor` rule that requires ≥30 orders AND ≥30 days post-launch before computing per-SKU-return-rate; below the floor, report per-vertical-return-rate-baseline as the placeholder.

3. **Ignoring per-channel-return-rate-attribution.** A SKU sold via Meta-driven-customers returns at 12% on average but sold via Email-driven-customers returns at 6% on average — the per-SKU-return-rate hides the per-channel dispersion. Wire per-channel-return-rate-attribution so the operator can see "Meta-driven-customers-return-at-12% vs Email-driven-customers-return-at-6%" and either optimize the Meta-channel-funnel for higher-quality-customers OR suppress Meta-driven-customers-from-paid-acquisition-lookalike-audiences per Triple Whale 2024 + Klaviyo 2024 + Postscript 2024 + Gorgias 2024 + Meta CAPI 2024 + Google Enhanced Conversions 2024 + TikTok Events API 2024 + Ecommerce Channel Return Rate 2024 benchmarks. **Fix:** wire per-channel-return-rate-attribution into the per-SKU-return-rate-dashboard with channel-level breakdown.

4. **Ignoring per-cohort-return-rate-attribution.** A SKU purchased by first-time-customers returns at 16% on average but purchased by repeat-customers returns at 6% on average — the per-SKU-return-rate hides the per-cohort dispersion. Wire per-cohort-return-rate-attribution so the operator can see "first-time-customers-return-at-16% vs repeat-customers-return-at-6%" and either optimize the first-time-customer-funnel for higher-quality-customers OR suppress high-returner-cohort-from-paid-acquisition-lookalike-audiences per Triple Whale 2024 + Klaviyo 2024 + Postscript 2024 + Gorgias 2024 + Meta CAPI 2024 + Google Enhanced Conversions 2024 + TikTok Events API 2024 + Ecommerce Cohort Return Rate 2024 + Ecommerce LTV By Return Rate 2024 benchmarks. **Fix:** wire per-cohort-return-rate-attribution into the per-SKU-return-rate-dashboard with cohort-level breakdown.

5. **Conflating per-SKU-return-cost-floor with per-SKU-return-rate.** A SKU with 30% return-rate BUT $30 AOV (e.g. apparel accessory) might have $9 per-SKU-return-cost-floor (= 30% × $30 per-return-cost), while a SKU with 18% return-rate BUT $200 AOV (e.g. footwear) might have $36 per-SKU-return-cost-floor (= 18% × $200 per-return-cost). The SKU with LOWER return-rate has HIGHER return-cost-floor.
