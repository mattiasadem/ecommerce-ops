1. **Treating 5-channel cross-channel-orchestration as the 1-channel extension (email-only) rather than the 5-channel-extension (email + SMS + web-push + mobile-push + direct-mail).** The 1-channel-extension's primary failure mode is "I have skill/616 (7-cohort extension), let me ADD ONE MORE channel = email + direct-mail" — this fails to capture the canonical 35-50pp cross-channel-reach lift over the 1-channel baseline per Klaviyo cross-channel 2024 + Iterable cross-channel 2024 + Salesforce Marketing Cloud cross-channel 2024 + Segment cross-channel 2024. 2. **Wrong per-cohort-channel-preference-matrix — using default cohort routing (all cohorts via email) instead of per-cohort-channel-preference-matrix.** The canonical per-cohort-channel-preference-matrix is BFCM-VIP: [email + SMS + mobile-push + direct-mail] / BFCM-loyalty-active: [email + SMS + mobile-push] / BFCM-mobile-browse: [SMS + web-push + mobile-push] / BFCM-gift-recipient: [email + direct-mail] etc. (per Salesforce Shopper Index cross-channel-preference 2024 + Klaviyo cross-channel-preference 2024 + Postscript cross-channel-preference 2024 + Iterable cross-channel-preference 2024 + Twilio cross-channel-preference 2024).
