# AI tier-1 voice-AI self-serve-deflection

> Move #20.6 is the canonical **inbound voice-call tier-1 self-serve-deflection engine** that sits ABOVE Move #20.5 (skill/324 ai-tier-2-voice-ai-resolution, inbound voice-call tier-2 ticket resolution) and Move #20.2 (skill/321 ai-tier-2-customer-service-deflection, ticket-text/email-channel tier-2). Move #20.6 handles the **voice-channel tier-1 self-serve-deflection** — the 35-50% of inbound DTC customer calls that are simple status / FAQ / policy questions (vs Move #20.5's 25-35% tier-2-complex-returns/exchanges/warranty/billing/subscription-cancellation vs Move #20.2's email/text/SMS-channel tier-1 + tier-2-mix): voice-call-driven order-status questions (8-12% of all calls), voice-call-driven shipping-status + tracking-questions (6-10%), voice-call-driven return-policy-FAQ (4-7%), voice-call-driven sizing-chart-questions (3-5%), voice-call-driven loyalty-points-balance + tier-questions (2-4%), voice-call-driven subscription-status + pause-or-skip-questions (2-4%), voice-call-driven discount-code + promotion-applicability-questions (2-3%), voice-call-driven product-availability + restock-questions (2-3%), voice-call-driven general-FAQ (2-3%), voice-call-driven address-change-question + payment-status-question + invoice-request + gift-card-balance-question (2-3% combined) — and the "voice-AI-self-serve-deflection" cases where the customer expects the voice-AI to **actually answer the question end-to-end during the call** (look up the tracking number + read it back, check the loyalty points + read them back, check the subscription status + read it back, look up the discount code + apply it, answer the return-policy-FAQ + read it back) rather than transfer them to email/text or to a human tier-1 agent. Built on **5 layers**: (Layer 1) **inbound-voice-call-routing + tier-1-intent-voice-classifier** — when the customer calls the operator's voice-number (Twilio-Flex / Aircall / RingCentral / Dialpad-AI / Genesys / NICE-inContact / Five9 / Amazon-Connect), the call is routed to the voice-AI-tier-1-orchestrator (Regal/PolyAI/Balto/Vapi/Retell-AI/Bland-AI rendered via OpenAI-Realtime-API / Anthropic-Claude-Voice / Google-Gemini-Live-API / ElevenLabs-Conversational-AI); the voice-AI classifies the inbound-call into 12 tier-1-intents (order-status / shipping-status / return-policy-FAQ / sizing-chart-question / loyalty-points-balance / subscription-status / discount-code-question / product-availability / general-FAQ / address-change-question / payment-status-question / invoice-or-gift-card-balance-question) via GPT-4o / Claude-Voice / Gemini-Live with low-temperature (0.1) + structured-output + per-intent-confidence-threshold (≥0.85 to auto-deflect-self-serve-during-call, 0.5-0.85 to AI-assist-human-tier-1-agent, <0.5 to escalate to Move #20.5 tier-2 voice-AI OR human tier-2-agent); (Layer 2) **per-intent-voice-self-serve-deflection-engine** — each of the 12 tier-1-intents has its own dedicated voice-channel-self-serve-deflection workflow: voice-driven-order-status → Shippo/EasyPost/Aftership/Routelookup API call-during-call + reads-back-tracking-number-during-call + sends-tracking-link-via-SMS-during-call; voice-driven-shipping-status → Shippo/EasyPost/Aftership API call-during-call + reads-back-current-status-and-ETA-during-call; voice-driven-return-policy-FAQ → Move #23 knowledge-base-FAQ-retrieval-via-vector-search (Algolia DocSearch / Typesense / Notion-AI / Gorgias-knowledge-base / Zendesk-help-center / HelpScout-docs) + reads-back-policy-section-during-call + sends-FAQ-link-via-SMS-during-call; voice-driven-sizing-chart-question → Move #37 ai-site-search-merchandising retrieval + Move #38 True-Fit-Fit-Code-from-profile + reads-back-recommended-size-during-call; voice-driven-loyalty-points-balance → Smile-points-balance-API-call-during-call + reads-back-points-balance + tier-status + reward-options-during-call; voice-driven-subscription-status → Recharge-customer-portal-API-call-during-call + reads-back-next-bill-date + product + status + skip-or-pause-availability-during-call; voice-driven-discount-code-question → Klaviyo-coupon-API-lookup + reads-back-applicable-codes + applies-code-to-cart-via-Shopify-storefront-API-during-call; voice-driven-product-availability + restock-question → Shopify-storefront-API-inventory-check-during-call + reads-back-current-availability + restock-ETA-during-call + offers-back-in-stock-notification-via-Klaviyo-during-call; voice-driven-general-FAQ → Move #23-knowledge-base-FAQ-retrieval + reads-back-FAQ-answer-during-call; voice-driven-address-change-question → Shippo-address-validation + Shopify-admin-API-update-during-call (only-if-order-not-yet-shipped); voice-driven-payment-status-question → Stripe-payment-intent-lookup-during-call + reads-back-charge-status-during-call; voice-driven-invoice-or-gift-card-balance-question → Stripe-invoice-lookup-during-call + reads-back-amount + sends-invoice-via-email-during-call OR gift-card-balance-lookup-via-Smile/Yotpo/Shopify-gift-card-API-during-call; (Layer 3) **voice-AI-self-serve-deflection-action-layer** — the voice-AI doesn't just answer during the call, it takes the action IN-REAL-TIME: calls Shippo API to look up the tracking number (customer receives tracking-link-via-SMS-during-call + voice-AI-confirms), calls Smile API to look up the loyalty points balance (points-balance-read-back-to-customer-during-call), calls Recharge API to read the subscription status + offer skip-or-pause (status-read-back + skip-scheduled-during-call), calls Klaviyo coupon API to look up + apply the discount code (code-applied-to-cart-during-call + cart-link-sent-via-SMS-during-call), calls Move #23 knowledge-base-FAQ-retrieval via Algolia / Typesense / Notion-AI / Gorgias-knowledge-base / Zendesk-help-center to read the FAQ (FAQ-answer-read-back + FAQ-link-sent-via-SMS-during-call), closes Gorgias ticket-with-resolution-summary during the call (so the customer never has to follow up via email), triggers Triple Whale tier-1-self-serve-touch-attribution (so the touch is attributed to cohort-LTV in real-time); (Layer 4) **voice-AI-tier-1-policy-engine + escalation-ladder** — 7-tier escalation-ladder (T0 voicemail-no-call / T1 voice-AI-call-with-AI-rendered-self-serve-answer / T2 voice-AI-call-with-real-time-coaching-via-Balto / T3 voice-AI-call-with-senior-human-coaching-via-Balto-QA-listening / T4 voice-AI-call-with-manager-on-call-listening / T5 voice-AI-call-with-senior-human-takeover-mid-call / T6 voice-AI-call-with-manager-takeover-mid-call / T7 senior-human-direct-call-with-no-voice-AI-layer); per-tier-1-cost-aware-deflection-overlay (voice-AI-self-serve-call-cost $0.32-$0.95/call vs Move #20.1-tier-1-email/text-cost-per-channel $1.50-$4.50/ticket vs Move #20.5-tier-2-voice-AI-cost $0.54-$1.60/call — voice-AI-tier-1 is the cheapest channel); per-cohort-LTV-aware-self-serve-deflection-policy (high-LTV ≥$1,200 = full-self-serve-deflection-during-call + per-customer-prior-call-record-context-injection, mid-LTV $400-$1,200 = standard-self-serve-deflection-during-call, low-LTV <$400 = voice-AI-tier-1-self-serve-deflection-during-call); per-state-call-recording-consent-and-compliance (CA requires-all-party-consent, FL requires-one-party-consent); fallback-to-Move-#20.5-when-voice-AI-tier-1-ineffective (call-resolution-rate <35% OR self-serve-deflection-fallback-rate >35% OR voicemail-rate-spike >40%); fallback-to-Move-#20.1-when-voice-AI-channel-overloaded (voice-channel-volume-spike >1500-calls-per-day → route next-call-to-email-self-serve-flow); (Layer 5) **voice-AI-tier-1-attribution-loop + per-customer-LTV-aware-self-serve-deflection-action-execution-loop** — Triple Whale voice-AI-call-attribution (every voice-AI-tier-1-call is attributed to per-customer-touch-attribution-feed) + per-customer-voice-AI-call-cost-attribution-via-Move-#40-financial-operations-unit-economics + voice-AI-tier-1-call-vs-Move-#20.1-tier-1-email-default-resolution-rate-comparison (voice-AI-tier-1 self-serve-resolution-rate 55-75% per Regal 2024 + PolyAI 2024 + Balto 2024 voice-AI-tier-1-inbound benchmarks vs Move #20.1 email-channel 40-60% deflection-rate — voice-AI-tier-1 is 15-20 pts higher on tier-1 because voice-channel customers expect in-call-resolution and the answers are lookup-only not policy-bound) + voice-AI-tier-1-call-cohort-segmentation-by-tier-1-intent + voice-AI-tier-1-call-real-time-dashboard-monitoring + voice-AI-tier-1-call-monthly-board-pack-and-rollback-decision + per-customer-tier-1-touch-attribution-via-Triple-Whale-tier-1-self-serve-touch-attribution-event + per-customer-LTV-tier-aware-self-serve-action-execution-loop.
