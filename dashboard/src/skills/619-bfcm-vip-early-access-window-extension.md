## Common pitfalls (16 from real builds)

### BFCM-VIP-early-access-temporal-window pitfalls

- **P1 — Treating the Mon-Nov-23 → Wed-Nov-25 window as a 1-day window instead of a 3-day window.** Operators that compress to Mon-Nov-23-launch-only lose 15-25% of BFCM-VIP-reach because they miss the Tue-Nov-24 + Wed-Nov-25 VIP-customers in different timezones (West-Coast-VIPs respond 6-9 hours later than East-Coast-VIPs; international-VIPs respond 9-14 hours later). The fix: ship BFCM-3-day-temporal-window-bucket with Mon-Nov-23 launch-email + Mon-Nov-23 launch-SMS + Tue-Nov-24 mobile-push + Wed-Nov-25 direct-mail.
- **P2 — Treating the Mon-Nov-23 launch as identical to the Mon-Dec-1 public-release-day launch.** Operators that use the same launch-template (no template content-tailoring for VIP-early-access) miss 5-15% of BFCM-VIP-revenue because the VIP-early-access-customer expects exclusive-curated-content + loyalty-VIP-discount-multiplier + loyalty-tier-up-reminder + gift-shopping-card-options that the public-release-day-template doesn't carry. The fix: ship 3 distinct launch-templates (Mon-Nov-23 / Tue-Nov-24 / Wed-Nov-25) per cohort × per-channel × per-VIP-early-access-temporal-window-bucket.

### BFCM-VIP-early-access-cohort-qualifying pitfalls
