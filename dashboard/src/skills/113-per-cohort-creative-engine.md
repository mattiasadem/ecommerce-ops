**Pitfall #1 — Bidding on first-order-AOV instead of per-creative-cohort-LTV.** The operator tells Meta / Google / TikTok the conversion-value is checkout-AOV instead of gross-margin-or-pLTV, so the algorithm optimizes toward first-order-discount-hunters instead of retainable-cohorts. **Fix:** Wire per-creative-cohort-LTV (30/60/90/180/365-day) via Triple Whale + Triple Whale pLTV + Polar + Polar Cohort LTV + Northbeam + Hyros and pass to Meta Advantage+ pLTV + Google Smart Bidding tROAS + Maximize Conversion Value + Value Rules + Enhanced Conversions + TikTok VBO. The canonical 5-step ladder: (a) pull cohort-LTV from Triple Whale, (b) compute per-creative × per-cohort LTV-multiplier, (c) set per-creative-conversion-value = AOV × per-cohort-LTV-multiplier × per-creative-LTV-multiplier, (d) pass to bid-engine via Value Rules or enhanced-conversions, (e) audit monthly via per-creative-LTV-CAC-ratio vs baseline.

**Pitfall #2 — Per-creative-LTV-attribution is not measured.** The operator cannot answer "which creative is LTV-positive per cohort" within 60 seconds. **Fix:** Wire per-creative × per-cohort × 30/60/90/180/365-day LTV attribution via Triple Whale + Triple Whale pLTV + Polar + Polar Cohort LTV + Northbeam + Hyros, build a per-creative-cohort-LTV-overlay-engine that surfaces LTV-CAC-ratio per creative per cohort, and add it to the weekly performance-marketing review.

**Pitfall #3 — Per-creative-cohort-LTV-window is wrong.** The operator uses a 7-day or 14-day attribution window when the cohort's repeat-purchase-cycle is 60-180 days, missing the bulk of LTV. **Fix:** Calibrate per-creative-cohort-LTV-window to per-cohort-repeat-purchase-cycle (consumables = 30-60d / apparel = 90-180d / supplements = 60-120d / subscription = 90-365d) and surface per-creative-LTV across 30/60/90/180/365-day windows.

**Pitfall #4 — Per-creative × per-cohort × per-overlay LTV-multiplier is not surfaced.** The operator has per-creative × per-cohort LTV but not per-creative × per-cohort × per-overlay (format / creator / UGC / brand) LTV-multiplier, missing the per-overlay-bid-overlay-upgrade opportunity. **Fix:** Build a per-creative × per-cohort × per-overlay LTV-multiplier-engine (per-format / per-creator / per-UGC / per-brand-overlay) and pass to bid-engine as Value Rules.
