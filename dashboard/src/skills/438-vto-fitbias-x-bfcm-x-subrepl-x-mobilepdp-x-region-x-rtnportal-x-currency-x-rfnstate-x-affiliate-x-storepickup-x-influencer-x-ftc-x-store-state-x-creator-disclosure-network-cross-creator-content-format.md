> A 14-axis decomposition that fuses per-creator-disclosure-network × per-creator-content-format into a single 192-cell creator-disclosure-network-cross-creator-content-format taxonomy (8 creator-disclosure-network × 24 creator-content-format combinations) and wires it into the canonical Move #41 VTO fit-bias attribution engine — closing the creator-disclosure-network loop on top of every Move #41.1-#41.27 extension and yielding a 1,931,153,891,971,036,800,000-cell primary cross-validation matrix that per-cohort bid, creative, message, audience, experimentation, suppression, pricing, attribution-decision, channel-orchestration, segment-strategy, and product-discovery engines can consume simultaneously.

## When to use this skill

Use Move #41.28 — creator-disclosure-network-cross-creator-content-format-extension — when ANY of the following are true:

1. **You run paid or organic creator campaigns across 3+ creator-disclosure-networks (Impact-Disclosure-Network + PartnerStack-Disclosure-Network + CreatorIQ-Disclosure-Network + Aspire-Disclosure-Network + GRIN-Disclosure-Network + Upfluence-Disclosure-Network + Klear-Disclosure-Network + Modash-Disclosure-Network) AND must show different creator-content-format treatments per network (e.g. Impact-Disclosure-Network favors Instagram-Reels + Instagram-Carousel + Pinterest-tutorial for FTC-Disclosure-2024-flag-clean cells; PartnerStack-Disclosure-Network favors TikTok-tutorial + TikTok-GRWM + YouTube-tutorial for hashtag-disclosure-tier cells; CreatorIQ-Disclosure-Network favors YouTube-tutorial + YouTube-GRWM + YouTube-routine for FTC-Endorsement-Guidelines-2024-flag cells; Aspire-Disclosure-Network favors Instagram-Stories + TikTok-family + Instagram-Reels for FTC-COPPA-compliant-tier cells; GRIN-Disclosure-Network favors Instagram-IGTV + Instagram-Carousel + YouTube-review for mid-market-stitching-velocity-disclosure-network cells; Upfluence-Disclosure-Network favors Instagram-Photo + YouTube-recipe + Instagram-Live for 90-day-disclosure-window cells; Klear-Disclosure-Network favors Instagram-Carousel + Pinterest-tutorial + YouTube-vlog for 180-day-disclosure-window cells; Modash-Disclosure-Network favors Instagram-Live + Pinterest-routine + YouTube-family for creator-economy-oversaturation-spike-detection cells).** Without this skill the per-creator-disclosure-network fallback collapses into a single "all networks share the same creator-content-format" rule that breaks FTC-Disclosure-2024 §255.5 (the 2024 guidance that mandates per-network-per-format differentiation — Impact-Disclosure-Network × Instagram-Reels is NOT comparable to Impact-Disclosure-Network × YouTube-tutorial).
2. **You have a 2024 creator-disclosure-network spike (a creator-disclosure-network × creator-content-format cell suddenly spikes 4-6× its baseline, e.g. an Impact-Disclosure-Network × Pinterest-tutorial post goes from 50K to 800K impressions in 24h during a Pinterest-Q4-Gifting-Spike) and need to scope creator-disclosure-network-spike separately from baseline-creator-disclosure-network + mature-creator-disclosure-network + emerging-creator-disclosure-network, because creator-disclosure-network-spike triggers a separate rate-limit-warning threshold (15s vs the 60s baseline).**
3. **You operate across multi-network creator marketplaces (LTK + Collective Voice + ShopStyle + RewardStyle/LiketoKnow.it + Amazon Live + TikTok Shop + Pinterest Creator Commerce + YouTube Shopping + Amazon-Influencer + Walmart-Connect + Target-Partner-Influencer-Program + Best-Buy-Influencer-Program) AND each marketplace enforces its OWN creator-disclosure-network floor (Amazon Live requires Impact-Disclosure-Network + PartnerStack-Disclosure-Network + CreatorIQ-Disclosure-Network presence; TikTok Shop requires Impact-Disclosure-Network + PartnerStack-Disclosure-Network + GRIN-Disclosure-Network; LTK requires PartnerStack-Disclosure-Network + CreatorIQ-Disclosure-Network + GRIN-Disclosure-Network). Without Move #41.28 the per-creator-disclosure-network × per-creator-content-format cell reads as a single normalized "creator-disclosure-network score" and the operator loses the ability to see WHICH network-format cell is the leak.**
4. **You have a current or pending 2024 FTC-Enforcement-Office investigation or have received a creator-disclosure warning letter.** The granular 8 × 24 = 192-cell creator-disclosure-network × creator-content-format matrix lets you prove per-network-per-format compliance and is a load-bearing artifact in any FTC-Disclosure-2024 §255.5 response (the FTC explicitly weights creator-disclosure-network when determining "material connection" disclosure scope — Aspire-Disclosure-Network × TikTok-family × FTC-COPPA-compliant-tier is the highest-risk 2024 disclosure cell).
5. **You are seeing a return-rate differential across creator-disclosure-networks that you can't explain with fit-bias alone.** The most common cause is that low-engagement-tier and nano-engagement-tier creator-disclosure-networks (Modash-Disclosure-Network + Klear-Disclosure-Network carry the WORST per-SKU-fit-bias profile) and the FTC-flagged low-engagement-rate-tier content triggers customer-side suspicion + return-rate spikes that look like a fit-bias problem but are actually a creator-disclosure-network-mismatch problem.
6. **You ship 3+ Move #41.20 creator-disclosure-network-derived networks to a Meta-Conversion-API + TikTok-Events-API + Pinterest-Conversions-API + YouTube-Data-API attribution stream** and need per-creator-disclosure-network × per-creator-content-format attribution to feed back into bid, creative, message, audience, experimentation, suppression, pricing, attribution-decision, channel-orchestration, segment-strategy, and product-discovery engines.
7. **You want to ship per-creator-disclosure-network × per-creator-content-format rollback-engine (auto-suppress a creator-disclosure-network × creator-content-format cell when the FTC-flag or rate-burst-spike fires, vs blanket-suppress all networks)** — the per-cell rollback precision is the difference between suppressing one bad creator-disclosure-network × creator-content-format cell and nuking a healthy channel.
8. **You're hitting 2024 state Attorney-General enforcement actions (California-AG, New-York-AG, Texas-AG, Illinois-AG, Massachusetts-AG)** for creator-marketing disclosure violations and need the per-creator-disclosure-network × per-creator-content-format audit trail to demonstrate remediation.

Do NOT use this skill if you only run 1 creator-disclosure-network (no per-network creator-content-format differentiation possible), you have no FTC exposure (you're a B2B wholesaler), or you're below the FTC-Disclosure-2024 thresholds (revenue < $5M AND no creator endorsements) — for those, Move #41.20 alone is sufficient.
