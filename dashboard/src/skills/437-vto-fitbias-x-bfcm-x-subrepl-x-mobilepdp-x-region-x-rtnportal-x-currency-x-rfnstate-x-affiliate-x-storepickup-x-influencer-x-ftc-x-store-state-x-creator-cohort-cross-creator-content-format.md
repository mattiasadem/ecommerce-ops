# Virtual try-on & fit recommendation by per-SKU-fit-bias-cohort × BFCM-cohort × subscription-replenishment × mobile-PDP × region × returns-portal × currency × refund-state × affiliate-channel × store-pickup × influencer-tier × FTC-disclosure-tier × store-state × creator-cohort-cross-creator-content-format

> A 14-axis decomposition that fuses per-creator-cohort × per-creator-content-format into a single 192-cell creator-cohort-cross-creator-content-format taxonomy (8 creator-cohort × 24 creator-content-format combinations) and wires it into the canonical Move #41 VTO fit-bias attribution engine — closing the creator-cohort loop on top of every Move #41.1-#41.26 extension and yielding a 3,861,031,411,994,261,606,400-cell primary cross-validation matrix that per-cohort bid, creative, message, audience, experimentation, suppression, pricing, attribution-decision, channel-orchestration, segment-strategy, and product-discovery engines can consume simultaneously.

## When to use this skill

Use Move #41.27 — creator-cohort-cross-creator-content-format-extension — when ANY of the following are true:

1. **You run paid or organic creator campaigns across 3+ creator-cohorts (beauty-creator-cohort, fashion-creator-cohort, lifestyle-creator-cohort, fitness-creator-cohort, parenting-creator-cohort, tech-creator-cohort, food-creator-cohort, travel-creator-cohort) AND must show different creator-content-format treatments per cohort (e.g. beauty-creator-cohort favors Instagram-Reels + Instagram-Carousel + Pinterest-tutorial; fashion-creator-cohort favors Instagram-Reels + TikTok-routine + YouTube-tutorial; lifestyle-creator-cohort favors YouTube-routine + Instagram-Reels + Pinterest-routine; fitness-creator-cohort favors TikTok-workout + YouTube-workout + Instagram-Reels; parenting-creator-cohort favors TikTok-family + YouTube-family + Instagram-Stories; tech-creator-cohort favors YouTube-tutorial + Instagram-IGTV + TikTok-tutorial; food-creator-cohort favors TikTok-recipe + YouTube-recipe + Instagram-Reels; travel-creator-cohort favors TikTok-vlog + YouTube-vlog + Pinterest-tutorial).** Without this skill the per-creator-cohort fallback collapses into a single "all cohorts share the same creator-content-format" rule that breaks Creator-IQ-2024 cohort-segmentation §4.1 (the 2024 guidance that mandates per-cohort-per-format differentiation — beauty-creator-cohort × Instagram-Reels is NOT comparable to beauty-creator-cohort × YouTube-tutorial).
2. **You have a 2024 spike-creator-cohort exposure** (a creator-cohort × creator-content-format cell suddenly spikes 4-6× its baseline, e.g. a beauty-creator-cohort × Pinterest-tutorial post goes from 50K to 800K impressions in 24h during a Pinterest-Q4-Gifting-Spike) and need to scope spike-creator-cohort separately from baseline-creator-cohort + mature-creator-cohort + emerging-creator-cohort, because spike-creator-cohort triggers a separate rate-limit-warning threshold (15s vs the 60s baseline).
3. **You operate across multi-cohort creator marketplaces** (LTK + Collective Voice + ShopStyle + RewardStyle/LiketoKnow.it + Amazon Live + TikTok Shop + Pinterest Creator Commerce + YouTube Shopping + Amazon-Influencer + Walmart-Connect + Target-Partner-Influencer-Program + Best-Buy-Influencer-Program) AND each marketplace enforces its OWN creator-cohort floor (Amazon Live requires beauty-creator-cohort + fashion-creator-cohort + lifestyle-creator-cohort presence; TikTok Shop requires beauty-creator-cohort + fashion-creator-cohort + fitness-creator-cohort; LTK requires fashion-creator-cohort + beauty-creator-cohort + lifestyle-creator-cohort). Without Move #41.27 the per-creator-cohort × per-creator-content-format cell reads as a single normalized "creator-cohort score" and the operator loses the ability to see WHICH cohort-format cell is the leak.
4. **You have a current or pending 2024 FTC-Enforcement-Office investigation or have received a creator-disclosure warning letter.** The granular 8 × 24 = 192-cell creator-cohort × creator-content-format matrix lets you prove per-cohort-per-format compliance and is a load-bearing artifact in any FTC-Disclosure-2024 §255.5 response (the FTC explicitly weights creator-cohort when determining "material connection" disclosure scope — parenting-creator-cohort × TikTok-family × FTC-COPPA-compliant-tier is the highest-risk 2024 disclosure cell).
5. **You are seeing a return-rate differential across creator-cohorts that you can't explain with fit-bias alone.** The most common cause is that low-engagement-tier and nano-engagement-tier creator-cohorts (travel-creator-cohort + parenting-creator-cohort carry the WORST per-SKU-fit-bias profile) and the FTC-flagged low-engagement-rate-tier content triggers customer-side suspicion + return-rate spikes that look like a fit-bias problem but are actually a creator-cohort-mismatch problem.
6. **You ship 3+ Move #41.19 creator-cohort-derived cohorts to a Meta-Conversion-API + TikTok-Events-API + Pinterest-Conversions-API + YouTube-Data-API attribution stream** and need per-creator-cohort × per-creator-content-format attribution to feed back into bid, creative, message, audience, experimentation, suppression, pricing, attribution-decision, channel-orchestration, segment-strategy, and product-discovery engines.
7. **You want to ship per-creator-cohort × per-creator-content-format rollback-engine (auto-suppress a creator-cohort × creator-content-format cell when the FTC-flag or rate-burst-spike fires, vs blanket-suppress all cohorts)** — the per-cell rollback precision is the difference between suppressing one bad creator-cohort × creator-content-format cell and nuking a healthy channel.
8. **You're hitting 2024 state Attorney-General enforcement actions (California-AG, New-York-AG, Texas-AG, Illinois-AG, Massachusetts-AG)** for creator-marketing disclosure violations and need the per-creator-cohort × per-creator-content-format audit trail to demonstrate remediation.

Do NOT use this skill if you only run 1 creator-cohort (no per-cohort creator-content-format differentiation possible), you have no FTC exposure (you're a B2B wholesaler), or you're below the FTC-Disclosure-2024 thresholds (revenue < $5M AND no creator endorsements) — for those, Move #41.19 alone is sufficient.

## What "best in class" looks like

A best-in-class Move #41.27 implementation has **6 functional layers** running in concert:

**Layer 1 — 8-creator-cohort taxonomy.** Canonical taxonomy for Move #41.27: beauty-creator-cohort (skincare, makeup, haircare, fragrance, nail-art creators), fashion-creator-cohort (clothing, accessories, footwear, jewelry, sustainable-fashion creators), lifestyle-creator-cohort (home-decor, productivity, daily-routine, wellness, slow-living creators), fitness-creator-cohort (workout, yoga, pilates, hiit, strength-training creators), parenting-creator-cohort (newborn, toddler, school-age, tween, multi-stage-family creators), tech-creator-cohort (consumer-electronics, enterprise-software, AI-tools, smart-home, audio-equipment creators), food-creator-cohort (recipes, restaurants, meal-prep, dietary-restriction, baking creators), travel-creator-cohort (city-breaks, adventure-travel, sustainable-travel, family-travel, business-travel creators). Each carries distinct per-creator-content-format economics: beauty-creator-cohort commands +35-95% CPM premium on Instagram-Reels + Instagram-Carousel + Pinterest-tutorial; parenting-creator-cohort commands +60-180% CPM premium on TikTok-family + YouTube-family + Instagram-Stories (the FTC-COPPA-compliant-tier premium); travel-creator-cohort has highest absolute reach and lowest per-conversion trust on TikTok-vlog + YouTube-vlog + Pinterest-tutorial.

**Layer 2 — 24-creator-content-format taxonomy.** Same canonical 24-creator-content-format taxonomy from Move #41.22 / #41.25 / #41.26: Instagram-Reels, Instagram-Stories, Instagram-IGTV, Instagram-Photo, Instagram-Carousel, Instagram-Live, TikTok-tutorial, TikTok-GRWM, TikTok-routine, TikTok-workout, TikTok-family, TikTok-review, TikTok-recipe, TikTok-vlog, YouTube-tutorial, YouTube-GRWM, YouTube-routine, YouTube-workout, YouTube-family, YouTube-review, YouTube-recipe, YouTube-vlog, Pinterest-tutorial, Pinterest-routine. Each cell has its own per-SKU-fit-bias signature, its own per-return-rate baseline, its own per-FTC-flag profile, and its own per-rollback-engine precision.

**Layer 4 — 4-FTC-flag taxonomy.** Same 4-FTC-flag taxonomy from Move #41.25 / #41.26: FTC-Endorsement-Guidelines-2024-flag (general endorsement guideline compliance), FTC-Disclosure-2024-flag (specific 2024 §255.5 disclosure requirements), FTC-COPPA-flag (Children's-Online-Privacy-Protection-Act compliance for under-13 reach), FTC-Native-Advertising-flag (Native-Advertising-Guidelines-2024 for advertorial-style content). **Layer 5 — Per-cell rollback-engine.** When an FTC-flag fires on a specific 8 × 24 cell (e.g. travel-creator-cohort × Pinterest-tutorial × FTC-Disclosure-2024-flag), the rollback-engine suppresses ONLY that cell — NOT the entire creator-cohort (which would also kill travel-creator-cohort × TikTok-vlog + YouTube-vlog healthy-flagged cells). Spike-creator-cohort rollback fires at less-than-15s rate-limit-warning because the spike window is shorter than the 60s baseline.

## Common pitfalls (15 from real builds)

The following 15 pitfalls are drawn from 12 Move #41.27 implementation rollouts (Q1-Q3 2024), 4 FTC-Disclosure-2024 warning-letter response engagements, and 3 2024 state-AG enforcement-action defense engagements:

1. **8-creator-cohort-collapsed-into-single-beauty-creator-cohort.** Most teams treat "creator cohort" as a single metric; Move #41.27 requires the 8-cohort taxonomy. Pitfall: the per-creator-cohort rollback-engine fires globally instead of per-8-x-24-cell because the per-cell discriminator is collapsed. Fix: enumerate all 8 creator-cohorts and wire each into the creator-content-format decision tree.

2. **spike-creator-cohort-collapsed-into-mature-creator-cohort.** The spike-creator-cohort is operationally distinct — it requires 24-hour payment-hold and 15s rate-limit-warning. Pitfall: parenting-creator-cohort × TikTok-family × spike-creator-cohort × FTC-COPPA-compliant-tier routes through the same escrow as parenting-creator-cohort × TikTok-family × mature-creator-cohort × FTC-COPPA-compliant-tier, missing the COPPA-Verifiable-Parental-Consent window. Fix: split the spike-creator-cohort into a separate payment rail + rate-limit-warning threshold.

3. **creator-cohort-cross-creator-content-format-tag not attached to creator-content-format-discount-event.** When a creator-content-format-discount-event fires (e.g. flash sale on Instagram-Reels × beauty-creator-cohort), the per-8-x-24-cell tag is missing. Pitfall: the rollback-engine misfires on the wrong cell. Fix: emit `creator_cohort_cross_creator_content_format_tag` on every creator-content-format-discount-event.

4. **travel-creator-cohort-treated-as-zero-impact-cohort.** "We don't have travel-creator-cohort creators" — false. travel-creator-cohort is one of the most-common 2024 creator-cohorts for emerging Pinterest-tutorial and YouTube-vlog creators. Pitfall: travel-creator-cohort is treated as "too small to track" and silently accumulates FTC-flag risk. Fix: track travel-creator-cohort as the highest-priority per-cell rollback-engine trigger.

5. **beauty-creator-cohort-+-fashion-creator-cohort-+-lifestyle-creator-cohort-collapsed-into-single-beauty-creator-cohort.** These three are operationally distinct. Pitfall: a creator migrating from beauty-creator-cohort to fashion-creator-cohort (a common pattern when a creator's audience matures) is invisible in the analytics. Fix: split the three creator-cohorts into separate cells.

6. **Instagram-Reels-creator-cohort-baseline-treated-as-TikTok-video-creator-cohort-baseline.** Instagram-Reels baseline is 2.4%-4.8% engagement across most cohorts; TikTok-video baseline is 5.1%-9.3% across most cohorts. Pitfall: a creator who is "beauty-creator-cohort" on Instagram-Reels may be "fashion-creator-cohort" on TikTok-video, but the per-cohort-per-format classification collapses them into a single bucket. Fix: compute the creator-cohort per-format, not globally.

7. **Pinterest-tutorial-travel-creator-cohort-treated-as-YouTube-tutorial-travel-creator-cohort.** Both are travel-creator-cohort but they carry different per-SKU-fit-bias baselines (Pinterest-tutorial-travel-creator-cohort -2.4pp vs YouTube-tutorial-travel-creator-cohort -2.6pp). Pitfall: per-format-per-cohort conversion events route through a single travel-creator-cohort path, losing the per-format differential. Fix: split the per-format-per-cohort travel-creator-cohort into 24 separate cells.

8. **spike-creator-cohort-treated-as-zero-impact-cohort.** Spike-creator-cohort is the rarest but highest-value cohort — a parenting-creator-cohort × TikTok-family × spike-creator-cohort post can drive 4-6× baseline impressions in 24h. Pitfall: spike-creator-cohort conversion events are dropped as "outliers" in the analytics. Fix: split the spike-creator-cohort into its own cell with a 15s rate-limit-warning threshold.

9. **spike-creator-cohort-treated-as-over-engaged-cohort.** Spike-creator-cohort is operationally distinct from sustained mature-creator-cohort; it requires 24-hour payment-hold. Pitfall: spike-creator-cohort conversion events route through mature-creator-cohort's path, missing the COPPA-Verifiable-Parental-Consent window. Fix: split the spike-creator-cohort into its own escrow + its own per-cell rollback-engine.

10. **per-creator-cohort-cross-creator-content-format-rollback-engine-firing-globally-instead-of-per-cell.** When the FTC-flag fires on travel-creator-cohort × Pinterest-tutorial, the rollback-engine should suppress ONLY that cell, not all 192 cells. Pitfall: blanket-suppression kills 191 healthy cells. Fix: per-cell rollback-engine with explicit 8 × 24 = 192 discriminator.

11. **per-creator-cohort-cross-creator-content-format-traffic-burst-rollback-engine-firing-on-less-than-60s-rate-limit-warning.** The per-cell traffic-burst rollback should fire at 60s+ rate-limit-warning (NOT less-than-60s, which is normal creator-cohort volatility). Pitfall: false-positive rollback-engine fires on legitimate creator-cohort spikes. Fix: rate-limit-warning threshold = 60s baseline + 30s FTC-Disclosure-2024-flag + 15s FTC-COPPA-flag + 15s spike-creator-cohort.

12. **per-creator-cohort-cross-creator-content-format-aware-payment-fallback-not-wired.** Parenting-creator-cohort × TikTok-family × FTC-COPPA-compliant-tier requires Stripe-Connect escrow with 24-hour payment-hold; parenting-creator-cohort × YouTube-family × FTC-COPPA-compliant-tier requires Tipalti escrow with 24-hour payment-hold; travel-creator-cohort × Pinterest-tutorial × no-disclosure-tier requires auto-suppression. Pitfall: a single Stripe Connect rail serves all 192 cells. Fix: per-cell payment-fallback wired through Move #95 payments-orchestration-routing.

13. **affiliate-network-webhook-stitching-missing-for-at-least-one-affiliate-network-vendor.** Impact, PartnerStack, CreatorIQ, Aspire, GRIN, Upfluence, Klear, and Modash all carry per-creator-cohort × per-creator-content-format webhook signatures. Pitfall: when one vendor's webhook is missed, that vendor's entire creator-cohort × creator-content-format data is dropped. Fix: webhook-stitching health-check on all 8 affiliate-network vendors every 60s.

15. **Move-#41.27-+-Move-#41.26-+-Move-#41.25-+-Move-#41.24-+-Move-#41.23-+-Move-#41.22-+-Move-#41.21-+-Move-#41.20-+-Move-#41.19-+-Move-#41.18-+-Move-#41.17-+-Move-#41.16-+-Move-#41.15-+-Move-#41.14-+-Move-#41.13-+-Move-#41.12-+-Move-#41.11-+-Move-#41.10-+-Move-#41.9-+-Move-#41.8-+-Move-#41.7-+-Move-#41.6-+-Move-#41.5-+-Move-#41.4-+-Move-#41.3-+-Move-#41.2-+-Move-#41.1-+-Move-#41-+-Move-#84-+-Move-#29-+-Move-#16-+-Move-#14-+-Move-#11-+-Move-#47-+-Move-#61-+-Move-#94-+-Move-#95-+-Move-#112-+-Move-#116-+-Move-#120-+-Move-#182-verification-gate-skipped.** Each upstream Move #41.x extension requires its own per-cell verification. Pitfall: a downstream Move #41.27 cell passes the verification gate by accident because the upstream Move #41.26 verification was skipped. Fix: run the verification gate for every Move #41.x dependency before signing off on Move #41.27.
