# Crisis PR operations for DTC ecommerce

> The 24-hour window. A DTC crisis — viral TikTok, product safety issue, founder controversy, supply chain failure, influencer fallout — moves at platform speed. A complaint that would have been an email in 2015 is a TikTok with 500K views by lunch. Mishandled, a single incident destroys 10–40% of brand value within 72 hours; well-handled, the same incident can be a 3–8% loyalty bump and a 6-month PR moat. The 8-phase crisis PR engine (vulnerability audit → social-sentiment-monitor → crisis-classifier → 4-lane response template → 15-min-SLA escalation tree → platform-specific playbooks for 8 channels → post-incident learning ledger → quarterly tabletop) protects the brand at 10:1–50:1 year-1 ROI on retainer + tooling cost. Every operator with >$500k GMV, a founder-led brand, or a TikTok/Instagram-dependent acquisition mix should ship this BEFORE the next crisis hits — not after.

## When to use this skill

You have:

- A Shopify (or Ikas / BigCommerce / WooCommerce) DTC store shipping physical goods OR digital products
- ≥$500k annual GMV OR ≥5,000 monthly email/SMS subscribers
- A founder-led brand OR a brand whose customer trust is load-bearing for conversion (beauty, supplements, food, baby, pet, jewelry, apparel)
- A creator/influencer acquisition mix (TikTok, Instagram, YouTube) where a single creator controversy can cascade
- A presence on third-party listings (Amazon, Walmart, Target) where bad reviews / FDA / CPSC notices spread off-platform
- An incident response team OR a single point-person who can be on-call during a crisis
- A Gorgias or Zendesk OR Kustomer account for ticket routing during a crisis
- A Klaviyo or Postscript or Attentive account for outbound customer comms

You do NOT have:

- A documented crisis PR playbook (the most common DTC gap — 70%+ of brands under $10M have no written crisis protocol)
- Pre-approved holding statements for the 8 high-probability scenarios (product recall, viral TikTok, founder controversy, supply chain failure, influencer fallout, employee misconduct, data breach, third-party scandal)
- A 24/7 on-call rotation with a 15-min response SLA
- A social sentiment monitor with real-time alerts (Brand24, Mention, Brandwatch, Sprout Social, Talkwalker, Sprinklr)
- A dark-site / crisis microsite template pre-staged for the 4 high-probability scenarios
- A pre-drafted FAQ + Q&A document for the 8 scenarios (so legal review doesn't take 8 hours)
- A post-incident learning ledger that feeds back into the playbook (every crisis makes the next one faster to handle)
- A 90-day pre-crisis tabletop exercise calendar (the cheapest insurance money can buy)

## The build (8–16 hours for a competent operator)

### Step 1 — Run the 8-scenario vulnerability audit

For each of the 8 canonical scenarios (product harm / viral TikTok / founder / supply chain / influencer / employee / data / third-party), score on a 3×3 matrix:

```
scenario = {
  product_recall: { probability: 0.10, impact: 0.20, total: 0.020 },
  viral_tiktok: { probability: 0.40, impact: 0.05, total: 0.020 },
  founder_controversy: { probability: 0.10, impact: 0.25, total: 0.025 },
  supply_chain: { probability: 0.15, impact: 0.10, total: 0.015 },
  influencer_fallout: { probability: 0.20, impact: 0.08, total: 0.016 },
  employee_misconduct: { probability: 0.05, impact: 0.05, total: 0.0025 },
  data_breach: { probability: 0.05, impact: 0.10, total: 0.005 },
  third_party: { probability: 0.10, impact: 0.04, total: 0.004 }
}
```

Total risk-adjusted loss = sum(probability × impact) = ~10.7% of brand value per year for a typical $1M–$10M GMV DTC.

That's your ROI justification. A $20k/year retainer + $5k/year tooling costs $25k to potentially save $1M+ of brand value in any given year.

### Step 2 — Build the 8-scenario holding-statement library

For each of the 8 scenarios, write 3 escalation tones (calm / concerned / corrective), pre-approved by legal:

```
TEMPLATE: product_recall_concerned
---
"[Brand] has been made aware of [general issue] affecting [product/SKU]. The safety of our customers is our highest priority. We have [voluntarily paused sales / initiated a voluntary recall / contacted the FDA] and are working with [regulator / supplier / third-party lab] to investigate. Customers who purchased [product/SKU] between [date range] should [specific action — stop use, dispose, contact us for refund]. We will provide a full update within [24 / 48 / 72] hours.

For questions, contact [email / phone / chat]. We are sorry for the concern this causes and will do better.

— [Founder/CEO name]"
```

Wire each of the 24 statements (8 scenarios × 3 tones) into a Notion / Google Doc / Linear "Crisis playbook" template. Legal pre-approval SLA: 24 hours.

### Step 3 — Set up the social-sentiment-monitor with 5-min alert SLA

Pick ONE of: Brand24 / Mention / Talkwalker / Brandwatch / Sprout Social / Sprinklr.

Configure:
- Brand name + 5 common misspellings + 3 hashtag variants
- Founder name + 2 common misspellings
- Top-5 product names + SKUs
- Top-10 creator names (if creator-mix brand)
- Negative-sentiment keywords: recall, lawsuit, sick, dangerous, fail, broken, scam, fraud, false-advertising
- Anomaly-detection: 3-sigma spike in mention volume OR negative-sentiment-ratio

Alert SLA: PagerDuty / Opsgenie page within 5 minutes of threshold breach.

Cost: $200–$2,000/month depending on vendor and brand size.

### Step 4 — Build the 4-lane crisis-classifier + 15-min response tree

```
incident_detected:
  if severity >= 80 (regulatory / safety / mass-casualty): page CEO + Legal + Ops + PR agency
  if severity >= 50 (viral / reputational / creator): page CEO + Marketing Lead + PR agency
  if severity >= 20 (operational / supply chain / employee): page Ops Lead + CX Lead
  if severity < 20 (single customer complaint): route to Gorgias tier-1 macro
```

Severity-score formula (0-100):
- 30 if regulatory (FDA / CPSC / FTC / AG)
- 20 if media-coverage (mainstream news, NYT / WSJ / Bloomberg / TechCrunch)
- 20 if viral (≥10K mentions / 24 hours on TikTok / Twitter / Reddit)
- 15 if creator-driven (creator with >100K followers involved)
- 10 if founder-named (founder is the brand)
- 5 if employee-named
- + impact multiplier (revenue / customer count / inventory at risk)

Wire the tree into PagerDuty / Opsgenie. Test quarterly.

### Step 5 — Pre-stage 4 dark-site / microsite templates

Pre-stage HTML templates for the 4 high-probability scenarios (product recall / supply chain / creator / data breach):

- `crisis.brand.com/recall` — SKU list, batch numbers, refund form, FAQ, contact
- `crisis.brand.com/shipping` — affected orders, expected delay, refund form
- `crisis.brand.com/creator` — statement, what we learned, what we changed
- `crisis.brand.com/security` — what was exposed, what was protected, what we're doing

Deploy from Notion / Linear / Statuspage template within 60 seconds of decision. Statuspage / BetterStack / Instatus / Atlassian Statuspage are the canonical vendors.

### Step 6 — Wire the 5-funnel-stage response cascade

Stage 1 (0-15 min) — Internal alert: PagerDuty / Opsgenie page with severity score + scenario lane
Stage 2 (15 min - 2 hr) — Holding statement: status page, social channels, "we're aware" press line
Stage 3 (2-12 hr) — Full statement: press release + Klaviyo email + Klaviyo SMS + Gorgias auto-reply + Amazon / Walmart listing update
Stage 4 (12 hr - 7 days) — Resolution update: status page + Klaviyo email + in-app banner
Stage 5 (7 days - 6 months) — Recovery: press, content pillars, community, retention flows
Stage 6 (30 days) — Learning ledger: Notion post-mortem + runbook update

Each stage has a pre-approved message template, an owner, an SLA, and an escalation path.

### Step 7 — Build the post-incident learning ledger

For every crisis (real or simulated), write a Notion post-mortem with 4 sections:

1. **Timeline** — minute-by-minute from detection to resolution, with every decision documented
2. **Decisions** — what we decided, why, who was in the room, what we considered
3. **Learnings** — what worked, what didn't, what surprised us
4. **Playbook updates** — the specific lines / processes / vendors we changed because of this crisis

Wire the post-mortem into the next quarterly tabletop exercise (Step 8).

### Step 8 — Run the 90-day pre-crisis tabletop exercise calendar

Quarterly tabletop exercise (4 per year):
- Pick 1-2 of the 8 scenarios
- Simulate the full cascade: PagerDuty page → holding statement → full statement → resolution
- Time the response against the SLA
- Identify gaps in the playbook
- Update the playbook with the learnings

Cost: 2-4 hours per tabletop × 4 per year = 8-16 hours of operator time per year. ROI: 1 well-simulated crisis saves $50k-$500k in real-crisis time.

## Common pitfalls (15 from real builds)

1. **"We'll handle it if it happens"** — the #1 DTC crisis mistake. 70%+ of brands under $10M have no written crisis protocol. By the time the crisis hits, you're already 4-24 hours behind. The fix: ship the 8-scenario holding-statement library BEFORE you need it. Legal pre-approval can happen in a 1-hour quarterly review.

2. **CEO-drafts-on-phone-at-2am** — the second-most-common mistake. The CEO wakes up to a viral TikTok, drafts a 200-word statement on their phone, posts it, and creates a new crisis on top of the original. The fix: holding-statement library with 24 pre-approved statements, decision tree for which one to use, and a 15-min SLA on the agency retainer.

3. **No social-sentiment-monitor** — by the time the CEO wakes up to a viral TikTok, it's already 4-12 hours old and the response window is gone. The fix: Brand24 / Mention / Sprinklr with 5-min alert SLA and 3-sigma anomaly detection. Cost: $200-$2,000/month.

4. **Legal-review-bottleneck** — legal review takes 8-24 hours, by which time the crisis has doubled. The fix: pre-approve the 24 holding statements (8 scenarios × 3 tones) in a quarterly legal review. Full-statement legal review can still happen but the holding statement buys you the first 2 hours.

5. **No status-page** — when the supply chain breaks, customers flood support. "Where's my order?" tickets spike 10-50x. Without a status page, Gorgias queues explode, CX team burns out, response times spike. The fix: Statuspage / BetterStack / Instatus pre-staged with the 4 high-probability scenarios.

6. **Founder-branded-company-without-founder-crisis-plan** — DTC founder brands (Krave Beauty, Glossier, The Honest Company, Hims, Athletic Greens, Bombas) are uniquely vulnerable to founder controversy because the brand = the founder. The fix: a 12-hour SLA founder-crisis playbook that pre-approves (a) the founder stepping back temporarily, (b) the COO/CMO taking over comms, (c) the board / advisor comms, (d) the employee all-hands script.

7. **Holding statement that's actually a denial** — "We do not believe our product caused the illness" reads as defensive, gets roasted on Twitter, makes the full-statement harder. The fix: "We are aware of [situation], we take it seriously, we are investigating, customers who [action] should [action]." Period. No denial in the first 2 hours.

8. **Auto-generated "we apologize for any inconvenience"** — the most-disliked PR phrase. Customers can smell corporate non-apology. The fix: name a person ("Sarah, our head of product safety, will personally oversee the investigation"), name an action ("we've voluntarily paused all sales and contacted the FDA"), name a timeline ("full update by Friday 5pm ET").

9. **Press release without a video statement** — text-only press releases read as evasive in 2024. A 60-90 second video from the founder / CEO is the canonical trust-builder. The fix: pre-record a generic "we take this seriously" video template (no script, just a frame), deploy within 2 hours of detection.

10. **Press release at 5pm Friday** — the canonical bury-the-bad-news move. Customers, media, and regulators see right through it. The fix: hold releases for Tuesday 9am ET, when media and customer attention is highest and the response has the longest tail.

11. **FTC / CPSC / FDA communication without legal** — regulatory comms are legal-first, not comms-first. Sending an FDA recall email without legal pre-approval can create additional liability. The fix: 24-hour legal pre-approval on all product-harm lane statements; PR agency on retainer with a former-FDA-counsel resource.

12. **Influencer-fallout-without-evidence** — when a creator alleges non-payment, the brand's instinct is to deny publicly. This creates a public he-said-she-said that the brand usually loses. The fix: respond with "we take this seriously, we are reviewing our records, we will respond privately with full documentation" — and then actually follow up with the documentation to the creator AND post a public summary 48-72 hours later.

13. **Creator-coordination-failure-during-crisis** — if 50 creators are posting about your product when a crisis hits, you need to coordinate the response with them BEFORE they post their own takes. The fix: a creator-registry in GRIN / Aspire / CreatorIQ / Linqia with a "crisis-mode" toggle that sends all creators a pre-approved holding statement within 30 minutes.

14. **Data-breach-without-72-hour-GDPR-clock** — GDPR requires notification within 72 hours of detection. State laws (CA / NY / TX) have their own clocks. Missing the clock = $10M+ in fines. The fix: 72-hour legal clock pre-staged in the playbook with the data-breach-lane template + the per-state notification list.

15. **No post-incident learning** — the worst mistake is treating the crisis as a one-off. The brand survives, the team breathes a sigh of relief, no one writes the post-mortem, the playbook doesn't get updated, the next crisis hits the same gaps. The fix: 30-day post-incident review with the 4-section Notion template (timeline / decisions / learnings / playbook updates), and feed every learning into the next quarterly tabletop exercise.
