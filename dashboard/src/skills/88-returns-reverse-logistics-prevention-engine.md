## Common pitfalls

1. **No per-portal R1/R2/R3 routing-engine.** Operators launch Loop Returns + ReturnGO + Happy Returns without per-portal R1/R2/R3 routing-rules. Each per-portal has unique R1-route-by-SKU-eligibility + R1-route-by-exchange-catalog-availability + R2-route-by-grade-A-inventory-recovery-priority + R2-route-by-warehouse-tier + R3-route-by-recommerce-handoff-eligibility + R3-route-by-donation-handoff-eligibility + R3-route-by-liquidation-handoff-eligibility. **Fix:** Build per-portal-R1-R2-R3-routing-engine BEFORE launch (Loop + ReturnGO + Happy Returns + AfterShip + ReturnLogic + Narvar + parcelLab + Returnly) with per-portal-route-rules-coverage ≥ 90%.

2. **No per-warehouse-grade-intake-engine.** Operators launch per-portal R1/R2/R3 routing without per-warehouse-grade-intake. Each per-warehouse has unique intake-receipt-grade-A-restock + intake-receipt-grade-B-recommerce-handoff + intake-receipt-grade-C-donation-handoff + intake-receipt-grade-D-liquidation-handoff. **Fix:** per-warehouse-grade-intake-engine with per-warehouse-intake-cycle-time + per-warehouse-inventory-recovery-loop + per-warehouse-grade-rules-coverage.

3. **No AI-grade-classification-engine.** Operators do per-warehouse-grade-intake manually. The reality: beauty-grade-rules-seal-broken + electronics-grade-rules-power-on + jewelry-grade-rules-stone + supplements-grade-rules-seal differs dramatically from apparel-grade-rules-size. **Fix:** AI-grade-classification-engine [ReturnGO-AI-grade + ReturnGO-photo-grade + ReturnGO-text-grade + ReturnGO-SKU-grade + Loop-Forecasting-grade + Happy-Returns-forecasting-grade] with per-warehouse-AI-grade-classification.

4. **No RFID-tagged-return-intake.** Operators launch per-warehouse-grade-intake without RFID-tagged-return-intake. The canonical failure: a grade-A restock takes 7+ days to find in the bin because RFID wasn't tagged at intake. **Fix:** RFID-tagged-return-intake [Shopify-RFID + Cin7-RFID + ShipHero-RFID + Extensiv-RFID + Stord-RFID + Optoro-RFID] with per-RFID-tag-intake-workflow + per-RFID-tag-grade-route + per-RFID-tag-relabel.

5. **No per-vertical-returns-routing-engine.** Operators launch AI-grade-classification without per-vertical-returns-routing. Each vertical has unique grade-rules. **Fix:** per-vertical-returns-routing [apparel + beauty + electronics + home + pet + footwear + jewelry + supplements] with per-vertical-grade-rules.

6. **No per-recommerce-handoff-engine.** Operators launch per-warehouse-grade-intake without per-recommerce-handoff. Each recommerce partner has unique grade-handler + pricing. **Fix:** per-recommerce-handoff [ThredUp + RealReal + Vestiaire + Rebag + StockX + GOAT + Back Market + Refurbed + Trove + Archive + Recurate + Amazon Renewed + Walmart Restored + Best Buy Refurbished + Apple Refurbished + Samsung Renewed + Microsoft Refurbished + Target Pre-Owned + eBay Refurbished] with per-recommerce-partner-grade-handler + per-recommerce-handoff-pricing.

7. **No per-recommerce-cohort-LTV-overlay.** Operators launch per-recommerce-handoff without per-recommerce-cohort-LTV-overlay. The canonical failure: recommerce revenue is correct per-partner but recommerce-overlap-cohort-LTV is wrong (same customer is in 2 recommerce channels). **Fix:** per-recommerce-cohort-LTV-overlay [Triple-Whale-recommerce-cohort-LTV + Polar-recommerce-cohort-LTV + Northbeam-recommerce-cohort-LTV] with per-recommerce-cohort-overlap-de-dup.

8. **No circular-economy-loop-engine.** Operators launch per-recommerce-handoff without circular-economy-loop. The canonical failure: brand-launches-Patagonia-Worn-Wear-without-trade-in-pricing-strategy. **Fix:** circular-economy-loop [Patagonia-Worn-Wear + Eileen-Fisher-Renew + The-North-Face-Renewed + Levis-Secondblue + REI-Re/Supply + Backcountry-Used + Apple-Trade-In + Samsung-Trade-In + Best-Buy-Trade-In + Gamestop-Trade-In + Microsoft-Trade-In + Dell-Trade-In + HP-Trade-In + Sony-Trade-In] with per-circular-economy-program-trade-in-credit-pricing.

9. **No donation-handoff-engine.** Operators launch per-warehouse-grade-intake without donation-handoff.
