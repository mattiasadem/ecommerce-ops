## When to use this skill

Use Move #41.29 — creator-engagement-rate-tier-cross-FTC-disclosure-tier-overlay — when ANY of the following are true:

1. **You run paid or organic creator campaigns across 4+ creator-engagement-rate-tiers (high-engagement-tier + medium-engagement-tier + low-engagement-tier + nano-engagement-tier + spike-engagement-tier) AND must show different FTC-disclosure-tier treatments per engagement-tier (e.g. high-engagement-tier carries the FTC-COPPA-compliant-tier verdict because it has reach to under-13 audiences; medium-engagement-tier carries the hashtag-disclosure-#ad-tier verdict as the canonical 2024 FTC-Disclosure §255.5 baseline; low-engagement-tier carries the no-disclosure-tier verdict because audience-fatigue obscures disclosure visibility; nano-engagement-tier carries the dedicated-disclosure-page-tier verdict because the FTC requires explicit material-connection statements; spike-engagement-tier carries the in-line-disclosure-tier verdict because the spike window demands visible disclosure inside the creator-content-format itself).** Without this skill the per-creator-engagement-rate-tier fallback collapses into a single "all engagement tiers share the same FTC-disclosure-tier" rule that breaks FTC-Disclosure-2024 §255.5 (the 2024 guidance that mandates per-engagement-tier-per-disclosure-tier differentiation — high-engagement-tier × FTC-COPPA-compliant-tier is NOT comparable to high-engagement-tier × no-disclosure-tier).
2. **You have a 2024 creator-engagement-rate-spike (a creator-engagement-rate-tier × FTC-disclosure-tier cell suddenly spikes 4-6× its baseline, e.g. a spike-engagement-tier × in-line-disclosure-tier post goes from 50K to 800K impressions in 24h during a TikTok-Q4-BFCM-Spike) and need to scope creator-engagement-rate-spike separately from baseline-creator-engagement-rate-tier + mature-creator-engagement-rate-tier + emerging-creator-engagement-rate-tier, because creator-engagement-rate-spike triggers a separate rate-limit-warning threshold (15s vs the 60s baseline).**
3. **You operate across multi-network creator marketplaces (LTK + Collective Voice + ShopStyle + RewardStyle/LiketoKnow.it + Amazon Live + TikTok Shop + Pinterest Creator Commerce + YouTube Shopping + Amazon-Influencer + Walmart-Connect + Target-Partner-Influencer-Program + Best-Buy-Influencer-Program) AND each marketplace enforces its OWN creator-engagement-rate-tier × FTC-disclosure-tier floor (Amazon Live requires FTC-COPPA-compliant-tier on high-engagement-tier + spike-engagement-tier; TikTok Shop requires hashtag-disclosure-tier on medium-engagement-tier + low-engagement-tier + creator-disclosure-network-tier on dedicated-disclosure-page-tier; LTK requires in-line-disclosure-tier on spike-engagement-tier + dedicated-disclosure-page-tier on nano-engagement-tier). Without Move #41.29 the per-creator-engagement-rate-tier × per-FTC-disclosure-tier cell reads as a single normalized "creator-engagement-rate-tier × FTC-disclosure-tier score" and the operator loses the ability to see WHICH engagement-tier-disclosure cell is the leak.**
4. **You have a current or pending 2024 FTC-Enforcement-Office investigation or have received a FTC-disclosure warning letter.** The granular 4 × 8 = 32-cell creator-engagement-rate-tier × FTC-disclosure-tier matrix lets you prove per-engagement-tier-per-disclosure-tier compliance and is a load-bearing artifact in any FTC-Disclosure-2024 §255.5 response (the FTC explicitly weights creator-engagement-rate-tier when determining "material connection" disclosure scope — high-engagement-tier × FTC-COPPA-compliant-tier is the highest-risk 2024 disclosure cell).
5. **You are seeing a return-rate differential across creator-engagement-rate-tiers that you can't explain with fit-bias alone.** The most common cause is that nano-engagement-tier and spike-engagement-tier creator-engagement-rate-tiers carry the WORST per-SKU-fit-bias profile (nano-engagement-tier has the lowest absolute reach AND the highest FTC-Disclosure-2024 §255.5 violation rate; spike-engagement-tier has the highest FTC-COPPA-flag rate because of under-13 reach during viral spikes) and the FTC-flagged engagement-rate-tier content triggers customer-side suspicion + return-rate spikes that look like a fit-bias problem but are actually a creator-engagement-rate-tier-mismatch problem.
6. **You ship 3+ Move #41.17 FTC-disclosure-tier-derived tiers to a Meta-Conversion-API + TikTok-Events-API + Pinterest-Conversions-API + YouTube-Data-API attribution stream** and need per-creator-engagement-rate-tier × per-FTC-disclosure-tier attribution to feed back into bid, creative, message, audience, experimentation, suppression, pricing, attribution-decision, channel-orchestration, segment-strategy, and product-discovery engines.
7. **You want to ship per-creator-engagement-rate-tier × per-FTC-disclosure-tier rollback-engine (auto-suppress a creator-engagement-rate-tier × FTC-disclosure-tier cell when the FTC-flag or rate-burst-spike fires, vs blanket-suppress all tiers)** — the per-cell rollback precision is the difference between suppressing one bad creator-engagement-rate-tier × FTC-disclosure-tier cell and nuking a healthy engagement-tier.
