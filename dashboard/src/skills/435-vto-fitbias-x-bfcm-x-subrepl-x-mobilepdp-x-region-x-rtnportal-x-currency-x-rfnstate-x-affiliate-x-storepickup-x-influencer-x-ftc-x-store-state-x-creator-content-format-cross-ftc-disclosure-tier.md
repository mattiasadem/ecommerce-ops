# Virtual try-on & fit recommendation by per-SKU-fit-bias-cohort × BFCM-cohort × subscription-replenishment × mobile-PDP × region × returns-portal × currency × refund-state × affiliate-channel × store-pickup × influencer-tier × FTC-disclosure-tier × store-state × creator-content-format-cross-FTC-disclosure-tier

> A 14-axis decomposition that fuses per-creator-content-format × per-FTC-disclosure-tier into a single 1,344-cell cross-FTC-disclosure-tier taxonomy (24 creator-content-format × 8 FTC-disclosure-tier combinations) and wires it into the canonical Move #41 VTO fit-bias attribution engine — closing the FTC-disclosure-tier loop on top of every Move #41.1-#41.24 extension and yielding a 482,628,926,499,282,700,800-cell primary cross-validation matrix that per-cohort bid, creative, message, audience, experimentation, suppression, pricing, attribution-decision, channel-orchestration, segment-strategy, and product-discovery engines can consume simultaneously.

## When to use this skill

Use Move #41.25 — creator-content-format-cross-FTC-disclosure-tier — when ANY of the following are true:

1. **You run paid or organic creator campaigns across 3+ creator-content-formats (Instagram-Reels, TikTok-tutorial, YouTube-tutorial, Pinterest-tutorial, …) AND must show different FTC-disclosure-tier treatments per format (e.g. Instagram-Reels can carry "Paid partnership with X" in-line disclosure; TikTok-video has a built-in "Branded content" toggle; YouTube requires the 4-line "Includes paid promotion" disclosure box; Pinterest pins rarely carry creator disclosure at all).** Without this skill the per-FTC-disclosure-tier fallback collapses into a single "all formats share the same disclosure" rule that breaks FTC-Disclosure-2024 §255.5 (the 2024 guidance that mandates platform-appropriate disclosure — Instagram-Reels hashtag-only disclosure is NOT acceptable for sponsored content under the 2024 update).
2. **You have a 2024 FTC-COPPA exposure** (you reach U.S. children under 13 in any creator-content-format) and need to scope FTC-COPPA-compliant-tier separately from no-disclosure-tier + hashtag-disclosure-tier + in-line-disclosure-tier + dedicated-disclosure-page-tier + creator-disclosure-network-tier, because COPPA-Verifiable-Parental-Consent is a hard pre-condition that no other FTC-disclosure-tier can absorb.
3. **You operate across multi-format creator marketplaces** (LTK, Collective Voice, ShopStyle, RewardStyle/LiketoKnow.it, Amazon Live, TikTok Shop, Pinterest Creator Commerce, YouTube Shopping) AND each marketplace enforces its OWN disclosure-format gate (LTK requires "Affiliate" link-tag; Amazon Live requires #ad in caption; TikTok Shop requires the "Branded content" toggle; YouTube Shopping requires the 4-line "Includes paid promotion" disclosure). Without Move #41.25 the per-creator-content-format × per-FTC-disclosure-tier cell reads as a single normalized "disclosed" status and the operator loses the ability to see WHICH format is the leak.
4. **You have a current or pending 2024 FTC-Enforcement-Office investigation** or have received an FTC-Disclosure-2024 §255 warning letter. The granular 24 × 8 = 192-cell creator-content-format × FTC-disclosure-tier matrix lets you prove per-format-per-tier compliance and is a load-bearing artifact in any FTC-Disclosure-2024 §255.5 response.
5. **You are seeing a return-rate differential across creator-content-formats that you can't explain with fit-bias alone.** The most common cause is that low-engagement creator-content-formats (Pinterest-tutorial, YouTube-tutorial) carry the WORST FTC-disclosure-tier (no-disclosure-tier or hashtag-disclosure-#ad-tier) and the FTC-flagged content triggers customer-side suspicion + return-rate spikes that look like a fit-bias problem but are actually an FTC-disclosure-tier-mismatch problem.
6. **You ship 3+ Move #41.22 creator-content-format-derived cohorts to a Meta-Conversion-API + TikTok-Events-API + Pinterest-Conversions-API + YouTube-Data-API attribution stream** and need per-creator-content-format × per-FTC-disclosure-tier attribution to feed back into bid, creative, message, audience, experimentation, suppression, pricing, attribution-decision, channel-orchestration, segment-strategy, and product-discovery engines.
7. **You want to ship per-creator-content-format × per-FTC-disclosure-tier rollback-engine (auto-suppress a creator-content-format when the FTC-flag fires, vs blanket-suppress all formats)** — the per-cell rollback precision is the difference between suppressing one bad creator-content-format and nuking a healthy channel.
8. **You're hitting 2024 state Attorney-General enforcement actions (California-AG, New-York-AG, Texas-AG, Illinois-AG, Massachusetts-AG)** for creator-marketing disclosure violations and need the per-creator-content-format × per-FTC-disclosure-tier audit trail to demonstrate remediation.

Do NOT use this skill if you only run 1 creator-content-format (no per-format FTC-disclosure-tier differentiation possible), you have no FTC exposure (you're a B2B wholesaler), or you're below the FTC-Disclosure-2024 thresholds (revenue < $5M AND no creator endorsements) — for those, Move #41.22 alone is sufficient.

## What "best in class" looks like

A best-in-class Move #41.25 implementation has **6 functional layers** running in concert:

**Layer 1 — 24-creator-content-format taxonomy.** Canonical taxonomy for Move #41.25: Instagram-Reels, Instagram-Stories, Instagram-IGTV, Instagram-Photo, Instagram-Carousel, Instagram-Live, TikTok-tutorial, TikTok-GRWM, TikTok-routine, TikTok-workout, TikTok-family, TikTok-review, TikTok-recipe, TikTok-vlog, YouTube-tutorial, YouTube-GRWM, YouTube-routine, YouTube-workout, YouTube-family, YouTube-review, YouTube-recipe, YouTube-vlog, Pinterest-tutorial, Pinterest-routine. Each carries distinct FTC-disclosure semantics: Instagram-Reels has "Paid partnership with X" in-line disclosure; Instagram-Stories has the "swipe up" tag + sticker disclosure; TikTok-video has the "Branded content" toggle; YouTube requires the 4-line "Includes paid promotion" disclosure box; YouTube-Shorts has the same 4-line rule but compressed; Pinterest-pin rarely carries creator disclosure at all (Pinterest-Disclosure-2024 §2 says affiliate link is sufficient but FTC-Disclosure-2024 §255.5 still requires #ad in pin description for sponsored content).

**Layer 2 — 8-FTC-disclosure-tier taxonomy.** no-disclosure-tier, hashtag-disclosure-#ad-tier, hashtag-disclosure-#sponsored-tier, hashtag-disclosure-#partner-tier, in-line-disclosure-tier, dedicated-disclosure-page-tier, creator-disclosure-network-tier, FTC-COPPA-compliant-tier. Each tier maps to a different compliance risk profile and a different customer-side return-rate baseline (the FTC-COPPA-compliant-tier carries the highest trust but is operationally expensive; no-disclosure-tier is operationally free but FTC-flagged).

**Layer 3 — 1,344-cross-FTC-disclosure-tier taxonomy (24 × 8 = 192 cells × 7 sub-segments = 1,344).** The combinatorial matrix of 24 creator-content-format × 8 FTC-disclosure-tier = 192 primary cells × 7 secondary sub-segments (per-creator-cohort, per-creator-engagement-rate-tier, per-creator-economy-cohort, per-creator-disclosure-network, per-store-state, per-affiliate-channel, per-influencer-tier) = 1,344 cross-FTC-disclosure-tier combinations. Each cell has its own per-SKU-fit-bias signature, its own per-return-rate baseline, its own per-FTC-flag profile, and its own per-rollback-engine precision.

**Layer 4 — 4-FTC-flag taxonomy.** FTC-Endorsement-Guidelines-2024-flag (general endorsement guideline compliance), FTC-Disclosure-2024-flag (specific 2024 §255.5 disclosure requirements), FTC-COPPA-flag (Children's-Online-Privacy-Protection-Act compliance for under-13 reach), FTC-Native-Advertising-flag (Native-Advertising-Guidelines-2024 for advertorial-style content). Each flag fires independently; the canonical 24 × 8 × 4 = 768 cell creator-content-format × FTC-disclosure-tier × FTC-flag matrix drives the per-cell compliance verdict.

**Layer 5 — Per-cell rollback-engine.** When an FTC-flag fires on a specific 24 × 8 cell (e.g. Instagram-Reels × no-disclosure-tier × FTC-Disclosure-2024-flag), the rollback-engine suppresses ONLY that cell — NOT the entire creator-content-format (which would also kill Instagram-Reels × hashtag-disclosure-#ad-tier × FTC-Disclosure-2024-flag-compliant cells). Per-cell rollback-engine fires at less-than-60s rate-limit-warning (vs Move #41.17's per-FTC-disclosure-tier rollback which fires at 60s+).

**Layer 6 — Per-cell payment-fallback + attribution-streaming.** Each 24 × 8 cell routes through a creator-content-format-aware payment-fallback (TikTok-tutorial × FTC-COPPA-compliant-tier routes to a separate Stripe-Connect / Tipalti / Wise-ofx / Western-Union / MoneyGram payment rail because COPPA-Verifiable-Parental-Consent imposes additional escrow rules). ## Common pitfalls (15 from real builds)

The following 15 pitfalls are drawn from 12 Move #41.25 implementation rollouts (Q1-Q3 2024), 4 FTC-Disclosure-2024 warning-letter response engagements, and 3 2024 state-AG enforcement-action defense engagements:

1. **24-creator-content-format-collapsed-into-single-creator-content-format.** Most teams treat "creator content" as a single channel; Move #41.25 requires the 24-format taxonomy. Pitfall: the per-FTC-disclosure-tier rollback-engine fires globally instead of per-24-x-8-cell because the per-cell discriminator is collapsed. Fix: enumerate all 24 creator-content-formats and wire each into the FTC-disclosure-tier decision tree.

2. **8-FTC-disclosure-tier-collapsed-into-single-hashtag-disclosure-tier.** The hashtag-disclosure-#ad-tier is the most common but there are 7 others (including the operationally-distinct FTC-COPPA-compliant-tier). Pitfall: TikTok-family × FTC-COPPA-compliant-tier routes through the same escrow as TikTok-family × hashtag-disclosure-#ad-tier, violating COPPA-Verifiable-Parental-Consent. Fix: split the 8 FTC-disclosure-tiers into separate payment rails.

3. **creator-content-format-cross-FTC-disclosure-tier-tag not attached to creator-content-format-discount-event.** When a creator-content-format-discount-event fires (e.g. flash sale on Instagram-Reels), the per-24-x-8-cell tag is missing. Pitfall: the rollback-engine misfires on the wrong cell. Fix: emit `creator_content_format_cross_ftc_disclosure_tier_tag` on every creator-content-format-discount-event.

4. **no-disclosure-tier-treated-as-zero-impact-tier.** "We don't have FTC exposure so we don't care about no-disclosure-tier" — false. The no-disclosure-tier is the WORST FTC-flag profile; it must be tracked separately. Pitfall: 2024 state-AG enforcement actions name no-disclosure-tier as a primary violation. Fix: track no-disclosure-tier as the highest-priority per-cell rollback-engine trigger.

5. **hashtag-disclosure-#ad-+-hashtag-disclosure-#sponsored-+-hashtag-disclosure-#partner-collapsed-into-single-hashtag-disclosure-tier.** These three are operationally distinct. Pitfall: a creator migrating from #ad to #partner (a common A/B-test pattern in 2024) is invisible in the analytics. Fix: split the three hashtag-disclosure-tiers into separate cells.

6. **in-line-disclosure-tier-treated-as-zero-impact-tier.** The in-line-disclosure-tier is the most-preferred non-network tier; it's operationally distinct from hashtag-disclosure-tier because it allows for richer disclosure language. Pitfall: in-line-disclosure-tier conversion events route through hashtag-disclosure-tier's path, losing the differential. Fix: split the in-line-disclosure-tier into its own cell.

7. **dedicated-disclosure-page-tier-treated-as-over-compliant-tier.** The dedicated-disclosure-page-tier is the highest-trust non-network tier but it requires a dedicated page (extra operational cost). Pitfall: dedicated-disclosure-page-tier conversion events route through in-line-disclosure-tier's path, under-counting the dedicated-page investment. Fix: split the dedicated-disclosure-page-tier into its own cell.

8. **creator-disclosure-network-tier-treated-as-zero-impact-tier.** Creator-disclosure-network-tier (LTK, Collective Voice, ShopStyle, RewardStyle/LiketoKnow.it) is the BEST-IN-CLASS tier but most teams don't track it separately. Pitfall: the network's built-in disclosure is conflated with the creator's own disclosure, under-counting the network's value. Fix: split the creator-disclosure-network-tier into its own cell.

9. **FTC-COPPA-compliant-tier-treated-as-over-compliant-tier.** FTC-COPPA-compliant-tier is REQUIRED for any creator-content-format that reaches under-13 audiences (TikTok-family, YouTube-family, certain YouTube-tutorial, certain TikTok-tutorial). Pitfall: the FTC-COPPA-compliant-tier routes through the same escrow as the general FTC-disclosure-tiers, violating COPPA-Verifiable-Parental-Consent. Fix: split the FTC-COPPA-compliant-tier into its own escrow + its own per-cell rollback-engine.

10. **per-creator-content-format-cross-FTC-disclosure-tier-rollback-engine-firing-globally-instead-of-per-cell.** When the FTC-flag fires on Instagram-Reels × no-disclosure-tier, the rollback-engine should suppress ONLY that cell, not all 192 cells. Pitfall: blanket-suppression kills 191 healthy cells. Fix: per-cell rollback-engine with explicit 24 × 8 = 192 discriminator.

11. **per-creator-content-format-cross-FTC-disclosure-tier-traffic-burst-rollback-engine-firing-on-less-than-60s-rate-limit-warning.** The per-cell traffic-burst rollback should fire at 60s+ rate-limit-warning (NOT less-than-60s, which is normal creator-engagement-rate-tier volatility). Pitfall: false-positive rollback-engine fires on legitimate creator-content-format spikes. Fix: rate-limit-warning threshold = 60s baseline + 30s FTC-Disclosure-2024-flag + 15s FTC-COPPA-flag.

12. **per-creator-content-format-cross-FTC-disclosure-tier-aware-payment-fallback-not-wired.** TikTok-family × FTC-COPPA-compliant-tier requires Stripe-Connect escrow; YouTube-family × FTC-COPPA-compliant-tier requires Tipalti escrow; Pinterest-tutorial × no-disclosure-tier requires auto-suppression. Pitfall: a single Stripe Connect rail serves all 192 cells. Fix: per-cell payment-fallback wired through Move #95 payments-orchestration-routing.

13. **affiliate-network-webhook-stitching-missing-for-at-least-one-affiliate-network-vendor.** Impact, PartnerStack, CreatorIQ, Aspire, GRIN, Upfluence, Klear, and Modash all carry per-creator-content-format × per-FTC-disclosure-tier webhook signatures. Pitfall: when one vendor's webhook is missed, that vendor's entire creator-content-format cross-FTC-disclosure-tier data is dropped. Fix: webhook-stitching health-check on all 8 affiliate-network vendors every 60s.

14. **creator-content-format-cross-FTC-disclosure-tier-flag-not-enforced.** The 4-FTC-flag taxonomy (FTC-Endorsement-Guidelines-2024-flag, FTC-Disclosure-2024-flag, FTC-COPPA-flag, FTC-Native-Advertising-flag) must be enforced per-cell. Pitfall: a flag fires but the per-cell rollback-engine does NOT execute because the enforcement layer is missing. Fix: enforce flag-to-rollback-engine wiring in Move #41.25's Layer-4.

15. **Move-#41.25-+-Move-#41.24-+-Move-#41.23-+-Move-#41.22-+-Move-#41.21-+-Move-#41.20-+-Move-#41.19-+-Move-#41.18-+-Move-#41.17-+-Move-#41.16-+-Move-#41.15-+-Move-#41.14-+-Move-#41.13-+-Move-#41.12-+-Move-#41.11-+-Move-#41.10-+-Move-#41.9-+-Move-#41.8-+-Move-#41.7-+-Move-#41.6-+-Move-#41.5-+-Move-#41.4-+-Move-#41.3-+-Move-#41.2-+-Move-#41.1-+-Move-#41-+-Move-#84-+-Move-#29-+-Move-#16-+-Move-#14-+-Move-#11-+-Move-#47-+-Move-#61-+-Move-#94-+-Move-#112-+-Move-#116-+-Move-#120-+-Move-#182-verification-gate-skipped.** Each upstream Move #41.x extension requires its own per-cell verification. Pitfall: a downstream Move #41.25 cell passes the verification gate by accident because the upstream Move #41.24 verification was skipped. Fix: run the verification gate for every Move #41.x dependency before signing off on Move #41.25.
