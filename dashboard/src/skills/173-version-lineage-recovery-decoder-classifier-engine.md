1. **Auto-classifier false-positive on Move-#155 fire without Move-#171-version-2-rollback.** The `classifier-1-auto` path emits when Move-#155-rollback-decision-status-classifier fires `rollback: required` even if Move-#171-version-lineage-overlay did NOT simultaneously emit `version-2-rollback`. **Fix:** the auto-classifier co-fire detector requires BOTH signals within the canonical 100ms window per UCP-version-lineage-recovery-decoder-classifier-auto-2026; a single signal fire tags as `classifier-3-system` instead, never `classifier-1-auto`.
2. **Operator-classifier session-staleness on long-running operator-UX-flow.** The `classifier-2-operator` path's operator-UX-flow session at `/version-lineage-recovery-decoder` expires after 30min of inactivity, causing the operator's manual backfill to lose its classifier tag. **Fix:** pin the operator-UX-flow session to `ecom-ops:version-lineage-recovery-decoder-classifier:v1` localStorage with a 24h TTL per UCP-version-lineage-recovery-decoder-classifier-operator-2026; the classifier tag is rehydrated on session resume.
3. **System-classifier cron double-fire on overlapping windows.** The `*/5 * * * *` `classifier-3-system` cron-job double-fires when a previous batch-rebuild job is still running. **Fix:** add a per-version-lineage-recovery-decoder-classifier-system job-lock using the canonical Move-#155-rollback-decision-status-classifier `cluster_key` as the lock-key per UCP-version-lineage-recovery-decoder-classifier-system-2026; the lock TTL is 4min (less than the 5min cron interval).
