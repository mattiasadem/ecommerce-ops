## Common pitfalls (15 from real builds)

1. **Per-question canonical-control-citation-table is wrong per carrier.** Coalition Q1 insists on NIST CSF 2.0 ID.AM-2 + ISO 27001:2022 A.5.9 + SOC 2 CC6.1; At-Bay Q1 insists on NIST SP 800-171 + SOC 2 Type II + ISO 27001:2022 — but a naive canonical-rules-engine uses ONE canonical-control-citation-table for all 8 carriers. Result: Coalition rejects the renewal-questionnaire at the first review. **Fix:** Each of the 96 canonical-questions has 8 per-carrier-control-citation-tables (Coalition / At-Bay / Beazley / Travelers / Hiscox / Chubb / AIG / NAS), keyed off the canonical-corpus-library.

2. **Canonical-tone-mapping differs by carrier AND by question.** Coalition expects concise-technical-250-words-max across all 12 questions; At-Bay expects narrative-incident-led-500-words-allowed; Beazley expects evidence-anchored; Travelers expects policy-imperative. A canonical-engine that applies ONE tone-mapping across all carriers rejects At-Bay's "narrative-led" answers. **Fix:** Per-question × per-carrier-tone-mapping (96 canonical-questions × 8 carriers × 6 canonical-tones = 4,608 tone-cells), keyed off `canonicalRule.canonicalToneMapping[carrier]`.

3. **Canonical-cohort-tier-aware-rephrasing rephrases incorrectly for LAPSED-COALITION-MERGEBOOK canonical-question-answer state.** Lapsed-cohort Q1 canonical-rule should surface "lapsed-cohort-segment-enforcement of password-rotation per last-touch Q4-2025 — REACTIVATION-FOCUSED", but a naive canonical-engine applies B2B-cohort-tier-aware-rephrasing-defaults. Result: lapsed-cohort-renewal-questionnaire surfaces B2B-cohort answers (wrong cohort-tier-aware-rephrasing). **Fix:** Per-rule-cohort-tier-aware-rephrasing (7 cohorts × 14 RCA-categories × 8 carriers = 784 cohort-tier-aware-rephrasing-tags), keyed off `canonicalRule.cohortTierAwareRephrasing[cohortKey][rcaCategory]`.

4. **Engineer-sign-off-trail is missing canonical-content-hash AND canonical-version-lineage.** Without canonical-content-hash, future canonical-rule-drift (per-renewal-cycle carrier-questionnaire-version-update like Coalition v4 → v4.1) silently drifts the canonical-rule and the renewal-PDF carries stale canonical-rules. Without canonical-version-lineage, the engineer cannot roll back a canonical-rule to a prior canonical-rephrasing-rule-version within 24h pre-renewal. **Fix:** Per-canonical-rule 7-element-engineer-sign-off-trail-emit (engineer-id + engineer-review-timestamp + engineer-review-version + per-rule-canonicalization-iteration-number + per-rule-source-rule-record-citation-verbatim + content-hash + counsel-of-record-review-trail + canonical-version-lineage).

5. **Counsel-of-record-pre-flight-canonicalization-gate is missing statute-bar-association.** A canonical-rule that doesn't carry counsel-statute-bar-association (Foley Hoag + Latham + Goodwin Procter + BCLP + Manatt + AdLaw 2024) means the engineer cannot defend the canonical-rule if a future consent-decree challenges it. **Fix:** Per-canonical-rule counsel-of-record-review with statute-bar-association — the canonical-rule records which counsel-of-record (Foley Hoag = Massachusetts + New York + California; Latham = California + New York; Goodwin Procter = Massachusetts + California; BCLP = California + Texas; Manatt = California + New York; AdLaw = California-state-AG) reviewed the rule, with timestamp + review-version + statute-bar-association.

6. **Pre-fill-canonicalization-pipeline runs on a 30-day batch cadence.** A daily cadence catches Coalition v4 → v4.1 transitions before they affect the renewal-PDF, but a 30-day batch cadence applies stale canonical-rules to the renewal-PDF. **Fix:** Pre-fill-canonicalization-pipeline runs on a daily cadence + an additional per-renewal-cycle-cadence run for the 14d Coalition / 30d At-Bay / 21d Beazley / 60d Travelers / 45d Hiscox / 30d Chubb / 30d AIG / 21d NAS windows.

7. **Canonical-rule canonical-pre-flight-rollback window is missing or too short.** A canonical-rule-pre-flight-rollback-window < 24h pre-renewal means the counsel-of-record cannot roll back a canonical-rule if a carrier-counter-engine fires within 24h of the renewal-window. **Fix:** Per-rule canonical-pre-flight-rollback window = 24h pre-renewal / 30d post-renewal (covers the canonical renewal-meeting-window AND the canonical contestation-window).

8. **Per-carrier-counter-engine-classifier is missing the 8-carrier-counter-engine-mapping.** A canonical-rule that doesn't emit a `carrierCounterEngine` token means the pre-fill-canonicalization doesn't fire the canonical-counter-engine (CounterCoalitionCohortTierDowngrade / CounterAtBayPolicyNonRenewal / CounterBeazleyPremiumDoubling / CounterTravelersPerCohortBurnRateFloor / CounterHiscoxBlendedRateSpike / CounterChubbPerCohortBurnRateFloor / CounterAIGRecurrencePreventionScoreThreshold / CounterNasCorrectionRateFloor) when the carrier-renewal-meeting pushes back. **Fix:** Per-canonical-rule `canonicalCarrierCounterEngine: 'CounterCoalitionCohortTierDowngrade'` field emitted in every canonical-rule-record.

9. **Per-cohort × per-RCA canonical-rule-coverage defaults to ALL 7 cohorts × ALL 14 RCAs.** A canonical-rule that defaults to "all cohorts × all RCAs" silently includes the wrong answer for cohort-tier-specific canonical-rules (e.g. lapsed-cohort-rule surfaces ALL-7-cohorts answer; expected = lapsed-cohort-only). **Fix:** Per-canonical-rule canonical-cohort-coverage-flag (default = all 7) + canonical-RCA-coverage-flag (default = all 14) + per-cohort-cohort-coverage-content-hash so future cohort-coverage-drift fires a regression-alert.

10. **Per-quarter canonical-corpus-rebuild drift is undetected.** Coalition v4 12-tab Excel was published 2025-Q2; if Coalition publishes v5 in Q4-2026, the canonical-corpus-library silently retains v4 rules and the renewal-PDF surfaces stale canonical-rules. **Fix:** Per-quarter canonical-corpus-rebuild + canonical-version-lineage-recovery + canonical-corpus-drift-detection-alert (the per-quarter rebuild emits a `corpusDriftDetected: true` flag and a canonical-corpus-version-lineage-recovery record).

11. **Per-carrier canonical-rule is missing carrier-counter-engine-classifier for cohort-tier-downgrade-counter.** Coalition expects the canonical-rule to emit `CounterCoalitionCohortTierDowngrade` (a counter-engine that fires if Coalition pushes back on the cohort-tier-bump from B2B-tier to VIP-tier). Without this, the pre-fill-canonicalization-rule doesn't fire the counter-engine when Coalition-meeting negotiations arise. **Fix:** Per-carrier canonical-rule emits the carrier-counter-engine-classifier as part of the canonical-rule-record (8 canonical-carrier-counter-engines × 12 canonical-questions × 7 cohorts × 14 RCA-categories = 9,408 counter-engine-mappings).

12. **Per-canonical-rule counsel-of-record-review is missing the 3-party sign-off chain (engineer + counsel + chief-security-officer).** A canonical-rule signed by the engineer but NOT by counsel-of-record AND chief-security-officer fails the per-consent-decree chain-of-custody requirement (Foley Hoag 2024 + Latham 2024 + Goodwin Procter 2024 + BCLP 2024 + Manatt 2024 + AdLaw 2024 consent-decree corpora). **Fix:** Per-canonical-rule canonical-engineer-sign-off chain-of-custody = engineer-of-record + counsel-of-record + chief-security-officer, each with sign-off-trail (id + timestamp + version + statute-bar-association).

13. **Per-canonical-rule audit-log is missing the 14-RCA-category attribution.** A canonical-rule that doesn't carry per-RCA-category-attribution (phishing / credential-stuffing / supply-chain / bot-mitigation / 3PL-outage / chargeback-cluster / refund-abuse / ransomware / BEC / social-engineering / API-exploit / SaaS-misconfig / insider / zero-day) means the renewal-PDF cannot answer "did this canonical-rule address the carrier's per-RCA-category concern?" **Fix:** Per-canonical-rule per-RCA-coverage-flag (14 RCA-categories) + per-RCA-canonical-coverage-content-hash.

14. **Per-canonical-rule canonical-version-lineage-recovery is missing per-renewal-cycle.** A canonical-rule that doesn't carry a `versionLineage: { v1: ... , v2: ... , v3: ... }` record means the engineer cannot roll back to a prior canonical-rule-version within 24h pre-renewal. **Fix:** Per-canonical-rule canonical-version-lineage-recovery record (emits per-renewal-cycle + per-quarter-cadence version-lineage); auditable for 7 years per FTC retention-rule + SEC OCFR 249p 2024 + consent-decree 7-year-statute-of-limitations.

15. **Per-canonical-rule canonical-pre-flight-rollback-window is missing counsel-of-record-override.** A canonical-rule that allows ONLY engineer-rollback but NOT counsel-of-record-override fails the canonical-consent-decree-defensibility-test (Foley Hoag 2024 + Latham 2024 + Goodwin Procter 2024 + BCLP 2024 + Manatt 2024 + AdLaw 2024 settlement-averages). **Fix:** Per-rule canonical-rollback-orchestrator with engineer-override + counsel-of-record-override + chief-security-officer-override (3-party-rollback-orchestrator).
